# Массивы в Go

Массив (array) — тип данных для хранения элементов одного типа с неизменным размером. Например, для температуры
каждого дня недели всегда нужно семь значений, и их можно хранить в массиве.

В Go длина массива — часть его типа. Поэтому `[3]int` и `[4]int` считаются разными типами. Ещё одно свойство массива:
после его создания нельзя добавить место для нового элемента или уменьшить его размер.

## Объявление массива

Тип массива объявляется в виде `[длина]типЭлемента`:

```go
package main

import "fmt"

func main() {
	var scores [4]int
	scores[0] = 78
	scores[1] = 91

	fmt.Println(scores)
	fmt.Println("Длина:", len(scores))
}
```

**Результат:**

```text
[78 91 0 0]
Длина: 4
```

> **Информация**
>
> Размер массива вычисляется с помощью `len`.

Строка `var scores [4]int` выделяет место для четырёх значений `int`. Элементы, которым не присвоено значение,
сначала равны `0`, потому что `0` — нулевое значение типа `int`. Нулевое значение — это начальное значение, которое Go
автоматически присваивает при создании переменной.

Каждый элемент массива выбирается по индексу, то есть по его порядковому номеру. Индексы массива начинаются с `0`.
Поэтому у массива из четырёх элементов индексы `0`, `1`, `2` и `3`. В примере выше значения присвоены первым двум
элементам, а два остальных остались равными `0`.

> **Внимание**
>
> В примере выше нельзя обратиться к элементу как `scores[4]`, потому что в этом массиве нет индекса `4`.
> Если константный индекс выходит за границы, компилятор выдаёт ошибку. Но если индекс вычисляется во время работы
> программы и выходит за границы, программа останавливается с ошибкой `panic`.

## Объявление массива без указания длины

Бывают случаи, когда не хочется вручную считать длину массива при написании программы, и для этого в компиляторе Go
тоже есть возможность. При объявлении массива достаточно записать его размер как `[...]`.

```go
package main

import "fmt"

func main() {
	colors := [3]string{"красный", "зелёный", "синий"}
	numbers := [...]int{10, 20, 30, 40}

	fmt.Println(colors)
	fmt.Println(numbers, len(numbers))
}
```

**Результат:**

```text
[красный зелёный синий]
[10 20 30 40] 4
```

В записи `[3]string` длина массива указана явно. А `...` в `[...]int` поручает компилятору определить длину по
количеству заданных элементов. Поскольку в `numbers` четыре элемента, его тип — `[4]int`.

## Обход массива (итерация)

Чтобы последовательно прочитать все элементы массива, используется `range`. На каждой итерации цикла он даёт индекс и
значение элемента.

> **Информация**
>
> Итерация — однократное выполнение тела цикла.

```go
package main

import "fmt"

func main() {
	scores := [4]int{78, 91, 85, 88}
	sum := 0

	for index, score := range scores {
		fmt.Printf("индекс %d: %d\n", index, score)
		sum += score
	}

	fmt.Println("Среднее:", float64(sum)/float64(len(scores)))
}
```

Результат:

```text
индекс 0: 78
индекс 1: 91
индекс 2: 85
индекс 3: 88
Среднее: 85.5
```

Цикл добавляет каждое значение `score` к переменной `sum`. Чтобы вычислить среднее, сумма делится на количество
элементов. Перед делением оба значения преобразованы в `float64`, потому что при делении двух значений `int` Go
отбрасывает дробную часть результата.

## Копирование массива

При присваивании массива другой переменной Go делает отдельную копию всех его элементов. Изменение элемента в копии
не влияет на исходный массив:

```go
package main

import "fmt"

func main() {
	original := [3]int{1, 2, 3}
	copied := original
	copied[0] = 99

	fmt.Println("Оригинал:", original)
	fmt.Println("Копия:", copied)
}
```

**Результат:**

```text
Оригинал: [1 2 3]
Копия: [99 2 3]
```

В примере `original` и `copied` — два независимых массива из одинаковых значений. Поэтому при изменении `copied[0]`
значение `original[0]` осталось прежним.

> **Информация**
>
> Массив полностью копируется и при передаче в функцию в качестве аргумента. Многократная передача большого массива в
> функции может создавать лишние копии. В таких случаях обычно используют slice.

## Сравнение массивов

Массивы можно сравнивать операторами `==` и `!=`, но это зависит от типа элементов массива. Если тип элементов
сравнимый, сравнимы и сами массивы.

Например, тип `int` сравнимый, поэтому массивы из элементов `int` тоже можно сравнивать:

```go
a := [3]int{1, 2, 3}
b := [3]int{1, 2, 3}
c := [3]int{1, 2, 4}

fmt.Println(a == b) // true
fmt.Println(a == c) // false
```

Go сравнивает массивы поэлементно. Если все соответствующие элементы равны, результат — `true`.

Если тип элементов массива несравнимый, сам массив тоже нельзя проверить операторами `==` или `!=`. Например, `slice`
несравним:

```go
a := [2][]int{
	{1, 2},
	{3, 4},
}

b := [2][]int{
	{1, 2},
	{3, 4},
}

// fmt.Println(a == b)
// Ошибка: массивы с элементами slice сравнивать нельзя.
```

## Когда используется массив?

Если количество элементов известно заранее и не меняется, массив удобен. Например, адрес IPv4 всегда состоит из
четырёх байтов. Его можно представить типом `[4]byte`.

Если количество элементов может увеличиваться или уменьшаться во время работы программы, обычно используют `slice`.
Значит, выбор между `массивом` и `slice` прежде всего зависит от того, меняется ли количество элементов.

## Дополнительные примеры

### 1. Определение длины компилятором

```go
package main

import "fmt"

func main() {
	colors := [...]string{"красный", "зелёный", "синий"}
	fmt.Printf("%T, длина: %d\n", colors, len(colors))
}
```

**Результат:**

```text
[3]string, длина: 3
```

Запись `...` позволяет не вводить длину массива вручную. Компилятор видит, что цветов три, и задаёт тип `colors` как
`[3]string`.

### 2. Литерал массива с индексами

```go
package main

import "fmt"

func main() {
	numbers := [6]int{1: 10, 4: 40}
	fmt.Println(numbers)
}
```

**Результат:**

```text
[0 10 0 0 40 0]
```

В литерале массива можно задать значения только нужным индексам. В этом примере по индексу `1` записывается `10`, а
по индексу `4` — `40`. Остальные элементы заполняются нулевым значением типа `int` — `0`.

### 3. Сравнение массивов на равенство

```go
package main

import "fmt"

func main() {
	a := [3]int{1, 2, 3}
	b := [3]int{1, 2, 3}
	fmt.Println(a == b)
}
```

**Результат:**

```text
true
```

`a` и `b` имеют одинаковый тип `[3]int`. Значения по соответствующим индексам тоже равны. Поэтому программа выводит
`true`.

### 4. Изменение копии массива

```go
package main

import "fmt"

func main() {
	original := [3]int{2, 4, 6}
	copied := original
	for i := range copied {
		copied[i] *= 2
	}
	fmt.Println("Оригинал:", original)
	fmt.Println("Копия:", copied)
}
```

**Результат:**

```text
Оригинал: [2 4 6]
Копия: [4 8 12]
```

`copied := original` копирует все элементы. Цикл удваивает только элементы `copied`. В результате `original` остаётся
прежним.

### 5. Вычисление суммы массива

```go
package main

import "fmt"

func main() {
	numbers := [5]int{4, 7, 2, 9, 3}
	sum := 0
	for _, num := range numbers {
		sum += num
	}
	fmt.Println(sum)
}
```

**Результат:**

```text
25
```

`range` возвращает индекс и значение. В этом примере индекс не нужен, поэтому вместо него записан пустой
идентификатор `_`. Каждое значение добавляется к `sum`, и программа выводит число `25`.

### 6. Нахождение индекса наибольшего элемента

```go
package main

import "fmt"

func main() {
	numbers := [5]int{4, 17, 8, 17, 3}
	largest := 0
	for i := 1; i < len(numbers); i++ {
		if numbers[i] > numbers[largest] {
			largest = i
		}
	}
	fmt.Println(largest, numbers[largest])
}
```

**Результат:**

```text
1 17
```

Переменная `largest` хранит не значение, а индекс наибольшего элемента. Сначала наибольшим считается элемент с
индексом `0`. Цикл сравнивает остальные элементы со значением `numbers[largest]`.

При сравнении используется `>`. Поэтому если наибольшее значение встречается несколько раз, сохраняется его первый
индекс. В этом массиве `17` встречается дважды, но в результате выводится его первый индекс — `1`.

### 7. Двумерный массив

```go
package main

import "fmt"

func main() {
	matrix := [2][3]int{{1, 2, 3}, {4, 5, 6}}
	for row := range matrix {
		for column := range matrix[row] {
			fmt.Print(matrix[row][column], " ")
		}
		fmt.Println()
	}
}
```

**Результат:**

```text
1 2 3
4 5 6
```

`[2][3]int` — массив из двух строк и трёх столбцов. Каждая строка сама является массивом `[3]int` из трёх элементов.
Чтобы получить элемент, сначала пишется индекс строки, затем индекс столбца: `matrix[row][column]`.

### 8. Главная диагональ матрицы

```go
package main

import "fmt"

func main() {
	matrix := [3][3]int{{1, 2, 3}, {4, 5, 6}, {7, 8, 9}}
	sum := 0
	for i := range matrix {
		sum += matrix[i][i]
	}
	fmt.Println(sum)
}
```

**Результат:**

```text
15
```

У элементов главной диагонали индексы строки и столбца одинаковы: `[0][0]`, `[1][1]` и `[2][2]`.
Цикл складывает значения `1`, `5` и `9`. Поэтому результат — `15`.

### 9. Частота цифр

```go
package main

import "fmt"

func main() {
	num := 120221
	var counts [10]int
	for num > 0 {
		counts[num%10]++
		num /= 10
	}
	fmt.Println(counts)
}
```

**Результат:**

```text
[1 2 3 0 0 0 0 0 0 0]
```

В этом примере индекс массива обозначает саму цифру. А значение по индексу хранит, сколько раз встретилась эта цифра.
Например, значение `counts[2]` показывает, сколько раз цифра `2` встречается в числе. В числе `120221` цифра `1`
встречается дважды, а `2` — трижды.

В десятичной системе всегда десять цифр — от `0` до `9`. Поскольку количество элементов не меняется, для этой задачи
подходит массив `[10]int`.

> **Информация**
>
> В этом простом примере `num` считается положительным. Если значение `num` равно ровно `0`, цикл не выполняется, и
> цифра ноль не подсчитывается. В программе, работающей с внешними данными, этот случай нужно проверять отдельно.

### 10. Разворот массива на месте

```go
package main

import "fmt"

func main() {
	arr := [5]int{10, 20, 30, 40, 50}
	for left, right := 0, len(arr)-1; left < right; left, right = left+1, right-1 {
		arr[left], arr[right] = arr[right], arr[left]
	}
	fmt.Println(arr)
}
```

**Результат:**

```text
[50 40 30 20 10]
```

Индекс `left` движется от начала массива, а `right` — от конца. На каждой итерации значения по этим индексам
меняются местами. Когда индексы встречаются, цикл заканчивается. Поскольку изменение выполняется в самом массиве,
дополнительный массив не нужен.

ёмкостью, а также с функцией `append()`.
