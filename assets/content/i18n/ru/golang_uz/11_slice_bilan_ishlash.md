# Работа со срезами (slice) в Go

**Срез** (slice) — тип данных для работы с элементами одного типа. В отличие от массива, длину среза можно при
необходимости увеличивать или уменьшать. Поэтому срезы часто используют, когда количество элементов заранее неизвестно.
Например, результат из API, прочитанные из файла строки или данные из базы удобно хранить в `slice`.

Срез — это не отдельный тип, который сам хранит элементы. Элементы находятся в базовом массиве (array) в памяти.
А срез ссылается на определённую часть этого массива. Он хранит, где он начинается, сколько в нём элементов и сколько
ещё места он может использовать.

- `len` — количество элементов, которые сейчас есть в `slice`.
- `cap` — место, доступное от начала `slice` до конца базового массива.

## Создание среза

Тип среза записывается как `[]типЭлемента`. Внутри квадратных скобок число не пишется. Например, `[]int` — `slice` из
элементов `int`, а `[3]int` — массив из трёх элементов.

```go
package main

import "fmt"

func main() {
	var empty []int
	fruits := []string{"яблоко", "гранат", "виноград"}
	numbers := make([]int, 3, 5)

	fmt.Println(empty, len(empty), cap(empty), empty == nil)
	fmt.Println(fruits)
	fmt.Println(numbers, len(numbers), cap(numbers))
}
```

**Результат:**

```text
[] 0 0 true
[яблоко гранат виноград]
[0 0 0] 3 5
```

`Slice` можно создать тремя способами:

- `var empty []int` — `nil`-срез, ещё не связанный с базовым массивом;
- `[]string{"яблоко", "гранат", "виноград"}` — срез, объявленный вместе со значениями;
- `make([]int, 3, 5)` — срез длины `3` и ёмкости `5`.

`nil`-срез пуст. С ним можно безопасно использовать такие функции, как `len`, `cap`, `range` и `append`. А три
элемента среза `numbers`, созданного через `make`, сначала заполняются `0` — нулевым значением типа `int`.

> **Информация**
>
> `nil`-срез и `[]int{}` оба пусты, то есть их длина `0`. Их можно сравнивать с `nil`, но равен `nil` только первый.
> Например, при преобразовании в JSON один выводится как `null`, а другой — как `[]`.

## Получение части среза

Чтобы взять из `slice` определённый диапазон, используется выражение среза. В записи `s[low:high]` элемент с
индексом `low` входит в результат, а элемент с индексом `high` — нет:

```go
package main

import "fmt"

func main() {
	numbers := []int{10, 20, 30, 40, 50}
	part := numbers[1:4]

	fmt.Println(part)
	part[0] = 99
	fmt.Println(numbers)
}
```

Результат:

```text
[20 30 40]
[10 99 30 40 50]
```

Выражение `numbers[1:4]` берёт элементы с индексами `1`, `2` и `3`. В результате получается `[20 30 40]`.

Эта операция не копирует элементы. Оба среза указывают на один и тот же базовый массив. `part[0]` — это на самом деле
то место, где находится `numbers[1]`. Поэтому когда туда записывается `99`, меняется и `numbers`. Если нужна отдельная
копия, используют функцию `copy`.

## `append`, длина и ёмкость

`append` добавляет новые элементы в конец среза. Он возвращает не исходный `slice`, а обновлённое значение `slice`.
Поэтому результат нужно снова сохранить в переменную:

```go
package main

import "fmt"

func main() {
	numbers := make([]int, 0, 2)

	numbers = append(numbers, 10, 20)
	fmt.Println(numbers, len(numbers), cap(numbers))

	numbers = append(numbers, 30)
	fmt.Println(numbers, len(numbers), cap(numbers))
}
```

Сначала добавляются два элемента, которые помещаются в ёмкость `slice`, а для третьего элемента имеющейся ёмкости не
хватает, поэтому результат такой:

```text
[10 20] 2 2
[10 20 30] 3 4
```

Если ёмкости хватает, `append` использует свободное место в существующем базовом массиве. Если не хватает, Go создаёт
массив побольше, копирует в него старые элементы и возвращает `slice`, ссылающийся на новый массив.

Новая ёмкость не обязательно будет ровно `4`. На сколько она вырастет, решает среда выполнения Go. Единственное
правило — ёмкость не может быть меньше длины. Поэтому логику программы не следует привязывать к тому, насколько растёт ёмкость.

> **Внимание**
>
> Написать просто `append(numbers, 30)` недостаточно. `append` может создать новый базовый массив, и возвращённый срез
> ссылается на него. Всегда присваивайте результат переменной: `numbers = append(numbers, 30)`.

## Связь между срезами

Срезы, связанные с одним базовым массивом, могут влиять на элементы друг друга. Обычно это происходит при
использовании `append`:

```go
package main

import "fmt"

func main() {
	original := []int{1, 2, 3, 4}
	part := original[:2]
	part = append(part, 99)

	fmt.Println("Оригинал:", original)
	fmt.Println("Часть:", part)
}
```

Результат:

```text
Оригинал: [1 2 99 4]
Часть: [1 2 99]
```

Сначала `part` ссылается на первые два элемента `original`. Его длина `2`, но в базовом массиве ещё есть свободная
ёмкость. Поэтому `append` не создаёт новый массив. Он записывает значение `99` в следующее место базового массива, то
есть поверх `original[2]`.

Если один из `slice` нужно изменять независимо, правильно сначала взять его отдельную копию в другую переменную.

## Копирование

`copy` копирует элементы из одного среза в другую переменную-срез. Срез-приёмник нужно заранее создать нужной длины.
`copy` также возвращает количество скопированных элементов:

```go
package main

import "fmt"

func main() {
	original := []int{1, 2, 3}
	copied := make([]int, len(original))
	n := copy(copied, original)
	copied[0] = 99

	fmt.Println("Скопировано:", n)
	fmt.Println("Оригинал:", original)
	fmt.Println("Копия:", copied)
}
```

Результат:

```text
Скопировано: 3
Оригинал: [1 2 3]
Копия: [99 2 3]
```

Для `copied` создан отдельный базовый массив. Поэтому запись `99` в `copied[0]` не влияет на `original`.

`copy` копирует только столько элементов, сколько помещается в длину обоих `slice`. Например, если в исходном `slice`
пять мест, а в новом — три, копируются только три элемента.

При копировании `slice` можно также использовать способы `copied := append([]int(nil), original...)` или
`copied := slices.Clone(original)`.

## Удаление элемента

Отдельной функции `delete` для удаления элемента `slice` нет. Чтобы сохранить порядок элементов, части до и после
удаляемого элемента объединяют через `append`:

```go
package main

import "fmt"

func main() {
	numbers := []int{10, 20, 30, 40}
	index := 1
	numbers = append(numbers[:index], numbers[index+1:]...)

	fmt.Println(numbers)
}
```

Результат:

```text
[10 30 40]
```

Часть `numbers[:index]` берёт всё, что стоит до удаляемого элемента. В этом примере значение `index` равно `1`,
поэтому результат — `[10]`. `numbers[index+1:]` берёт все элементы после удаляемого. Результат этой части — `[30 40]`.
Функция `append()` добавляет к первой части элементы второй. Оператор `...` разбивает часть `[30 40]` на отдельные
элементы и передаёт их в `append()`. Так элемент `20` не попадает в новую часть, и получается `[10 30 40]`.

Если значение `index` приходит от пользователя или из другого внешнего источника, сначала нужно проверить условие
`0 <= index && index < len(numbers)`. Иначе при взятии части произойдёт `panic`.

## Дополнительные примеры

### 1. Заблаговременное выделение ёмкости среза

```go
package main

import "fmt"

func main() {
	numbers := make([]int, 0, 5)
	for i := 1; i <= 5; i++ {
		numbers = append(numbers, i*i)
	}
	fmt.Println(numbers, len(numbers), cap(numbers))
}
```

Если количество элементов примерно известно, заблаговременное выделение ёмкости уменьшает количество новых массивов,
создаваемых при `append`. При создании среза его длина `0`, потому что элементы ещё не добавлены. А ёмкость `5`,
поэтому место для первых пяти элементов уже готово.

### 2. Добавление нескольких элементов сразу

```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2}
	numbers = append(numbers, 3, 4, 5)
	fmt.Println(numbers)
}
```

`append` принимает несколько элементов за один вызов. В примере значения `3`, `4` и `5` добавляются друг за другом.
Результат — `[1 2 3 4 5]`.

### 3. Добавление элементов другого среза

```go
package main

import "fmt"

func main() {
	first := []int{1, 2}
	second := []int{3, 4}
	joined := append(first, second...)
	fmt.Println(joined)
}
```

Знак `...` передаёт элементы среза `second` в `append` как отдельные значения. В результате из элементов обоих срезов
получается `[1 2 3 4]`.

> **Внимание**
>
> Если ёмкости хватает, `append` может использовать базовый массив `first`. Если `joined` должен быть полностью
> независимым, сначала создайте копию.

### 4. Разворот среза на месте

```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4, 5}
	for left, right := 0, len(numbers)-1; left < right; left, right = left+1, right-1 {
		numbers[left], numbers[right] = numbers[right], numbers[left]
	}
	fmt.Println(numbers)
}
```

Индекс `left` движется от начала, а `right` — от конца к середине. На каждом шаге элементы по этим индексам меняются
местами. Поскольку изменение выполняется в существующем срезе, дополнительный срез не создаётся.

### 5. Фильтрация элементов по условию

```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4, 5, 6}
	evens := make([]int, 0, len(numbers))
	for _, num := range numbers {
		if num%2 == 0 {
			evens = append(evens, num)
		}
	}
	fmt.Println(evens)
}
```

Цикл добавляет в срез `evens` только чётные числа. Поскольку для результата создан отдельный срез, `numbers` не
меняется. Количество чётных элементов не может превысить длину источника. Поэтому заранее выделена ёмкость, равная
длине источника.

### 6. Фильтрация без дополнительной памяти

```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4, 5, 6}
	evens := numbers[:0]
	for _, num := range numbers {
		if num%2 == 0 {
			evens = append(evens, num)
		}
	}
	fmt.Println(evens)
}
```

`numbers[:0]` создаёт срез нулевой длины, но не создаёт новый базовый массив. `append` записывает выбранные чётные
числа в базовый массив `numbers`, начиная с начала. В результате дополнительный базовый массив не выделяется, но
элементы источника тоже меняются.

### 7. Удаление элемента без сохранения порядка

```go
package main

import "fmt"

func main() {
	numbers := []int{10, 20, 30, 40}
	index := 1
	numbers[index] = numbers[len(numbers)-1]
	numbers = numbers[:len(numbers)-1]
	fmt.Println(numbers)
}
```

На место удаляемого `20` записывается последний элемент — `40`. Затем длина среза уменьшается на единицу. Результат —
`[10 40 30]`. Если порядок не важен, этот способ не требует сдвигать остальные элементы.

### 8. Расширение среза до нужной длины

```go
package main

import "fmt"

func main() {
	numbers := make([]int, 2, 5)
	numbers[0], numbers[1] = 10, 20
	numbers = numbers[:4]
	numbers[2], numbers[3] = 30, 40
	fmt.Println(numbers)
}
```

Если новая длина не превышает ёмкость, срез можно расширить повторным взятием среза. В примере длина увеличивается с
`2` до `4`. Ставшие видимыми элементы сначала имеют значение `0`, затем в них записываются `30` и `40`.

### 9. Создание двумерного среза

```go
package main

import "fmt"

func main() {
	rows, columns := 2, 3
	table := make([][]int, rows)
	for i := range table {
		table[i] = make([]int, columns)
		table[i][0] = i + 1
	}
	fmt.Println(table)
}
```

`[][]int` — срез, элементы которого тоже `[]int`. Сначала создаётся внешний срез для строк. Затем в цикле для каждой
строки выделяется отдельный внутренний срез. Поэтому строки могут быть одинаковой или разной длины.

### 10. Сравнение срезов на равенство

```go
package main

import (
	"fmt"
	"slices"
)

func main() {
	a := []int{1, 2, 3}
	b := []int{1, 2, 3}
	fmt.Println(slices.Equal(a, b))
}
```

Срезы нельзя сравнивать друг с другом через `==`. Можно только проверить, является ли срез `nil`, в виде
`slice == nil`.

Если элементы имеют сравнимый тип, `slices.Equal` сначала сравнивает длины, а затем элементы с одинаковыми
индексами. Поскольку оба среза в примере одинаковы, программа вывела `true`.

> **Совет**
>
> - Срезы используются для последовательных данных, длина которых может меняться.
> - `len` — количество элементов, которые сейчас есть в срезе, а `cap` — доступное место в базовом
>     массиве.
> - Срез, вырезанный из другого, обычно связан с тем же базовым массивом, что и исходный. Изменение в одном
>     влияет и на другой.
> - Срез, возвращённый `append`, всегда нужно присваивать переменной. Если ёмкости не хватает, создаётся новый базовый массив.
