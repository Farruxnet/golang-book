# Математические функции в Go

Простые математические действия, такие как сложение, вычитание, умножение и деление, можно выполнять операторами Go.

Например:

```go
a + b
a - b
a * b
a / b
```

Но для более сложных вычислений — нахождения квадратного корня, возведения в степень, вычисления синуса или косинуса, округления чисел — нужны готовые функции.

В стандартной библиотеке Go такие функции находятся в пакете `math`.

В этой части мы рассмотрим:

* подключение пакета `math` к программе;
* использование математических констант;
* вычисление корней и степеней;
* округление чисел;
* тригонометрические функции;
* логарифм и экспоненту;
* `NaN` и бесконечные значения.

## Импорт пакета `math`

Чтобы использовать функции и константы пакета `math`, сначала нужно импортировать пакет (`import`).

Например:

```go
package main

import "math"
import "fmt"

func main() {
    fmt.Println(math.Pi)
}
```

Результат:

```text
3.141592653589793
```

Здесь `math.Pi` — готовое значение числа π из стандартной библиотеки Go.

Важно, что `Pi` — не функция. Это константа.

Поэтому пишется:

```go
math.Pi
```

Скобки не нужны.

В отличие от этого, `math.Sqrt()` и `fmt.Println()` — функции:

```go
math.Sqrt(81)
fmt.Println("Привет")
```

Скобки используются, чтобы передать функции аргументы.

В первом примере `fmt.Println()` выводит значение `math.Pi` в обычном виде:

```text
3.141592653589793
```

Если нужно показать только два знака после запятой, можно использовать `fmt.Printf()` и формат `%.2f`:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    fmt.Printf("Pi: %.2f\n", math.Pi)
}
```

Результат:

```text
Pi: 3.14
```

Здесь:

```text
%.2f
```

означает вывод числа типа `float` с двумя знаками после запятой.

Например:

* `%.2f` — два знака;
* `%.3f` — три знака;
* `%.4f` — четыре знака.

Есть важное различие: форматирование меняет только результат, который виден на экране.

Само значение `math.Pi` не меняется.

Например, в `math.Pi` по-прежнему хранится примерно:

```text
3.141592653589793
```

Мы только выводим его в виде `3.14`.

**Совет**

Если нужно несколько пакетов, их можно подключить отдельными `import`. Но в коде на Go обычно используется один блок `import`:

````
```go
import (
    "fmt"
    "math"
)
```
````

## Часто используемые математические функции

Большая часть функций пакета `math` работает со значениями `float64`.

В большинстве случаев функция:

1. принимает аргумент `float64`;
2. выполняет вычисление;
3. возвращает значение `float64`.

В следующей таблице приведены самые используемые функции:

| Функция или константа   | Назначение                                                          |
| ----------------------- | ------------------------------------------------------------------- |
| `math.Abs(x)`           | возвращает модуль `x`, то есть его неотрицательное значение         |
| `math.Sqrt(x)`          | вычисляет квадратный корень из `x`                                  |
| `math.Cbrt(x)`          | вычисляет кубический корень из `x`                                  |
| `math.Pow(x, y)`        | возводит `x` в степень `y`                                          |
| `math.Pow10(n)`         | вычисляет 10 в степени `n`                                          |
| `math.Min(x, y)`        | возвращает меньшее из двух чисел                                    |
| `math.Max(x, y)`        | возвращает большее из двух чисел                                    |
| `math.Mod(x, y)`        | вычисляет остаток от деления для дробных чисел                      |
| `math.Floor(x)`         | округляет вниз, к ближайшему меньшему целому значению               |
| `math.Ceil(x)`          | округляет вверх, к ближайшему большему целому значению              |
| `math.Round(x)`         | округляет до ближайшего целого значения                             |
| `math.Sin(x)`           | вычисляет синус `x`, заданного в радианах                           |
| `math.Cos(x)`           | вычисляет косинус `x`, заданного в радианах                         |
| `math.Tan(x)`           | вычисляет тангенс `x`, заданного в радианах                         |
| `math.Asin(x)`          | возвращает арксинус `x` в радианах                                  |
| `math.Acos(x)`          | возвращает арккосинус `x` в радианах                                |
| `math.Atan(x)`          | возвращает арктангенс `x` в радианах                                |
| `math.Exp(x)`           | возводит число `e` в степень `x`                                    |
| `math.Log(x)`           | вычисляет натуральный логарифм `x`                                  |
| `math.Log10(x)`         | вычисляет десятичный логарифм `x`                                   |
| `math.Hypot(x, y)`      | вычисляет гипотенузу треугольника с катетами `x` и `y`              |
| `math.Pi`               | математическая константа π                                          |
| `math.E`                | математическая константа e                                          |

В следующих разделах мы рассмотрим важные из этих функций на отдельных примерах.

## Модуль, корень и степень

Модуль обозначает величину числа без учёта его знака.

Например:

```text
|-12.5| = 12.5
```

В Go модуль можно вычислить с помощью `math.Abs()`.

Для квадратного корня используется `math.Sqrt()`, для кубического — `math.Cbrt()`.

А для возведения в степень есть `math.Pow()`.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    num := -12.5

    fmt.Println("Модуль:", math.Abs(num))
    fmt.Println("Квадратный корень из 81:", math.Sqrt(81))
    fmt.Println("Кубический корень из 27:", math.Cbrt(27))
    fmt.Println("2 в степени 5:", math.Pow(2, 5))
    fmt.Println("10 в степени 3:", math.Pow10(3))
}
```

Результат:

```text
Модуль: 12.5
Квадратный корень из 81: 9
Кубический корень из 27: 3
2 в степени 5: 32
10 в степени 3: 1000
```

Теперь рассмотрим каждое вычисление отдельно.

```go
math.Abs(-12.5)
```

даёт:

```text
12.5
```

Потому что модуль убирает знак минус.

```go
math.Sqrt(81)
```

вычисляет квадратный корень из `81`:

```text
9 × 9 = 81
```

Поэтому результат — `9`.

```go
math.Cbrt(27)
```

находит кубический корень:

```text
3 × 3 × 3 = 27
```

Результат — `3`.

`math.Pow()` принимает два аргумента:

```go
math.Pow(2, 5)
```

Здесь:

* `2` — основание;
* `5` — показатель степени.

Вычисление:

```text
2 × 2 × 2 × 2 × 2 = 32
```

Оба аргумента `math.Pow()` при вычислении используются как `float64`, и результат тоже `float64`.

А `math.Pow10(3)` предназначена для особого случая:

```text
10³ = 1000
```

То есть если нужно вычислить только степень 10, удобнее `math.Pow10()`.

## Вычисление площади круга

Площадь круга находится по формуле:

```text
S = πr²
```

Здесь:

* `S` — площадь круга;
* `π` — число пи;
* `r` — радиус.

Получим радиус от пользователя и вычислим площадь круга с помощью `math.Pi` и `math.Pow()`:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    var radius float64

    fmt.Print("Введите радиус круга: ")
    fmt.Scan(&radius)

    area := math.Pi * math.Pow(radius, 2)

    fmt.Printf("Площадь круга: %.2f\n", area)
}
```

Эта программа работает по шагам так.

Сначала создаётся переменная `radius` типа `float64`:

```go
var radius float64
```

Затем считывается значение, введённое пользователем:

```go
fmt.Scan(&radius)
```

Например, если пользователь ввёл `5`:

```text
radius = 5
```

Затем:

```go
math.Pow(radius, 2)
```

вычисляет:

```text
5² = 25
```

Потом вычисляется:

```text
math.Pi * 25
```

Примерно:

```text
3.141592653589793 × 25 = 78.539816...
```

Поскольку результат выводится через `%.2f`, на экране будет:

```text
78.54
```

Полный результат:

```text
Введите радиус круга: 5
Площадь круга: 78.54
```

Квадрат радиуса можно вычислить и без `math.Pow()`:

```go
radius * radius
```

Например:

```go
area := math.Pi * radius * radius
```

Именно для возведения в квадрат этот способ простой и понятный.

А `math.Pow()` особенно полезна, когда степень заранее не известна или нужна произвольная степень.

## Вычисление гипотенузы

По теореме Пифагора гипотенуза прямоугольного треугольника вычисляется по формуле:

```text
c = √(a² + b²)
```

Здесь `a` и `b` — катеты.

Например, если `a = 3` и `b = 4`:

```text
a² = 9
b² = 16

9 + 16 = 25

√25 = 5
```

В Go это вычисление можно выполнить двумя способами:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    a := 3.0
    b := 4.0

    simple := math.Sqrt(a*a + b*b)
    withHypot := math.Hypot(a, b)

    fmt.Println("Через Sqrt:", simple)
    fmt.Println("Через Hypot:", withHypot)
}
```

Результат:

```text
Через Sqrt: 5
Через Hypot: 5
```

Первый способ записывает формулу напрямую:

```go
math.Sqrt(a*a + b*b)
```

Здесь:

```text
a * a = 3 * 3 = 9
b * b = 4 * 4 = 16
9 + 16 = 25
sqrt(25) = 5
```

Второй способ:

```go
math.Hypot(a, b)
```

создан именно для этой задачи.

Для обычных значений оба способа дают одинаковый результат.

Но при работе с очень большими или очень маленькими числами `math.Hypot()` выполняет вычисление более устойчиво с вычислительной точки зрения. При обычном вычислении `a*a + b*b` для некоторых экстремальных значений могут возникать проблемы, связанные с пределами `float64`.

Поэтому для вычислений вроде гипотенузы или расстояния между двумя координатами удобна `math.Hypot()`.

## Округление чисел

Для приведения дробных чисел к целым значениям в пакете `math` есть несколько функций.

Самые используемые:

* `math.Floor()`;
* `math.Ceil()`;
* `math.Round()`.

Хотя они выглядят похоже, работают они по-разному.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    num := 3.7

    fmt.Println("Floor:", math.Floor(num))
    fmt.Println("Ceil:", math.Ceil(num))
    fmt.Println("Round:", math.Round(num))
}
```

Результат:

```text
Floor: 3
Ceil: 4
Round: 4
```

Рассмотрим каждую функцию отдельно.

```go
math.Floor(3.7)
```

возвращает ближайшее целое значение, которое меньше числа или равно ему.

Поэтому:

```text
3.7 → 3
```

А `math.Ceil()` работает в сторону увеличения:

```go
math.Ceil(3.7)
```

результат:

```text
3.7 → 4
```

`math.Round()` выбирает ближайшее целое значение:

```go
math.Round(3.7)
```

Число `3.7` ближе к `4`, чем к `3`. Поэтому результат:

```text
4
```

Эти функции возвращают значение `float64`.

Например:

```go
rounded := math.Floor(3.7)
fmt.Printf("Значение: %v, тип: %T\n", rounded, rounded)
```

Результат будет примерно таким:

```text
Значение: 3, тип: float64
```

Хотя на экране видно `3`, тип переменной не `int`.

Она по-прежнему имеет тип:

```go
float64
```

С отрицательными числами нужно особенно внимательно относиться к результатам `Floor` и `Ceil`.

Например:

```go
math.Floor(-3.2)
```

даёт:

```text
-4
```

На первый взгляд может показаться, что должно быть `-3`. Но `Floor` всегда движется по числовой оси в меньшую сторону.

На числовой оси:

```text
-4 < -3.2 < -3
```

Поэтому меньшее целое — `-4`.

И наоборот:

```go
math.Ceil(-3.2)
```

даёт:

```text
-3
```

## Округление до заданного числа знаков после запятой

Иногда число нужно математически округлить не до целого, а, например, до двух знаков после запятой.

Пример:

```text
12.3456
```

это значение мы хотим привести к виду:

```text
12.35
```

Для этого значение можно сначала умножить на `100`, затем округлить и потом снова разделить на `100`.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    num := 12.3456
    rounded := math.Round(num*100) / 100

    fmt.Println(rounded)
}
```

Результат:

```text
12.35
```

Разберём вычисление по шагам.

Начальное значение:

```text
12.3456
```

Сначала умножается на `100`:

```text
12.3456 × 100 = 1234.56
```

Затем:

```go
math.Round(1234.56)
```

даёт:

```text
1235
```

Потом снова делится на `100`:

```text
1235 / 100 = 12.35
```

В результате само значение математически округляется до двух знаков после запятой.

Этот способ не нужно путать с:

```go
fmt.Printf("%.2f", num)
```

`fmt.Printf("%.2f", num)` только форматирует выводимый на экран вид до двух знаков.

А способ с `math.Round()` старается округлить и значение, которое используется в дальнейших вычислениях.

**Внимание**

`float64` не может абсолютно точно хранить в памяти все десятичные дроби.

```
Например, двоичное представление некоторых чисел, таких как `0.1` и `0.2`, бесконечно. Поэтому компьютер хранит их как ближайшее значение `float64`.

В финансовых вычислениях обычного `float64` и `math.Round()` может оказаться недостаточно.

При работе с денежными значениями часто удобнее хранить деньги как целое число в наименьшей единице.

Например, вместо `125.50` рубля можно хранить целое число в копейках.

В сложных финансовых системах также применяют специальные **decimal**-типы или библиотеки.
```

## Наименьшее и наибольшее значение

Чтобы найти меньшее из двух значений `float64`, используется `math.Min()`, а большее — `math.Max()`.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    first := 17.5
    second := 12.8

    fmt.Println("Меньшее:", math.Min(first, second))
    fmt.Println("Большее:", math.Max(first, second))
}
```

Результат:

```text
Меньшее: 12.8
Большее: 17.5
```

Здесь:

```go
math.Min(17.5, 12.8)
```

сравнивает оба числа и возвращает значение:

```text
12.8
```

```go
math.Max(17.5, 12.8)
```

возвращает значение:

```text
17.5
```

Эти функции полезны, например, чтобы значение не превышало определённый предел или чтобы выбрать больший из двух размеров.

**Информация**

`math.Min()` и `math.Max()` работают со значениями `float64`.

````
При работе с обычными значениями `int` в современных версиях Go можно использовать встроенные функции языка `min()` и `max()`.

Например:

```go
smaller := min(10, 20)
larger := max(10, 20)
```

В этом случае не нужно преобразовывать значения `int` в `float64`.
````

## Градусы и радианы

В тригонометрии есть несколько способов измерять угол.

В повседневной математике обычно используются градусы:

```text
30°
45°
90°
180°
```

Но функции Go:

```go
math.Sin()
math.Cos()
math.Tan()
```

принимают угол не в градусах, а в **радианах**.

Поэтому градусы сначала нужно перевести в радианы.

Формула:

```text
радианы = градусы × π / 180
```

Например, для `30°`:

```text
30 × π / 180
```

После сокращения получается:

```text
π / 6
```

В Go:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    degrees := 30.0
    radians := degrees * math.Pi / 180

    fmt.Printf("sin(30°) = %.2f\n", math.Sin(radians))
    fmt.Printf("cos(30°) = %.2f\n", math.Cos(radians))
}
```

Результат:

```text
sin(30°) = 0.50
cos(30°) = 0.87
```

Важная строка в коде:

```go
radians := degrees * math.Pi / 180
```

Она переводит значение `30°` в радианы.

Затем:

```go
math.Sin(radians)
```

и:

```go
math.Cos(radians)
```

вычисляют правильные значения.

**Внимание**

Следующий код:

````
```go
math.Sin(30)
```

не вычисляет синус `30°`.

Здесь значение `30` принимается как **30 радиан**.

Поэтому путаница между градусами и радианами — одна из самых распространённых ошибок в тригонометрических вычислениях.
````

## Обратные тригонометрические функции

Обычные тригонометрические функции находят тригонометрическое значение по углу.

Например:

```text
sin(30°) = 0.5
```

А обратные тригонометрические функции делают обратное.

Если:

```text
sin(x) = 0.5
```

то для нахождения угла `x` используется `math.Asin()`.

Для `math.Asin()` и `math.Acos()` аргумент обычно должен лежать в диапазоне:

```text
-1 ≤ x ≤ 1
```

Результат возвращается в радианах.

Если результат нужен в градусах, используется формула:

```text
градусы = радианы × 180 / π
```

Пример:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    value := 0.5
    radians := math.Asin(value)
    degrees := radians * 180 / math.Pi

    fmt.Printf("asin(%.1f) = %.0f°\n", value, degrees)
}
```

Результат:

```text
asin(0.5) = 30°
```

Код работает по шагам так.

Сначала вычисляется:

```go
math.Asin(0.5)
```

Результат — примерно:

```text
0.523598...
```

радиан.

Затем с помощью:

```go
radians * 180 / math.Pi
```

он переводится в градусы.

Результат:

```text
30
```

**Внимание**

Для `math.Asin()` и `math.Acos()` аргумент в пределах действительных чисел должен быть от `-1` до `1`.

````
Например:

```go
math.Asin(2.5)
```

или:

```go
math.Acos(2.5)
```

не имеют результата, определённого как действительное число.

В этом случае Go возвращает значение `NaN`.
````

**Информация**

`NaN` — **Not a Number**, то есть «не число», специальное значение `float64`.

```
Это значение используется для представления результата неправильной математической операции или операции, не определённой для действительных чисел.
```

## Логарифм и экспонента

`math.Exp(x)` и `math.Log(x)` — взаимно обратные математические операции.

`math.Exp(x)` вычисляет значение:

```text
eˣ
```

Здесь `e` — математическая константа, примерно равная:

```text
2.718281828...
```

А `math.Log(x)` вычисляет натуральный логарифм.

Пример:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    x := 2.0
    ePower := math.Exp(x)

    fmt.Printf("e^%.0f = %.4f\n", x, ePower)
    fmt.Printf("log(%.4f) = %.4f\n", ePower, math.Log(ePower))
    fmt.Println("Десятичный логарифм:", math.Log10(1000))
}
```

Результат:

```text
e^2 = 7.3891
log(7.3891) = 2.0000
Десятичный логарифм: 3
```

Сначала вычисляется:

```go
math.Exp(2)
```

```text
e² ≈ 7.389056...
```

Результат записывается в переменную `ePower`.

Затем вычисляется:

```go
math.Log(ePower)
```

Поскольку `Log` и `Exp` — обратные операции, результат снова примерно:

```text
2
```

А `math.Log10()` вычисляет десятичный логарифм:

```go
math.Log10(1000)
```

поскольку:

```text
10³ = 1000
```

результат:

```text
3
```

Для `math.Log(x)` важно, чтобы аргумент был положительным.

Например:

```go
math.Log(0)
```

возвращает отрицательную бесконечность.

Натурального логарифма отрицательного числа в пределах действительных чисел не существует.

Поэтому вычисление вроде:

```go
math.Log(-5)
```

возвращает `NaN`.

## `NaN` и бесконечность

Некоторые математические операции не имеют результата во множестве действительных чисел.

Например:

```text
√-1
```

не является действительным числом.

В Go при выполнении:

```go
math.Sqrt(-1)
```

программа не останавливается сразу.

Вместо этого пакет `math` возвращает специальное значение `NaN`.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    result := math.Sqrt(-1)

    fmt.Println(result)
    fmt.Println("Это NaN?", math.IsNaN(result))
}
```

Результат:

```text
NaN
Это NaN? true
```

Здесь:

```go
math.IsNaN(result)
```

проверяет, является ли значение `NaN`.

Поскольку результат — `NaN`, функция возвращает:

```text
true
```

Проверять `NaN` обычным равенством неправильно. Для этого используется именно `math.IsNaN()`.

А для проверки бесконечных значений есть:

```go
math.IsInf()
```

Например, результатом математического вычисления может быть положительная или отрицательная бесконечность.

В практических программах часто лучше до вычисления проверить, что аргумент функции находится в допустимом диапазоне.

Например, если квадратный корень нужен только для неотрицательных значений:

```go
if x < 0 {
    fmt.Println("Нельзя извлечь действительный квадратный корень из отрицательного числа")
    return
}

result := math.Sqrt(x)
```

Такой подход не даёт неправильному результату попасть в дальнейшие вычисления.

## Функции в одной программе

В следующем примере большинство рассмотренных выше основных функций `math` собраны в одной программе:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    x := 2.5
    y := 3.0
    trigValue := 0.5

    fmt.Printf("math.Abs(-%v) = %v\n", x, math.Abs(-x))
    fmt.Printf("math.Sin(%v) = %.4f\n", x, math.Sin(x))
    fmt.Printf("math.Cos(%v) = %.4f\n", x, math.Cos(x))
    fmt.Printf("math.Tan(%v) = %.4f\n", x, math.Tan(x))
    fmt.Printf("math.Asin(%v) = %.4f\n", trigValue, math.Asin(trigValue))
    fmt.Printf("math.Acos(%v) = %.4f\n", trigValue, math.Acos(trigValue))
    fmt.Printf("math.Atan(%v) = %.4f\n", x, math.Atan(x))
    fmt.Printf("math.Exp(%v) = %.4f\n", x, math.Exp(x))
    fmt.Printf("math.Log(%v) = %.4f\n", x, math.Log(x))
    fmt.Printf("math.Pow(%v, %v) = %.4f\n", x, y, math.Pow(x, y))
    fmt.Printf("math.Pow10(3) = %.4f\n", math.Pow10(3))
    fmt.Printf("math.Sqrt(%v) = %.4f\n", x, math.Sqrt(x))
    fmt.Printf("math.Floor(%v) = %.4f\n", x, math.Floor(x))
    fmt.Printf("math.Ceil(%v) = %.4f\n", x, math.Ceil(x))
    fmt.Printf("math.Round(%v) = %.4f\n", x, math.Round(x))
    fmt.Printf("math.Pi = %.4f\n", math.Pi)
    fmt.Printf("math.E = %.4f\n", math.E)
    fmt.Printf("math.Min(%v, %v) = %.4f\n", x, y, math.Min(x, y))
    fmt.Printf("math.Max(%v, %v) = %.4f\n", x, y, math.Max(x, y))
    fmt.Printf("math.Mod(%v, %v) = %.4f\n", x, y, math.Mod(x, y))
}
```

Результат:

```text
math.Abs(-2.5) = 2.5
math.Sin(2.5) = 0.5985
math.Cos(2.5) = -0.8011
math.Tan(2.5) = -0.7470
math.Asin(0.5) = 0.5236
math.Acos(0.5) = 1.0472
math.Atan(2.5) = 1.1903
math.Exp(2.5) = 12.1825
math.Log(2.5) = 0.9163
math.Pow(2.5, 3) = 15.6250
math.Pow10(3) = 1000.0000
math.Sqrt(2.5) = 1.5811
math.Floor(2.5) = 2.0000
math.Ceil(2.5) = 3.0000
math.Round(2.5) = 3.0000
math.Pi = 3.1416
math.E = 2.7183
math.Min(2.5, 3) = 2.5000
math.Max(2.5, 3) = 3.0000
math.Mod(2.5, 3) = 2.5000
```

Здесь `x`:

```go
x := 2.5
```

используется для большинства простых математических функций.

`y`:

```go
y := 3.0
```

используется в функциях, которым нужны два аргумента: `math.Pow()`, `math.Min()`, `math.Max()` и `math.Mod()`.

А для обратных тригонометрических функций выбрано отдельное значение:

```go
trigValue := 0.5
```

Причина в том, что для `math.Asin()` и `math.Acos()` значение должно быть между `-1` и `1`.

Например:

```go
math.Asin(0.5)
```

— правильный аргумент.

Результат выводится в радианах, примерно:

```text
0.5236
```

А `math.Mod(x, y)` вычисляет остаток от деления.

В этом примере вычисляется:

```go
math.Mod(2.5, 3)
```

Поскольку `2.5` меньше `3`, `3` не помещается в него ни одного раза целиком. Поэтому остаток:

```text
2.5
```

Большинство чисел в результате отформатированы через:

```text
%.4f
```

Поэтому они показаны с четырьмя знаками после запятой.

## Примеры

В следующих примерах посмотрим, как простые арифметические операторы и функции пакета `math` используются в практических задачах.

### 1. Площадь и периметр прямоугольника

В этом примере вычисляются площадь и периметр прямоугольника.

Формула площади:

```text
S = ширина × высота
```

Формула периметра:

```text
P = 2 × (ширина + высота)
```

Код:

```go
package main

import "fmt"

func main() {
    width, height := 8.0, 5.0

    fmt.Println("Площадь:", width*height)
    fmt.Println("Периметр:", 2*(width+height))
}
```

Разберём вычисление по шагам.

Площадь:

```text
8 × 5 = 40
```

Периметр:

```text
8 + 5 = 13
2 × 13 = 26
```

Результат:

```text
Площадь: 40
Периметр: 26
```

В этом примере специальная функция `math` не нужна. Достаточно обычных операторов умножения и сложения.

### 2. Длина окружности и площадь круга

В этом примере по радиусу вычисляются длина окружности и площадь круга.

Длина окружности:

```text
L = 2πr
```

Площадь круга:

```text
S = πr²
```

Код:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    radius := 3.0

    fmt.Printf("Длина: %.2f\n", 2*math.Pi*radius)
    fmt.Printf("Площадь: %.2f\n", math.Pi*radius*radius)
}
```

Здесь `radius` равен:

```text
3
```

Длина окружности примерно:

```text
2 × 3.14159 × 3 ≈ 18.85
```

А площадь круга:

```text
3.14159 × 3 × 3 ≈ 28.27
```

`math.Pi` даёт готовое значение числа π из стандартной библиотеки Go. Использовать `math.Pi` точнее, чем писать `3.14` вручную.

### 3. Среднее значение трёх чисел

Среднее арифметическое находят, сложив все числа и разделив сумму на их количество.

```go
package main

import "fmt"

func main() {
    a, b, c := 7.0, 8.0, 10.0

    average := (a + b + c) / 3

    fmt.Printf("%.2f\n", average)
}
```

Вычисление:

```text
7 + 8 + 10 = 25
25 / 3 = 8.3333...
```

`fmt.Printf("%.2f", ...)` показывает результат с двумя знаками после запятой:

```text
8.33
```

Поскольку значения `a`, `b` и `c` имеют тип `float64`, деление не теряет дробную часть.

Если бы вычисление выполнялось с целыми числами, нужно было бы учитывать правила целочисленного деления.

### 4. Вычисление процента

В этом примере к цене товара применяется скидка.

```go
package main

import "fmt"

func main() {
    price := 240_000.0
    discountPercent := 15.0

    discount := price * discountPercent / 100

    fmt.Println("Новая цена:", price-discount)
}
```

Сначала вычисляется `15%` от `240 000`:

```text
240000 × 15 / 100 = 36000
```

Значит, скидка:

```text
36000
```

Затем скидка вычитается из начальной цены:

```text
240000 - 36000 = 204000
```

Результат:

```text
Новая цена: 204000
```

Эту формулу можно использовать для процентов, налогов, комиссий и других относительных вычислений.

### 5. Перевод температуры

Формула перевода температуры из градусов Цельсия в градусы Фаренгейта:

```text
°F = °C × 9 / 5 + 32
```

Код:

```go
package main

import "fmt"

func main() {
    celsius := 25.0
    fahrenheit := celsius*9/5 + 32

    fmt.Printf("%.1f °F\n", fahrenheit)
}
```

Вычисление:

```text
25 × 9 = 225
225 / 5 = 45
45 + 32 = 77
```

Результат:

```text
77.0 °F
```

Здесь значение `celsius` записано как `25.0`.

Поэтому оно имеет тип `float64`.

В результате вычисления в выражении тоже выполняются с числами с плавающей точкой, и дробная часть при необходимости сохраняется.

### 6. Расстояние между двумя точками

На координатной плоскости расстояние между двумя точками вычисляется по формуле:

```text
d = √((x₂ - x₁)² + (y₂ - y₁)²)
```

`math.Hypot()` выполняет именно вычисление:

```text
√(a² + b²)
```

Поэтому ей можно передать разности координат:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    x1, y1 := 1.0, 2.0
    x2, y2 := 4.0, 6.0

    distance := math.Hypot(x2-x1, y2-y1)

    fmt.Println(distance)
}
```

Сначала находятся разности координат:

```text
x2 - x1 = 4 - 1 = 3
y2 - y1 = 6 - 2 = 4
```

Затем вычисляется:

```text
√(3² + 4²)
```

```text
3² = 9
4² = 16
9 + 16 = 25
√25 = 5
```

Результат:

```text
5
```

Это теорема Пифагора, применённая к координатам.

### 7. Деление с округлением вверх

Иногда элементы нужно разделить на группы определённой вместимости.

Например:

* есть `23` товара;
* в каждую коробку помещается `5` товаров.

Обычное целочисленное деление:

```text
23 / 5 = 4
```

даёт такой результат.

Но в `4` коробки помещается только:

```text
4 × 5 = 20
```

товаров.

Остаётся ещё `3` товара.

Значит, на самом деле нужно `5` коробок.

Следующая формула — распространённый способ округлить целочисленное деление вверх:

```go
package main

import "fmt"

func main() {
    products, boxSize := 23, 5

    boxes := (products + boxSize - 1) / boxSize

    fmt.Println(boxes)
}
```

Вычисление:

```text
23 + 5 - 1 = 27
27 / 5 = 5
```

При целочисленном делении дробная часть отбрасывается.

Поэтому результат:

```text
5
```

Эта формула полезна для положительных целых чисел:

```text
(n + d - 1) / d
```

Здесь:

* `n` — количество элементов;
* `d` — вместимость одной группы.

### 8. Удержание числа в диапазоне

Иногда значение не должно выходить за определённые нижнюю и верхнюю границы.

Например, процент не должен быть меньше:

```text
0
```

и больше:

```text
100
```

Но представим, что в программу пришло значение:

```text
135
```

Чтобы удержать его в диапазоне `0..100`, можно вместе использовать `math.Min()` и `math.Max()`:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    percent := 135.0

    percent = math.Max(0, math.Min(percent, 100))

    fmt.Println(percent)
}
```

Вычисление выполняется изнутри наружу.

Сначала вычисляется:

```go
math.Min(135, 100)
```

Результат:

```text
100
```

Потому что `100` меньше.

Затем вычисляется:

```go
math.Max(0, 100)
```

Результат снова:

```text
100
```

Таким образом:

```text
135 → 100
```

значение ограничивается.

Если бы значение было `-20`:

```text
math.Min(-20, 100) = -20
math.Max(0, -20) = 0
```

Значит:

```text
-20 → 0
```

Этот способ используется, чтобы удерживать значение в определённом интервале.

### 9. Сравнение чисел с плавающей точкой

Прямое сравнение значений `float64` через `==` не всегда даёт ожидаемый результат.

Причина в том, что многие десятичные дроби нельзя точно представить в двоичной системе.

Поэтому число может храниться в памяти с очень маленькой погрешностью.

Если разница между двумя значениями очень мала, их можно считать практически равными.

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    a := 0.1 + 0.2
    b := 0.3

    equal := math.Abs(a-b) < 1e-9

    fmt.Println(equal)
}
```

Здесь:

```go
a - b
```

вычисляет разницу между двумя значениями.

Разница может быть и отрицательной. Поэтому через:

```go
math.Abs(a - b)
```

берётся её модуль.

Затем через:

```go
< 1e-9
```

проверяется, что она меньше очень маленького допустимого порога.

`1e-9` в научной записи означает:

```text
0.000000001
```

Если разница меньше этого:

```go
equal = true
```

Этот способ — пример подхода, который называется **сравнением с эпсилоном**.

В практической программе выбор значения эпсилон зависит от масштаба вычислений и требуемой точности.

### 10. Сложный процент

При сложном проценте процент каждого нового периода начисляется не только на начальную сумму, но и на проценты, накопленные в предыдущих периодах.

Упрощённая формула:

```text
A = P × (1 + r)ⁿ
```

Здесь:

* `P` — начальная сумма;
* `r` — процент за один период;
* `n` — количество периодов;
* `A` — итоговая сумма.

В Go степень можно вычислить через `math.Pow()`:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    principal := 1_000_000.0
    annualRate := 12.0
    years := 3.0

    result := principal * math.Pow(1+annualRate/100, years)

    fmt.Printf("%.2f\n", result)
}
```

Сначала процент переводится в дробь:

```text
12 / 100 = 0.12
```

Затем:

```text
1 + 0.12 = 1.12
```

Для трёх лет вычисляется:

```text
1.12³
```

По шагам:

```text
1.12 × 1.12 = 1.2544
1.2544 × 1.12 = 1.404928
```

Затем умножается начальная сумма:

```text
1 000 000 × 1.404928 = 1 404 928
```

Результат:

```text
1404928.00
```

Здесь `math.Pow()` позволяет вычислить результат через степень, не повторяя вручную одно и то же умножение для каждого года.
