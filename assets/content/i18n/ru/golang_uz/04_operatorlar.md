# Операторы в Go

Оператор — символ или сочетание символов, которое выполняет определённое действие над значениями.

Например:

* `+` складывает два числа;
* `==` проверяет, равны ли два значения;
* `&&` объединяет несколько логических условий.

Значения, с которыми работает оператор, называются **операндами**.

Например:

```go
a + b
```

В этом выражении:

* `+` — оператор;
* `a` — первый операнд;
* `b` — второй операнд.

В Go операторы используются для многих задач: арифметических вычислений, сравнения значений, проверки условий, работы с битами и обновления значений переменных.

## Арифметические операторы

Арифметические операторы выполняют математические действия над числами.

| Оператор | Действие            | Пример   | Результат |
| -------- | ------------------- | -------- | --------: |
| `+`      | сложение            | `10 + 3` |      `13` |
| `-`      | вычитание           | `10 - 3` |       `7` |
| `*`      | умножение           | `10 * 3` |      `30` |
| `/`      | деление             | `10 / 3` |       `3` |
| `%`      | остаток от деления  | `10 % 3` |       `1` |

Следующая программа показывает все основные арифметические операторы:

```go
package main

import "fmt"

func main() {
    a := 10
    b := 3

    fmt.Println("Сложение:", a+b)
    fmt.Println("Вычитание:", a-b)
    fmt.Println("Умножение:", a*b)
    fmt.Println("Деление:", a/b)
    fmt.Println("Остаток:", a%b)
}
```

Результат:

```text
Сложение: 13
Вычитание: 7
Умножение: 30
Деление: 3
Остаток: 1
```

Здесь `a` и `b` — целые числа типа `int`.

Поэтому выражение:

```go
a / b
```

тоже выполняется как целочисленное деление.

Хотя математически `10 / 3` равно `3.333...`, Go оставляет здесь только целую часть. Результат — `3`.

### Деление целых и дробных чисел

В Go тип результата деления зависит от типов операндов.

Если оба операнда целые, результат тоже целый. Дробная часть отбрасывается:

```go
result := 10 / 3 // 3
```

Это вычисление работает так:

```text
10 / 3 = 3.333...
```

Но поскольку оба операнда имеют тип `int`, дробная часть не сохраняется:

```text
result = 3
```

Если нужен дробный результат, операнды нужно преобразовать в дробный тип, например `float32` или `float64`.

Например:

```go
package main

import "fmt"

func main() {
    total := 10
    people := 3
    perPerson := float64(total) / float64(people)

    fmt.Printf("На каждого: %.2f\n", perPerson)
}
```

Результат:

```text
На каждого: 3.33
```

Здесь:

```go
float64(total)
```

преобразует значение `total` из типа `int` в тип `float64`.

Точно так же:

```go
float64(people)
```

преобразует значение `people` в тип `float64`.

После этого вычисление выполняется как:

```text
10.0 / 3.0
```

и дробная часть сохраняется.

В `fmt.Printf`:

```go
%.2f
```

выводит результат с двумя цифрами после запятой.

**Внимание**

Делить на ноль нельзя.

````
Деление целого числа на `0` приводит к ошибке во время выполнения.

Например, следующий код опасен:

```go
divisor := 0
result := 10 / divisor
```

Поскольку во время выполнения значение `divisor` равно `0`, в программе возникает panic.
````

### Остаток от деления

Оператор `%` возвращает остаток, который получается после деления.

Например:

```go
17 % 5
```

Разберём вычисление по шагам:

```text
17 / 5 = 3
3 * 5 = 15
17 - 15 = 2
```

Значит:

```text
17 % 5 = 2
```

Оператор остатка полезен во многих местах.

Например:

* проверка, чётное число или нечётное;
* разбиение времени на часы, минуты и секунды;
* периодические вычисления;
* циклический перебор индексов.

Важный момент: в Go `%` работает с целыми числами.

## Увеличение и уменьшение на единицу

Оператор `++` увеличивает значение на единицу.

А оператор `--` уменьшает значение на единицу.

Например:

```go
package main

import "fmt"

func main() {
    count := 5
    count++
    fmt.Println(count)

    count--
    fmt.Println(count)
}
```

Результат:

```text
6
5
```

В начале программы:

```text
count = 5
```

Затем выполняется:

```go
count++
```

```text
count = 6
```

Потом выполняется:

```go
count--
```

```text
count = 5
```

В отличие от некоторых других языков программирования, эти операторы не являются выражениями.

В Go `count++` и `count--` — отдельные инструкции (statement).

Поэтому их нельзя помещать внутрь другого выражения:

```go
// result := count++ // ошибка компиляции
```

Например, запись:

```text
x = y++
```

которая может встречаться в C или JavaScript, в Go не существует.

Это правило делает код понятнее. Момент, когда значение увеличивается или уменьшается, хорошо виден на отдельной строке.

## Операторы присваивания

Оператор `=` присваивает значение справа существующей переменной слева.

Например:

```go
num := 10
num = 20
```

В первой строке:

```go
num := 10
```

создаётся новая переменная `num`, и ей присваивается значение `10`.

Во второй строке:

```go
num = 20
```

новая переменная не создаётся. Значение существующей переменной `num` меняется на `20`.

В Go арифметическое действие и присваивание можно записать одним коротким оператором:

| Короткая запись | Полная запись   |
| --------------- | --------------- |
| `num += 5`      | `num = num + 5` |
| `num -= 5`      | `num = num - 5` |
| `num *= 5`      | `num = num * 5` |
| `num /= 5`      | `num = num / 5` |
| `num %= 5`      | `num = num % 5` |

Например:

```go
package main

import "fmt"

func main() {
    balance := 100
    balance += 50
    balance -= 20

    fmt.Println("Баланс:", balance)
}
```

Результат:

```text
Баланс: 130
```

Разберём вычисление по шагам.

Начальное значение:

```text
balance = 100
```

Затем:

```go
balance += 50
```

на самом деле означает:

```go
balance = balance + 50
```

Результат:

```text
balance = 150
```

Затем:

```go
balance -= 20
```

равносильно:

```go
balance = balance - 20
```

Результат:

```text
balance = 130
```

Здесь важно помнить разницу между `:=` и `=`.

`:=` обычно используется, чтобы объявить новую локальную переменную и присвоить ей начальное значение.

`=` присваивает новое значение существующей переменной.

## Операторы сравнения

Операторы сравнения сравнивают два значения.

Результат сравнения всегда имеет тип `bool`:

```text
true
```

или:

```text
false
```

Основные операторы сравнения:

| Оператор | Значение          | Пример     | Результат |
| -------- | ----------------- | ---------- | --------- |
| `==`     | равно             | `10 == 10` | `true`    |
| `!=`     | не равно          | `10 != 3`  | `true`    |
| `>`      | больше            | `10 > 3`   | `true`    |
| `<`      | меньше            | `10 < 3`   | `false`   |
| `>=`     | больше или равно  | `10 >= 10` | `true`    |
| `<=`     | меньше или равно  | `3 <= 10`  | `true`    |

Например:

```go
package main

import "fmt"

func main() {
    age := 20
    minAge := 18

    fmt.Println("Равно:", age == minAge)
    fmt.Println("Не равно:", age != minAge)
    fmt.Println("Разрешено:", age >= minAge)
}
```

Результат:

```text
Равно: false
Не равно: true
Разрешено: true
```

Первое сравнение:

```go
age == minAge
```

выглядит так:

```text
20 == 18
```

Это неверно, поэтому результат:

```text
false
```

Второе сравнение:

```go
20 != 18
```

Это верно:

```text
true
```

Третье условие:

```go
20 >= 18
```

тоже верно. Значит, требование минимального возраста выполнено.

**Информация**

`=` и `==` — не один и тот же оператор.

````
`=` присваивает значение:

```go
age = 20
```

А `==` проверяет равенство:

```go
age == 20
```
````

## Логические операторы

Логические операторы работают со значениями `bool`.

Они используются, чтобы объединить несколько условий или получить противоположное условие.

| Оператор | Название | Когда результат `true`?                      |
| -------- | -------- | -------------------------------------------- |
| `&&`     | И        | когда оба условия `true`                     |
| `\|\|`   | ИЛИ      | когда хотя бы одно из условий `true`         |
| `!`      | НЕ       | когда операнд `false`                        |

**Информация**

Для значений `bool` сравнения порядка, например `<` или `>`, не используются.

```
Чтобы сравнить значения `bool` на равенство, можно использовать операторы `==` и `!=`.
```

Например:

```go
package main

import "fmt"

func main() {
    age := 22
    hasTicket := true
    banned := false

    canEnter := age >= 18 && hasTicket && !banned
    fmt.Println("Вход разрешён:", canEnter)
}
```

Результат:

```text
Вход разрешён: true
```

Разобьём это выражение на отдельные части:

```go
age >= 18
```

Результат:

```text
22 >= 18
true
```

Следующее значение:

```go
hasTicket
```

уже равно:

```text
true
```

Затем:

```go
!banned
```

Значение `banned`:

```text
false
```

Оператор `!` меняет его на противоположное:

```text
!false = true
```

Поэтому всё выражение становится:

```text
true && true && true
```

Результат:

```text
true
```

Значит, возраст пользователя достаточный, у него есть билет, и вход ему не запрещён.

**Таблица истинности:**

| `a`     | `b`     | `a && b` | `a \|\| b` |
| ------- | ------- | -------- | ---------- |
| `false` | `false` | `false`  | `false`    |
| `false` | `true`  | `false`  | `true`     |
| `true`  | `false` | `false`  | `true`     |
| `true`  | `true`  | `true`   | `true`     |

В операторе `&&` обе стороны должны быть `true`.

Например:

```text
true && false = false
```

А в операторе `||` достаточно, чтобы хотя бы одна сторона была `true`:

```text
true || false = true
```

Оператор `!` меняет значение на противоположное:

```text
!true  = false
!false = true
```

### Короткое замыкание

Операторы `&&` и `||` не всегда вычисляют все операнды.

Если результат уже известен, Go не проверяет оставшуюся часть выражения.

Это называется **коротким замыканием** (short-circuit evaluation).

Например:

```go
divisor := 0
safe := divisor != 0 && 10/divisor > 1
```

Разберём это выражение по шагам.

Первое условие:

```go
divisor != 0
```

Значение `divisor` равно `0`, поэтому:

```text
0 != 0
false
```

Чтобы результат `&&` был `true`, обе стороны должны быть `true`.

Первая сторона уже `false`.

Значит, общий результат точно будет `false`.

Поэтому Go не вычисляет вторую часть:

```go
10 / divisor > 1
```

Если бы эта часть выполнилась:

```go
10 / 0
```

произошло бы деление на ноль.

Но благодаря короткому замыканию это вычисление вообще не выполняется.

Для оператора `||` действует похожее правило.

Например:

```go
ready := true || expensiveCheck()
```

Поскольку первый операнд `true`, общий результат уже `true`.

Поэтому `expensiveCheck()` не вызывается.

## Побитовые операторы

Побитовые операторы работают с двоичным (binary) представлением целых чисел.

Например, число в десятичной системе:

```text
6
```

в двоичном виде:

```text
110
```

Побитовые операторы могут встречаться в таких задачах:

* хранение нескольких разрешений в одном значении;
* работа с битовыми флагами и масками;
* обработка протоколов или форматов файлов;
* низкоуровневые вычисления;
* включение или выключение определённых битов.

Основные побитовые операторы:

| Оператор | Действие                                                      |
| -------- | ------------------------------------------------------------- |
| `&`      | побитовое И                                                   |
| `\|`     | побитовое ИЛИ                                                 |
| `^`      | побитовое исключающее ИЛИ (XOR) или, унарно, инверсия битов   |
| `&^`     | сброс битов — AND NOT                                         |
| `<<`     | сдвиг влево                                                   |
| `>>`     | сдвиг вправо                                                  |

Пример:

```go
package main

import "fmt"

func main() {
    a := 6 // в двоичном виде: 110
    b := 3 // в двоичном виде: 011

    fmt.Println(a & b)  // 010, то есть 2
    fmt.Println(a | b)  // 111, то есть 7
    fmt.Println(a ^ b)  // 101, то есть 5
    fmt.Println(a << 1) // 1100, то есть 12
}
```

Результат:

```text
2
7
5
12
```

Теперь посмотрим, как получаются эти результаты.

`a`:

```text
6 = 110
```

`b`:

```text
3 = 011
```

Для удобства запишем их одинаковой длины:

```text
a = 110
b = 011
```

### `&` — побитовое И

```text
110
011
---
010
```

Проверяется каждая пара битов.

`1` в результате остаётся, только если оба бита равны `1`.

```text
1 & 0 = 0
1 & 1 = 1
0 & 1 = 0
```

Результат:

```text
010 = 2
```

### `|` — побитовое ИЛИ

```text
110
011
---
111
```

Если хотя бы один из битов равен `1`, бит результата равен `1`.

Результат:

```text
111 = 7
```

### `^` — XOR

В двухоперандном операторе `^` разные биты дают `1`, а одинаковые — `0`:

```text
110
011
---
101
```

Результат:

```text
101 = 5
```

Если `^` применить как унарный оператор к одному целому числу, он инвертирует все его биты. Результат при этом зависит от разрядности типа.

### `<<` — сдвиг влево

Следующее выражение:

```go
a << 1
```

сдвигает биты значения `a` на одну позицию влево.

Начальное значение:

```text
110
```

На один бит влево:

```text
1100
```

В десятичной системе это равно:

```text
12
```

Пока достаточно понять основное назначение этих операторов. В следующих примерах мы увидим их практическое применение с битовыми флагами.

## Приоритет операторов

Если в одном выражении участвует несколько операторов, Go выполняет их в определённом порядке приоритета.

Например:

```go
first := 2 + 3*4
```

Это выражение имеет вид:

```text
2 + 3 * 4
```

Приоритет оператора `*` выше, чем у `+`.

Поэтому сначала вычисляется:

```text
3 * 4 = 12
```

Затем:

```text
2 + 12 = 14
```

Результат:

```text
14
```

Если использовать скобки:

```go
second := (2 + 3) * 4
```

сначала выполняется выражение в скобках:

```text
2 + 3 = 5
```

Затем:

```text
5 * 4 = 20
```

Результат:

```text
20
```

Упрощённый порядок приоритета сверху вниз такой:

1. `*`, `/`, `%`, `<<`, `>>`, `&`, `&^`;
2. `+`, `-`, `|`, `^`;
3. `==`, `!=`, `<`, `<=`, `>`, `>=`;
4. `&&`;
5. `||`.

Операторы внутри одной группы имеют одинаковый приоритет.

Если выражение становится сложным, не обязательно полагаться только на приоритет операторов.

Скобки часто яснее показывают замысел кода.

Например:

```go
price - price*discount/100
```

технически может быть правильным.

Но запись:

```go
price - (price*discount)/100
```

яснее показывает читателю, как сгруппировано вычисление.

В следующей части мы выполним простые математические вычисления с помощью операторов.

## Примеры

### 1. Определение чётного или нечётного числа

Этот пример показывает проверку чётности числа с помощью оператора `%`.

```go
package main

import "fmt"

func main() {
    num := 17
    fmt.Println(num%2 == 0)
}
```

`num % 2` вычисляет остаток от деления числа на `2`.

Для `17`:

```text
17 % 2 = 1
```

Затем:

```go
num%2 == 0
```

на самом деле становится:

```text
1 == 0
```

Результат:

```text
false
```

Если число чётное, остаток от деления на `2` равен `0`.

Например:

```text
18 % 2 = 0
```

Поэтому `% 2 == 0` — распространённый способ проверить чётность числа.

### 2. Проверка значения в диапазоне

Этот пример проверяет, находится ли значение между двумя границами.

```go
package main

import "fmt"

func main() {
    age := 24
    workingAge := age >= 18 && age <= 60
    fmt.Println(workingAge)
}
```

Разделим выражение на две части:

```go
age >= 18
```

и:

```go
age <= 60
```

Значение `age` равно `24`.

Значит:

```text
24 >= 18 = true
24 <= 60 = true
```

Затем работает `&&`:

```text
true && true = true
```

Результат:

```text
true
```

Здесь используется `&&`, потому что возраст должен одновременно соответствовать обоим требованиям.

### 3. Последовательное обновление значения

В этом примере вместе используются короткие формы операторов присваивания и оператор `--`.

```go
package main

import "fmt"

func main() {
    num := 10
    num += 5
    num *= 2
    num--
    fmt.Println(num)
}
```

Начальное значение:

```text
num = 10
```

Первое действие:

```go
num += 5
```

равносильно:

```text
10 + 5 = 15
```

Теперь:

```text
num = 15
```

Затем:

```go
num *= 2
```

равносильно:

```text
15 * 2 = 30
```

Теперь:

```text
num = 30
```

В конце:

```go
num--
```

уменьшает значение на единицу:

```text
30 - 1 = 29
```

Результат:

```text
29
```

Этот пример показывает последовательное изменение значения несколькими действиями.

### 4. Короткое замыкание

Этот пример показывает, как свойство короткого замыкания оператора `&&` предотвращает деление на ноль.

```go
package main

import "fmt"

func main() {
    divisor := 0
    safe := divisor != 0 && 10/divisor > 1
    fmt.Println(safe)
}
```

Сначала проверяется:

```go
divisor != 0
```

Значение:

```text
divisor = 0
```

Поэтому:

```text
0 != 0 = false
```

Если левая сторона `&&` равна `false`, всё выражение тоже точно `false`.

Go не вычисляет правую сторону:

```go
10 / divisor > 1
```

Поэтому действие:

```text
10 / 0
```

не выполняется, и ошибки деления на ноль не возникает.

Результат:

```text
false
```

Этот приём часто используется, чтобы проверить нужное условие перед выполнением опасного действия.

### 5. Разбиение времени с помощью остатка

Этот пример с помощью операторов `/` и `%` разбивает общее количество секунд на часы, минуты и секунды.

```go
package main

import "fmt"

func main() {
    totalSeconds := 3672
    hours := totalSeconds / 3600
    minutes := totalSeconds % 3600 / 60
    seconds := totalSeconds % 60
    fmt.Println(hours, minutes, seconds)
}
```

Начальное значение:

```text
totalSeconds = 3672
```

Сначала находим часы:

```go
hours := totalSeconds / 3600
```

Вычисление:

```text
3672 / 3600 = 1
```

Значит:

```text
hours = 1
```

Теперь находим, сколько секунд осталось после полных часов:

```text
3672 % 3600 = 72
```

Из этих `72` секунд находим минуты:

```text
72 / 60 = 1
```

Значит:

```text
minutes = 1
```

В конце находим секунды, оставшиеся после полных минут:

```text
3672 % 60 = 12
```

Значит:

```text
seconds = 12
```

Результат:

```text
1 1 12
```

То есть:

```text
1 час, 1 минута, 12 секунд
```

Здесь `/` берёт количество целых единиц, а `%` отделяет оставшуюся часть для следующего шага.

### 6. Включение флага с помощью битов

Этот пример показывает добавление нового разрешения к существующему значению с помощью битового флага.

```go
package main

import "fmt"

func main() {
    const write = 1 << 1
    perm := 1
    perm |= write
    fmt.Printf("%03b\n", perm)
}
```

Сначала вычисляется:

```go
const write = 1 << 1
```

Двоичный вид `1`:

```text
001
```

Сдвигаем его на один бит влево:

```text
001 << 1 = 010
```

Значит:

```text
write = 2
```

Затем:

```go
perm := 1
```

В двоичном виде:

```text
perm = 001
```

Следующий оператор:

```go
perm |= write
```

на самом деле означает:

```go
perm = perm | write
```

Вычисление:

```text
001
010
---
011
```

Результат:

```text
011
```

`|` включает нужный бит и сохраняет остальные уже включённые биты.

Поэтому этот оператор очень удобен для добавления нового разрешения в набор битовых флагов.

### 7. Проверка флага с помощью битов

Этот пример проверяет, включён ли определённый бит.

```go
package main

import "fmt"

func main() {
    const write = 1 << 1
    perm := 0b011
    fmt.Println(perm&write != 0)
}
```

Значение `write`:

```text
010
```

А `perm`:

```text
011
```

Теперь применяем оператор `&`:

```text
011
010
---
010
```

Результат не `0`:

```text
010 != 000
```

Поэтому выводится:

```text
true
```

Смысл этой проверки: включён ли бит `write` в значении `perm`?

`&` оставляет только те биты, которые равны `1` в обоих значениях.

Если нужного бита нет, результат будет `0`.

### 8. Выключение бита

В этом примере определённый флаг выключается с помощью оператора `&^`.

```go
package main

import "fmt"

func main() {
    const write = 1 << 1
    perm := 0b111
    perm &^= write
    fmt.Printf("%03b\n", perm)
}
```

Начальное значение:

```text
perm = 111
```

Флаг `write`:

```text
010
```

Следующая запись:

```go
perm &^= write
```

на самом деле означает:

```go
perm = perm &^ write
```

Оператор `&^` сбрасывает в левом операнде те биты, которые равны `1` в правом операнде.

Поэтому:

```text
111
010
---
101
```

Результат:

```text
101
```

То есть средний бит выключен, а остальные биты остались без изменений.

### 9. Обмен значениями с помощью исключающего ИЛИ

Этот пример показывает, что с помощью оператора `^` можно поменять местами значения двух целых чисел без временной переменной.

```go
package main

import "fmt"

func main() {
    a, b := 5, 9
    a ^= b
    b ^= a
    a ^= b
    fmt.Println(a, b)
}
```

В начале:

```text
a = 5
b = 9
```

Первое действие:

```go
a ^= b
```

на самом деле означает:

```go
a = a ^ b
```

Следующие действия, используя свойство XOR, восстанавливают старые значения и меняют их местами.

В конце:

```text
a = 9
b = 5
```

Результат:

```text
9 5
```

Этот пример показывает интересное свойство оператора `^`.

Но в практическом коде на Go такой способ обычно не рекомендуется, потому что в Go есть гораздо более понятная запись:

```go
a, b = b, a
```

Этот вариант короче, легче читается и сразу показывает замысел кода.

### 10. Уточнение приоритета скобками

Этот пример демонстрирует приоритет операторов и то, как скобки делают замысел вычисления понятным.

```go
package main

import "fmt"

func main() {
    discounted := 100_000 - (100_000*15)/100
    fmt.Println(discounted)
}
```

Здесь начальная цена:

```text
100000
```

Скидка:

```text
15%
```

Сначала вычисляется размер скидки:

```text
100000 * 15 = 1500000
```

Затем:

```text
1500000 / 100 = 15000
```

Значит, размер скидки:

```text
15000
```

Вычитаем скидку из основной суммы:

```text
100000 - 15000 = 85000
```

Результат:

```text
85000
```

Скобки:

```go
(100_000 * 15)
```

яснее показывают, какую часть вычисления нужно рассматривать вместе.

А `_` в `100_000` только облегчает чтение числа.

Следующие две записи имеют одинаковое значение:

```go
100000
```

и:

```go
100_000
```

Подчёркивание `_` не влияет на значение числа. Оно облегчает чтение больших чисел, визуально группируя цифры.
