# Цикл for

Одинаково повторяющиеся процессы называются циклами. В программировании повторения используются очень часто, и для них
применяется оператор цикла `for`. Например, цикл нужен, чтобы вывести числа от `1` до `100` или вычислить сумму.

В Go для циклов есть только оператор `for`. Он выполняет роль `for`, `while` и бесконечного цикла из других языков.

## `for` из трёх частей

Самая распространённая форма:

```go
for init; condition; update {
	// повторяемый код
}
```

- `init` выполняется один раз перед началом цикла;
- `condition` проверяется перед каждой итерацией;
- `update` выполняется в конце каждой итерации.

> **Информация**
>
> **Итерация** — однократное выполнение тела цикла.

```go
package main

import "fmt"

func main() {
	for i := 0; i < 5; i++ {
		fmt.Println(i)
	}
}
```

**Результат:**

```text
0
1
2
3
4
```

Сначала один раз выполняется `i := 0`. Пока `i < 5` равно `true`, `i` выводится на экран. Затем `i++` увеличивает
значение на единицу, и условие проверяется снова. Когда `i` доходит до `5`, условие становится `false`, и цикл завершается.

К `i` можно обращаться только внутри блока `for`. Если написать `fmt.Println(i)` после цикла, возникнет ошибка
компиляции.

> **Информация**
>
> В Go `i++` используется только как отдельная инструкция. Нельзя написать `x := i++` или `if i++ > 2`.

## `for` с условием

Если вынести части инициализации и обновления наружу, `for` работает как `while` в других языках:

```go
package main

import "fmt"

func main() {
	i := 1
	for i <= 3 {
		fmt.Println(i)
		i++
	}
}
```

Результат:

```text
1
2
3
```

В этой форме `i` создаётся до цикла, поэтому её можно использовать и после него. Нужно не забыть увеличивать `i`:
если `i` не меняется, `i <= 3` всегда остаётся `true`, и цикл не заканчивается.

## Бесконечный цикл

Если условие не написано, цикл продолжается бесконечно:

```go
for {
	// процесс продолжается бесконечно
}
```

Бесконечный цикл нужен в серверах, воркерах и программах, обрабатывающих события. Им управляют не закрытием
терминала, а через `break`, `return` или условие отмены в логике программы.

> **Информация**
>
> Оператор `break` останавливает цикл.

```go
package main

import "fmt"

func main() {
	num := 1

	for {
		if num > 3 {
			break // срабатывает, когда num больше 3, и цикл здесь останавливается.
		}

		fmt.Println(num)
		num++
	}
}
```

Результат:

```text
1
2
3
```

Когда `num > 3`, `break` сразу завершает `for`. Оставшаяся часть тела цикла после `break` не выполняется.

## Пропуск итерации с помощью continue

`continue` нужен, чтобы пропустить оставшуюся часть текущей итерации цикла и перейти к следующей.
Следующая программа выводит только чётные числа:

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 10; i++ {
		if i%2 != 0 {
			continue
		}

		fmt.Println(i)
	}
}
```

Результат:

```text
2
4
6
8
10
```

`i%2` даёт остаток от деления числа на `2`. У нечётного числа остаток не равен нулю, и из-за `continue` `Println()` не
выполняется. В `for` из трёх частей после `continue` выполняется часть обновления, то есть `i++`.

Если нужны только чётные числа, результат можно получить, увеличив шаг цикла до двух:

```go
for i := 2; i <= 10; i += 2 {
	fmt.Println(i)
}
```

## Пример: сумма введённых чисел

Спросим у пользователя, сколько чисел он введёт, и вычислим их сумму:

```go
package main

import "fmt"

func main() {
	var count int

	fmt.Print("Введите количество чисел: ")
	_, err := fmt.Scan(&count)
	if err != nil {
		fmt.Println("Ошибка: введите целое число.")
		return
	}
	if count < 1 || count > 1000 {
		fmt.Println("Ошибка: количество должно быть от 1 до 1000.")
		return
	}

	sum := 0
	for i := 1; i <= count; i++ {
		var number int

		fmt.Printf("Введите число %d: ", i)
		_, err = fmt.Scan(&number)
		if err != nil {
			fmt.Println("Ошибка: все значения должны быть целыми числами.")
			return
		}

		sum += number
	}

	fmt.Println("Сумма:", sum)
}
```

Если ввести `3`, а затем `10`, `20` и `-5`:

```text
Введите количество чисел: 3
Введите число 1: 10
Введите число 2: 20
Введите число 3: -5
Сумма: 25
```

Поскольку `count` — внешнее значение, проверены и его тип, и допустимый диапазон. Цикл выполняется ровно `count`
раз. Каждое значение добавляется к сумме через `sum += number`. Верхняя граница для `count` не даёт запуститься
слишком долгому циклу.

> **Внимание**
>
> Сложение очень многих или очень больших значений `int` может привести к переполнению. Go не останавливает
> переполнение знаковых целых как ошибку во время выполнения. При работе с финансовыми или ненадёжными данными нужно проверять границы.

## Обход значений с помощью `range`

`range` используется для обхода (итерации) элементов строки, массива, среза, map и канала. В следующем примере со
строкой берутся каждый символ Unicode и байтовый индекс, с которого он начинается:

```go
package main

import "fmt"

func main() {
	word := "Go‘zal"

	for index, char := range word {
		fmt.Printf("index=%d char=%c\n", index, char)
	}
}
```

Результат:

```text
index=0 char=G
index=1 char=o
index=2 char=‘
index=5 char=z
index=6 char=a
index=7 char=l
```

Слово `Go‘zal` по-узбекски означает «красивый». Индексы идут как `0, 1, 2, 5...`, потому что символ `‘` в UTF-8
занимает три байта. Тип `char` — `rune`. Разницу между `byte` и `rune` мы глубже рассмотрим в следующем уроке.

Если одно из значений не нужно, используется пустой идентификатор `_`:

```go
for _, char := range word {
	fmt.Printf("%c ", char)
}
```

Если нужен только индекс, второе значение писать не обязательно:

```go
for index := range word {
	fmt.Println(index)
}
```

## Вложенные циклы и `label break`

Внутри цикла можно написать другой цикл. Обычный `break` завершает только текущий цикл. Если нужно завершить и
внешний цикл, используется метка (label):

```go
package main

import "fmt"

func main() {
outer:
	for row := 1; row <= 3; row++ {
		for column := 1; column <= 3; column++ {
			if row == 2 && column == 2 {
				break outer
			}
			fmt.Println(row, column)
		}
	}
}
```

Результат:

```text
1 1
1 2
1 3
2 1
```

`break outer` завершает внешний цикл, отмеченный меткой `outer:`. Метки полезны при глубоко вложенном управлении, но
если их много, код становится труднее понимать.

## Распространённые ошибки

### Граница, сдвинутая на единицу

`i < 10` не включает `10`, а `i <= 10` включает. Это называется ошибкой на единицу (off-by-one). Важно проверять
случаи первого и последнего элемента и пустого диапазона.

### Ненужный бесконечный цикл

Если в `for` с условием не обновляется значение, влияющее на условие, цикл не заканчивается. Даже если бесконечный
цикл написан намеренно, в нём должна быть логика для его остановки.

### Путаница между `break` и `continue`

`break` полностью завершает цикл. `continue` пропускает только оставшуюся часть текущей итерации. Какой из них
нужен, определяет логика программы.

В следующих частях оператор цикла `for` снова будет использоваться при работе с типами данных `array`, `slice` и `map`.

## Примеры

### 1. Вывод чисел от `1` до `10`

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 10; i++ {
		fmt.Print(i, " ")
	}
	fmt.Println()
}
```

Начальное значение — `1`, а условие — `i <= 10`. Поэтому обе границы входят в результат.

### 2. Вывод чисел от `10` до `1`

```go
package main

import "fmt"

func main() {
	for i := 10; i >= 1; i-- {
		fmt.Print(i, " ")
	}
	fmt.Println()
}
```

На этот раз счётчик уменьшается на единицу через `i--`. Условие завершает цикл, когда `i` становится меньше `1`.

### 3. Сумма чисел от `1` до `10`

```go
package main

import "fmt"

func main() {
	sum := 0
	for i := 1; i <= 10; i++ {
		sum += i
	}
	fmt.Println(sum)
}
```

Результат — `55`. Начальное значение суммы — `0`, потому что прибавление нуля не меняет значения числа.

### 4. Произведение чисел от `1` до `10`

```go
package main

import "fmt"

func main() {
	product := 1
	for i := 1; i <= 10; i++ {
		product *= i
	}
	fmt.Println(product)
}
```

Результат — `3628800`. Произведение начинается с `1`, потому что умножение на `1` не меняет значения. Если начать с `0`, результат всегда оставался бы нулём.

### 5. Вывод чётных чисел

```go
package main

import "fmt"

func main() {
	for i := 2; i <= 20; i += 2 {
		fmt.Print(i, " ")
	}
	fmt.Println()
}
```

Счётчик увеличивается не на один, а на два. Поэтому цикл проходит только по чётным значениям.

### 6. Сумма цифр числа

```go
package main

import "fmt"

func main() {
	num := 5832
	sum := 0
	for num > 0 {
		sum += num % 10
		num /= 10
	}
	fmt.Println(sum)
}
```

`num % 10` берёт последнюю цифру, а `num /= 10` убирает эту цифру. Результат — `18`.

### 7. Запись числа в обратном порядке

```go
package main

import "fmt"

func main() {
	num := 1234
	reversed := 0
	for num > 0 {
		reversed = reversed*10 + num%10
		num /= 10
	}
	fmt.Println(reversed)
}
```

Каждая новая цифра добавляется в конец предыдущего результата. Результат — `4321`.

### 8. Вычисление факториала

```go
package main

import "fmt"

func main() {
	n := 6
	result := 1
	for i := 2; i <= n; i++ {
		result *= i
	}
	fmt.Println(result)
}
```

Результат `6!` равен `720`. Цикл начинается с `2`, потому что умножение на `1` не меняет результат.

### 9. Проверка простого числа

```go
package main

import "fmt"

func main() {
	num := 29
	prime := num >= 2
	for i := 2; i*i <= num && prime; i++ {
		if num%i == 0 {
			prime = false
		}
	}
	fmt.Println(prime)
}
```

Делители достаточно проверять до квадратного корня из числа. Когда делитель найден, `prime` становится `false`, и цикл останавливается.

### 10. Последовательность Фибоначчи

```go
package main

import "fmt"

func main() {
	a, b := 0, 1
	for i := 0; i < 10; i++ {
		fmt.Print(a, " ")
		a, b = b, a+b
	}
	fmt.Println()
}
```

Каждое новое значение получается из суммы двух предыдущих. Одновременное присваивание обновляет `a` и `b`, не теряя их старых значений.

### 11. Таблица умножения

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 3; i++ {
		for j := 1; j <= 5; j++ {
			fmt.Printf("%d × %d = %d\n", i, j, i*j)
		}
	}
}
```

Внешний цикл управляет первым числом, внутренний — вторым. Для каждого `i` значение `j` снова начинается с `1`.

### 12. Пропуск ненужных значений через `continue`

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 20; i++ {
		if i%3 != 0 {
			continue
		}
		fmt.Print(i, " ")
	}
	fmt.Println()
}
```

Для значений, не делящихся на `3`, `continue` пропускает оставшиеся инструкции. В результате выводятся только числа, кратные `3`.
