# Тип данных `map` в Go

`map` хранит данные в виде пар «ключ — значение». В `Slice` и `Array` мы обращаемся к элементам по индексам вроде
`0`, `1`, `2`. А в `map` к значению обращаются по ключу, который мы задаём сами. Например, цену товара можно получить
по его названию, а пользователя — по его ID.

Все ключи в `map` должны быть одного типа. Для значений тоже задаётся один общий тип. Каждый ключ встречается только
один раз. Но под разными ключами может храниться одно и то же значение.

## Создание `map`

Тип `map` записывается как `map[ТипКлюча]ТипЗначения`. Например, в `map[string]int` ключ имеет тип `string`, а
значение — `int`. `map` можно создать с готовыми значениями или с помощью `make`:

```go
package main

import "fmt"

func main() {
	prices := map[string]int{
		"хлеб":   4_000,
		"молоко": 12_000,
		"рис":    18_000,
	}

	stock := make(map[string]int)
	stock["хлеб"] = 25

	fmt.Println("Цена молока:", prices["молоко"])
	fmt.Println("Хлеба на складе:", stock["хлеб"])
}
```

Результат:

```text
Цена молока: 12000
Хлеба на складе: 25
```

`prices` создана с готовыми парами «ключ — значение». Чтобы получить значение, ключ пишут в квадратных скобках:
`prices["молоко"]`.

А `make(map[string]int)` создаёт пустую `map`, в которую можно записывать значения. Затем строка
`stock["хлеб"] = 25` добавляет в неё новую пару.

`make` можно передать и примерное количество элементов: `make(map[string]int, 100)`. Это число не делает длину `map`
равной `100`. Оно даёт среде выполнения Go подсказку, чтобы заранее спланировать память. При создании `map` всё равно
пуста.

## `nil` и пустая `map`

Нулевое значение объявленной, но ещё не созданной `map` — `nil`:

```go
package main

import "fmt"

func main() {
	var nilMap map[string]int
	emptyMap := make(map[string]int)

	fmt.Println(len(nilMap), nilMap == nil)
	fmt.Println(len(emptyMap), emptyMap == nil)
	fmt.Println(nilMap["нет"])
}
```

Результат:

```text
0 true
0 false
0
```

`nilMap` и `emptyMap` обе пусты, поэтому их длина `0`. Разница в том, что `nilMap` ещё не создана для работы и равна
`nil`. А `emptyMap` создана через `make`, и в неё можно записывать значения.

Чтение значения из `nil`-map, получение её длины, обход через `range` и удаление ключа через `delete` безопасны. При
чтении отсутствующего ключа возвращается нулевое значение типа `int` (`0`).

Но записать значение в `nil`-map нельзя. Такая попытка приводит к ошибке `panic: assignment to entry in nil map`.
Перед записью значений `map` нужно создать **литералом** или через `make`.

## Проверка наличия ключа

При обращении к отсутствующему ключу возвращается нулевое значение типа. Например, для `map[string]int` это значение
`0`. Но по результату `0` нельзя понять, есть ключ или нет, потому что `0` может быть и значением, сохранённым в `map`.

Чтобы различить эти два случая, используется форма «запятая, ok» (`comma ok`):

```go
package main

import "fmt"

func main() {
	scores := map[string]int{"Али": 0}

	score, ok := scores["Али"]
	fmt.Println("Али:", score, ok)

	score, ok = scores["Вали"]
	fmt.Println("Вали:", score, ok)
}
```

Результат:

```text
Али: 0 true
Вали: 0 false
```

Переменная `score` получает значение, а `ok` равна `true`, если ключ есть, и `false`, если его нет. В примере ключ
`Али` есть, и его значение `0`. Ключа `Вали` нет, поэтому, хотя значение в обоих случаях `0`, результат `ok` разный.

> **Запомните**
>
> Если само значение не нужно, его можно отбросить через `_`: `_, ok := scores["Али"]`. Тогда проверяется только
> наличие ключа, а значение переменной игнорируется. Игнорирование через `_` также предотвращает ошибку компиляции в
> **Go**, ведь программа, в которой переменная объявлена, но не используется, не компилируется.

## Обновление и удаление значения

Присваивание значения новому ключу добавляет элемент в `map`. Присваивание существующему ключу заменяет его старое
значение. Для удаления элемента используется `delete(имяMap, ключ)`. `delete` не выдаёт ошибку, даже если ключа нет.

```go
package main

import "fmt"

func main() {
	user := map[string]string{"name": "Сардор", "city": "Ташкент"}
	user["name"] = "Элбек"
	delete(user, "city")

	fmt.Println(user["name"])
	_, ok := user["city"]
	fmt.Println("Город существует:", ok)
}
```

Результат:

```text
Элбек
Город существует: false
```

В примере значение `Сардор` ключа `name` заменено на `Элбек`. Ключ `city` удалён. Последующая проверка `value, ok`
показала, что его больше нет.

## Какие типы могут быть ключами?

Чтобы найти нужное значение, `map` сравнивает ключи. Поэтому тип ключа должен быть сравнимым операторами `==` и `!=`.

Ключами могут быть числа, `string`, `bool`, указатели и каналы. Также ключами используются массивы из сравнимых
элементов и struct, все поля которых сравнимы. `slice`, `map` и функции несравнимы, поэтому ключами быть не могут.

Технически ключом может быть и `float64`. Но значение `NaN` не равно даже самому себе. Поэтому с дробными числами в
качестве ключей нужно быть осторожным.

## `range` и порядок

На порядок хранения элементов `map` полагаться нельзя. При итерации `map` через `range` элементы при каждом запуске
программы могут идти в разном порядке.

Чтобы всегда получать результат в алфавитном порядке, ключи нужно отсортировать отдельно:

```go
package main

import (
	"fmt"
	"sort"
)

func main() {
	ages := map[string]int{"Али": 24, "Вали": 31, "Лола": 27}
	keys := make([]string, 0, len(ages))

	for name := range ages {
		keys = append(keys, name)
	}
	sort.Strings(keys)

	for _, name := range keys {
		fmt.Println(name, ages[name])
	}
}
```

Результат:

```text
Али 24
Вали 31
Лола 27
```

Сначала все ключи собраны в срез `keys`. `sort.Strings` отсортировал их в алфавитном порядке. Следующий цикл получил
значения из `map` по отсортированным ключам.

Этот способ можно использовать, когда тест, лог или список для пользователя всегда должен выводиться в одном и том же
порядке. Полагаться на порядок итерации `map` через `range` не всегда правильно.

## Присваивание, передача в функцию и параллельная работа

> **Запомните**
>
> Запись `b := a` не копирует элементы `map`. `a` и `b` ссылаются на одни и те же данные. Изменение через `b` влияет
> и на `a`. Если нужна полностью независимая копия, создайте новую `map` и скопируйте в неё каждую пару «ключ — значение».

> **Запомните**
>
> Одновременная запись в обычную `map` из нескольких `goroutine` небезопасна. Чтение, пока другая `goroutine`
> записывает, тоже опасно. В таком случае доступ к данным нужно согласовывать. Для этого используют `sync.Mutex`,
> `sync.RWMutex`, единоличное владение через `channel` или, если подходит задаче, `sync.Map`.
> Если несколько `goroutine` только читают и ни одна не меняет `map`, читать одновременно можно. Способы параллельной
> работы подробно рассматриваются в части про `concurrency`.

## Дополнительные примеры

### 1. Подсчёт частоты слов

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	counts := make(map[string]int)
	for _, word := range strings.Fields("go быстрый go простой go") {
		counts[word]++
	}
	fmt.Println(counts)
}
```

`strings.Fields` разбивает текст на отдельные слова. Каждое слово используется в map как ключ. Для отсутствующего
ключа возвращается нулевое значение типа `int` — `0`. Поэтому `counts[word]++` работает правильно, даже когда слово
встречается впервые. Слово `go` встречается три раза, поэтому его значение — `3`.

### 2. Группировка элементов

```go
package main

import "fmt"

func main() {
	numbers := []int{1, 2, 3, 4, 5, 6}
	groups := make(map[string][]int)
	for _, num := range numbers {
		key := "нечётные"
		if num%2 == 0 {
			key = "чётные"
		}
		groups[key] = append(groups[key], num)
	}
	fmt.Println(groups)
}
```

Типом значения `map` может быть и срез. Чётные числа добавляются в срез под ключом `"чётные"`, а нечётные — под ключом
`"нечётные"`. Для отсутствующего ключа возвращается `nil`-срез. Добавлять элементы в `nil`-срез через `append`
безопасно, поэтому создавать каждую группу заранее не нужно.

### 3. map в роли множества

```go
package main

import "fmt"

func main() {
	unique := make(map[string]bool)
	for _, name := range []string{"Али", "Вали", "Али"} {
		unique[name] = true
	}
	fmt.Println(len(unique))
}
```

Иногда нужно лишь знать, есть значение в множестве или нет. В Go нет отдельного типа множества (set), но эту задачу
может выполнять `map[string]bool`. Ключ обозначает элемент множества, а `true` — его наличие. При повторной записи
ключа `Али` новый элемент не добавляется. Поэтому результат `len` равен `2`.

### 4. Удаление повторов

```go
package main

import "fmt"

func main() {
	numbers := []int{3, 1, 3, 2, 1}
	seen := make(map[int]bool)
	result := make([]int, 0, len(numbers))
	for _, num := range numbers {
		if !seen[num] {
			seen[num] = true
			result = append(result, num)
		}
	}
	fmt.Println(result)
}
```

map `seen` хранит, встречалось ли число раньше. Если число встречается впервые, оно записывается в `seen` и
добавляется в `result`. При следующих встречах условие не выполняется. В результате получается `[3 1 2]`, и порядок
первого появления чисел сохраняется.

### 5. Независимая копия map

```go
package main

import "fmt"

func main() {
	original := map[string]int{"яблоко": 2, "гранат": 3}
	copied := make(map[string]int, len(original))
	for key, value := range original {
		copied[key] = value
	}
	copied["яблоко"] = 10
	fmt.Println(original["яблоко"], copied["яблоко"])
}
```

Цикл копирует каждую пару в новую `map`. Поэтому добавление ключа в `copied` или изменение значения `int` в ней не
влияет на `original`. Программа выводит `2 10`.

Здесь значения имеют тип `int`, поэтому простого копирования достаточно. Если тип значения ссылается на другие данные,
например срез, `map` или указатель, для полностью независимой копии нужно отдельно копировать и внутренние значения.

### 6. Вложенная map

```go
package main

import "fmt"

func main() {
	scores := make(map[string]map[string]int)
	scores["Али"] = make(map[string]int)
	scores["Али"]["Go"] = 95
	fmt.Println(scores["Али"]["Go"])
}
```

Каждое значение внешней `map` само является `map`. Прежде чем записывать значение во внутреннюю map `scores["Али"]`,
её нужно создать через `make`. Иначе программа попытается записать в `nil`-map, и произойдёт `panic`.

### 7. Массив в качестве ключа

```go
package main

import "fmt"

func main() {
	colors := map[[2]int]string{{2, 3}: "красный"}
	fmt.Println(colors[[2]int{2, 3}])
}
```

Массив из элементов `int` — сравнимый тип. Поэтому `[2]int` может объединить две координаты в один ключ `map`. В
примере для ключа `[2]int{2, 3}` берётся значение `красный`.

### 8. Вывод ключей по порядку

```go
package main

import (
	"fmt"
	"sort"
)

func main() {
	prices := map[string]int{"виноград": 20, "гранат": 15, "яблоко": 10}
	keys := make([]string, 0, len(prices))
	for key := range prices {
		keys = append(keys, key)
	}
	sort.Strings(keys)
	for _, key := range keys {
		fmt.Println(key, prices[key])
	}
}
```

Порядок обхода `map` не гарантируется. Сначала ключи собираются в срез, затем сортируются через `sort.Strings`.
Последний цикл выводит цены в порядке `виноград`, `гранат`, `яблоко`.

### 9. Сравнение значений двух map

```go
package main

import (
	"fmt"
	"maps"
)

func main() {
	a := map[string]int{"a": 1, "b": 2}
	b := map[string]int{"b": 2, "a": 1}
	fmt.Println(maps.Equal(a, b))
}
```

Значение `map` нельзя сравнить с другой `map` через `==`. Напрямую её можно сравнивать только с `nil`.

Если тип значений сравнимый, `maps.Equal` проверяет пары «ключ — значение» двух map. Порядок, в котором пары записаны
в коде, не важен. У `a` и `b` в примере одинаковые пары, поэтому результат — `true`.

### 10. Обновление, если ключ существует

```go
package main

import "fmt"

func main() {
	stock := map[string]int{"книга": 5}
	if count, ok := stock["книга"]; ok {
		stock["книга"] = count - 1
	} else {
		fmt.Println("Товар не найден")
	}
	fmt.Println(stock)
}
```

Запись `count, ok := stock["книга"]` внутри `if` объединяет получение значения и проверку наличия ключа. Если ключ
есть, количество книг уменьшается на единицу. Если ключа нет, выводится сообщение.
