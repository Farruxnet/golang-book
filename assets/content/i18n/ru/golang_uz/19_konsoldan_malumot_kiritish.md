# Ввод данных с консоли

В предыдущих частях значения, которые использует программа, мы писали прямо в коде. Но обычно программы просят
пользователя вручную ввести имя, число или другие данные.

В этой части мы научимся делать это в терминале и сохранять значение в переменную.

Для получения данных из терминала в пакете `fmt` есть функция `fmt.Scan()`. С её помощью можно считывать значения.

```go
package main

import "fmt"

func main() {
	var age int

	fmt.Print("Введите ваш возраст: ")
	if _, err := fmt.Scan(&age); err != nil {
		fmt.Println("Не удалось прочитать возраст:", err)
		return
	}

	fmt.Println("Вы ввели возраст:", age)
}
```

Запустите программу:

```bash
go run main.go
```

Когда в терминале появится запрос, напишите `25` и нажмите `Enter`:

Результат должен быть таким:

```text
Введите ваш возраст: 25
Вы ввели возраст: 25
```

> **Информация**
>
> `fmt.Print()` выводит текст, но не добавляет новую строку. Поэтому пользователь вводит значение рядом с запросом.
> А `fmt.Println()` добавил бы новую строку после вывода.

Теперь попробуем разобраться в программе выше:

`var age int` создаёт переменную и присваивает ей нулевое значение `0`. `fmt.Scan(&age)` читает значение из
терминала и записывает его в эту переменную. `Scan()` возвращает, сколько значений прочитано, и возможную ошибку.
В этом примере количество значений не нужно, поэтому использован `_`, а ошибка проверена через `err`. Если есть
ошибка, программа выводит причину и завершает работу через `return`.

Использованный здесь `if` при выполнении условия запускает код своего блока. Запись `err != nil` проверяет, есть ли
ошибка. Условные операторы и работа с ошибками подробно объяснялись в прошлых уроках.

`&age` — адрес переменной `age` в памяти. `Scan()` принимает в качестве значения адрес переменной в памяти.

> **Внимание**
>
> Пишется не `fmt.Scan(age)`, а `fmt.Scan(&age)`. Без `&` функция `Scan()` не может записать в переменную новое
> значение и возвращает ошибку.

> **Информация**
>
> Об адресах памяти можно прочитать в статье [> Компьютер и операционная система](https://farruxnet.uz/blog/2026/06/01/kompyuter-va-operatsion-tizim/) (на узбекском).
> Пока достаточно понимать `&` как указание **запиши значение по адресу, где находится эта переменная**. Адреса памяти и указатели
> подробно объясняются в отдельной части позже.

## Чтение нескольких значений

`Scan()` можно передать адреса нескольких переменных. В терминале значения разделяются пробелом или новой строкой:

```go
package main

import "fmt"

func main() {
	var width float64
	var height float64

	fmt.Print("Введите ширину и высоту прямоугольника: ")
	if _, err := fmt.Scan(&width, &height); err != nil {
		fmt.Println("Не удалось прочитать размеры:", err)
		return
	}
	area := width * height
	fmt.Printf("Площадь: %.2f\n", area)
}
```

**Результат:**

```text
Введите ширину и высоту прямоугольника: 5.5 3
Площадь: 16.50
```

**Значения можно вводить и на отдельных строках:**

```text
Введите ширину и высоту прямоугольника: 5.5
3
Площадь: 16.50
```

При чтении текста `fmt.Scan()` читает до пробела. То есть одно слово:

```go
package main

import "fmt"

func main() {
	var name string

	fmt.Print("Введите имя и фамилию: ")
	if _, err := fmt.Scan(&name); err != nil {
		fmt.Println("Не удалось прочитать имя:", err)
		return
	}

	fmt.Printf("Привет, %s!\n", name)
}
```

Результат:

```text
Введите имя и фамилию: Али
Привет, Али!
```

Если пользователь введёт `Али Валиев`, в `name` запишется только `Али`. Для целой строки нужно использовать другую
функцию.

Полное имя или длинный текст можно прочитать одной строкой с помощью `bufio.Reader`:

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Введите имя и фамилию: ")

	name, err := reader.ReadString('\n')
	if err != nil {
		fmt.Println("Не удалось прочитать имя:", err)
		return
	}
	name = strings.TrimSpace(name)

	fmt.Printf("Привет, %s!\n", name)
}
```

Результат:

```text
Введите имя и фамилию: Али Валиев
Привет, Али Валиев!
```

В этой программе:

- `os.Stdin` обозначает поток данных, приходящих из терминала;
- `bufio.NewReader()` создаёт средство чтения из этого потока;
- `ReadString('\n')` читает до символа новой строки, который приходит при нажатии `Enter`;
- `strings.TrimSpace()` удаляет пробелы и символ новой строки в начале и в конце текста.

> **Информация**
>
> `reader.ReadString('\n')` возвращает два значения: текст, введённый пользователем, и возможную ошибку при
> чтении. Текст сохраняется в `name`, а ошибка — в `err`. Если `err != nil`, программа выводит причину ошибки и
> завершает работу через `return`. Функции и работа с ошибками подробно изучались в предыдущих частях.

В следующем уроке мы рассмотрим программы командной строки, работающие с аргументами, стандартными потоками и
кодами завершения.

## Примеры

### 1. Чтение двух чисел из одной строки

```go
package main

import "fmt"

func main() {
	var a, b int
	fmt.Print("Введите два числа: ")
	if _, err := fmt.Scan(&a, &b); err != nil {
		fmt.Println("Не удалось прочитать числа:", err)
		return
	}
	fmt.Println("Сумма:", a+b)
}
```

`fmt.Scan()` читает значения, разделённые пробелом или новой строкой. `&a` и `&b` показывают, куда записать введённые значения.

### 2. Чтение дробного числа

```go
package main

import "fmt"

func main() {
	var price float64
	fmt.Print("Цена: ")
	if _, err := fmt.Scan(&price); err != nil {
		fmt.Println("Не удалось прочитать цену:", err)
		return
	}
	fmt.Printf("Цена: %.2f\n", price)
}
```

Для `float64` дробная часть отделяется точкой: `12.5`.

### 3. Чтение значения «да или нет»

```go
package main

import "fmt"

func main() {
	var active bool
	fmt.Print("Активен? (true/false): ")
	if _, err := fmt.Scan(&active); err != nil {
		fmt.Println("Не удалось прочитать значение:", err)
		return
	}
	fmt.Println(active)
}
```

Текст `true` или `false` читается прямо в переменную типа `bool`.

### 4. Указание источника ввода через `Fscan`

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	var num int
	fmt.Fscan(os.Stdin, &num)
	fmt.Println(num * num)
}
```

`Fscan()` принимает источник данных отдельным аргументом. Здесь источник — `os.Stdin`, обозначающий терминал.

### 5. Чтение целой строки

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Адрес: ")
	address, _ := reader.ReadString('\n')
	fmt.Println(strings.TrimSpace(address))
}
```

`ReadString()` сохраняет и текст с пробелами — до конца строки.

### 6. Чтение строки через `Scanner`

```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	scanner := bufio.NewScanner(os.Stdin)
	fmt.Print("Комментарий: ")
	scanner.Scan()
	fmt.Println("Принято:", scanner.Text())
}
```

`Scanner.Text()` не включает символ `\n` в конце строки.

### 7. Чтение первого символа Unicode

```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Один символ: ")
	char, size, _ := reader.ReadRune()
	fmt.Printf("Символ: %c, размер в UTF-8: %d байт\n", char, size)
}
```

`ReadRune()` читает один символ Unicode. Второй результат показывает, сколько байтов этот символ занимает в кодировке UTF-8.

### 8. Чтение одной строки через `Scanln`

```go
package main

import "fmt"

func main() {
	var firstName, lastName string
	fmt.Print("Имя и фамилия: ")
	fmt.Scanln(&firstName, &lastName)
	fmt.Println("Привет,", firstName, lastName)
}
```

`Scanln()` читает значения только до конца текущей строки. В этом примере имя и фамилия записываются в отдельные переменные.

### 9. Чтение чисел, разделённых запятой

```go
package main

import "fmt"

func main() {
	var a, b int
	fmt.Print("a,b: ")
	fmt.Scanf("%d,%d", &a, &b)
	fmt.Println(a + b)
}
```

`Scanf()` позволяет задать формат ввода. В этом примере запятая — обязательный разделитель.

### 10. Проверка количества введённых значений

```go
package main

import "fmt"

func main() {
	var width, height int
	n, err := fmt.Scan(&width, &height)
	fmt.Println("Прочитано значений:", n)
	fmt.Println("Ошибка:", err)
	fmt.Println("Площадь:", width*height)
}
```

`Scan()` возвращает также количество успешно прочитанных значений и возникшую ошибку. В примерах выше мы проверяли эти результаты с помощью `if`.
