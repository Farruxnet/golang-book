# switch: выбор одного из нескольких вариантов

`switch` выбирает один из нескольких путей в зависимости от значения или условия. Например, можно найти название дня
по его номеру, пояснить код состояния HTTP или выполнить действие, соответствующее роли пользователя.

`if` и `else if` из прошлого урока тоже используются для выбора. Однако когда одно значение сравнивается со многими
вариантами, `switch` обычно компактнее и легче читается.

## Основной синтаксис

```go
switch expression {
case value1:
	// выполняется, если expression равно value1
case value2:
	// выполняется, если expression равно value2
default:
	// выполняется, если ни один case не подошёл
}
```

`switch` сначала вычисляет выражение. Затем сравнивает значения `case` сверху вниз. Выполняется блок первого подходящего
`case`, и `switch` завершается. Если ни один не подошёл, выполняется необязательный блок `default`.

> **Информация**
>
> В Go не нужно писать `break` в конце каждого `case`. После выполнения подходящего блока переход к следующему `case`
> автоматически не происходит. Эта особенность отличает Go от таких языков, как C, Java и JavaScript.

## Определение дня недели

```go
package main

import "fmt"

func main() {
	var day int

	fmt.Print("Введите номер дня недели (1-7): ")
	_, err := fmt.Scan(&day)
	if err != nil {
		fmt.Println("Ошибка: введите целое число.")
		return
	}

	switch day {
	case 1:
		fmt.Println("Понедельник")
	case 2:
		fmt.Println("Вторник")
	case 3:
		fmt.Println("Среда")
	case 4:
		fmt.Println("Четверг")
	case 5:
		fmt.Println("Пятница")
	case 6:
		fmt.Println("Суббота")
	case 7:
		fmt.Println("Воскресенье")
	default:
		fmt.Println("Ошибка: номер дня должен быть от 1 до 7.")
	}
}
```

Если ввести `5`:

```text
Введите номер дня недели (1-7): 5
Пятница
```

Значение `day` сравнивается с каждым `case`. `5` подходит только к `case 5`. Значения `0` или `8` не соответствуют ни
одному дню, поэтому `default` выводит сообщение об ошибке. Если ввести текст, ошибка, возвращённая `fmt.Scan()`,
попадает в переменную `err`, условный оператор `if` проверяет её и на этом останавливает работу.

## Несколько значений в одном `case`

Если для нескольких значений нужно выполнить одно и то же действие, значения можно записать в одном `case` через запятую:

```go
package main

import "fmt"

func main() {
	day := "суббота"

	switch day {
	case "суббота", "воскресенье":
		fmt.Println("Выходной день")
	case "понедельник", "вторник", "среда", "четверг", "пятница":
		fmt.Println("Рабочий день")
	default:
		fmt.Println("Неизвестный день")
	}
}
```

Результат:

```text
Выходной день
```

Запятая здесь означает **или**. Если значение `day` равно `"суббота"` или `"воскресенье"`, выполняется первый блок.
Значения должны иметь тип, сравнимый с `day`. Например, если switch работает со `string`, нельзя написать `case 1`,
то есть значение другого типа.

## `switch` без выражения

Выражение после `switch` можно не писать. Тогда он работает как `switch true`, и каждый `case` — логическое условие:

```go
package main

import "fmt"

func main() {
	temperature := 28

	switch {
	case temperature < -50 || temperature > 60:
		fmt.Println("Температура вне допустимого диапазона")
	case temperature < 0:
		fmt.Println("Холодно")
	case temperature < 20:
		fmt.Println("Прохладно")
	case temperature < 30:
		fmt.Println("Тепло")
	default:
		fmt.Println("Жарко")
	}
}
```

Результат:

```text
Тепло
```

Условия проверяются сверху вниз. Поскольку `28 < 30` — первое подходящее условие, выводится `Тепло`. Порядок важен!
Если написать `temperature < 30` раньше `temperature < 20`, то, например, `15` тоже подойдёт под это условие, и блок
`Прохладно` не выполнится.

`switch` без выражения может быть удобной для чтения заменой сложной цепочке `if`–`else if`. Его часто применяют для
диапазонов, валидации и взаимоисключающих условий.

## Короткое объявление в `switch`

Перед выражением `switch` можно написать короткую инструкцию. Инструкция и выражение разделяются точкой с запятой:

```go
package main

import "fmt"

func main() {
	name := "  Go  "

	switch length := len(name); length {
	case 0:
		fmt.Println("Текст пустой")
	case 1, 2, 3:
		fmt.Println("Короткий текст")
	default:
		fmt.Println("Длина текста:", length)
	}
}
```

Результат:

```text
Длина текста: 6
```

`length := len(name)` выполняется только один раз. Переменная `length` существует в блоках `case` и `default`, но не
видна за пределами `switch`. `len()` возвращает количество байтов.

## `break` и `fallthrough`

В обычном `switch` `break` не нужен. Но если блок нужно завершить раньше, его можно использовать:

```go
switch status {
case "ready":
	if cancelled {
		break
	}
	fmt.Println("Работа началась")
}
```

`break` завершает ближайший `switch` или `for`. В этом примере, если `cancelled` равно `true`, вывод не выполняется.

`fallthrough` выполняет следующий `case` после подходящего блока, не проверяя его условие:

```go
package main

import "fmt"

func main() {
	level := 3

	switch level {
	case 3:
		fmt.Println("Основные возможности")
		fallthrough
	case 2:
		fmt.Println("Дополнительные возможности")
		fallthrough
	case 1:
		fmt.Println("Начальные возможности")
	default:
		fmt.Println("Неизвестный уровень")
	}
}
```

Результат:

```text
Основные возможности
Дополнительные возможности
Начальные возможности
```

> **Внимание**
>
> `fallthrough` не проверяет условие следующего `case`. Поэтому его используют осторожно и редко.

> **Совет**
>
> `fallthrough` должен быть последней инструкцией в блоке. В последнем `case` он не используется.

## Какие значения можно сравнивать?

В обычном `switch` выражение и значения `case` должны быть сравнимы между собой. Могут работать числа, `string`,
`bool`, указатели, каналы, а также массивы и struct, состоящие только из сравнимых полей. Значения slice, map и функций
нельзя сравнивать обычным равенством, поэтому они не могут быть значениями `case`.

Значения `case` не обязаны быть константами, известными при компиляции. Можно использовать и выражения. Однако
повторение `case` с одинаковой константой приводит к ошибке компиляции:

```go
// Неправильно: у обоих case одинаковое значение.
switch num {
case 1:
	fmt.Println("один")
case 1:
	fmt.Println("ещё один")
}
```

> **Информация**
>
> `default` необязателен. Если его нет и ни один `case` не подошёл, `switch` ничего не выполняет. При проверке внешнего
> значения `default` часто полезен, чтобы не скрывать неизвестный случай.

В следующей части мы изучим цикл `for` — оператор повторения.

## Примеры

### 1. Проверка нескольких значений в одном `case`

```go
package main

import "fmt"

func main() {
	day := "суббота"
	switch day {
	case "суббота", "воскресенье":
		fmt.Println("Выходной день")
	default:
		fmt.Println("Рабочий день")
	}
}
```

Если подходит одно из значений, записанных через запятую, выполняется этот `case`.

### 2. Проверка диапазона через `switch` без выражения

```go
package main

import "fmt"

func main() {
	score := 86
	switch {
	case score >= 90:
		fmt.Println("A")
	case score >= 80:
		fmt.Println("B")
	case score >= 70:
		fmt.Println("C")
	default:
		fmt.Println("F")
	}
}
```

Если после `switch` не написано выражение, каждый `case` проверяется как логическое условие.

### 3. Начальное значение внутри `switch`

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	switch hour := time.Now().Hour(); {
	case hour < 12:
		fmt.Println("Доброе утро")
	case hour < 18:
		fmt.Println("Добрый день")
	default:
		fmt.Println("Добрый вечер")
	}
}
```

`hour` видна только внутри `switch`. Поскольку часть после точки с запятой пустая, работают условные `case`.

### 4. Определение времени года по названию месяца

```go
package main

import "fmt"

func main() {
	month := "апрель"
	switch month {
	case "декабрь", "январь", "февраль":
		fmt.Println("Зима")
	case "март", "апрель", "май":
		fmt.Println("Весна")
	case "июнь", "июль", "август":
		fmt.Println("Лето")
	case "сентябрь", "октябрь", "ноябрь":
		fmt.Println("Осень")
	default:
		fmt.Println("Неизвестный месяц")
	}
}
```

В одном `case` записаны несколько месяцев одного времени года. `default` отдельно сообщает о неправильном названии месяца.

### 5. Выбор действия калькулятора

```go
package main

import "fmt"

func main() {
	a, b := 12, 4
	op := "/"
	switch op {
	case "+":
		fmt.Println(a + b)
	case "-":
		fmt.Println(a - b)
	case "*":
		fmt.Println(a * b)
	case "/":
		fmt.Println(a / b)
	default:
		fmt.Println("Неизвестная операция")
	}
}
```

`switch` выбирает нужный оператор по знаку действия. В примере с делением заранее известно, что `b` не равно нулю.

### 6. Вычисляемые значения `case`

```go
package main

import "fmt"

func main() {
	a, b := 2, 3
	result := 6
	switch result {
	case a + b:
		fmt.Println("Сумма")
	case a * b:
		fmt.Println("Произведение")
	default:
		fmt.Println("Не подходит")
	}
}
```

Значение `case` может вычисляться и из переменных. Здесь `6` подходит ко второму `case`.

### 7. Раннее завершение `case` через `break`

```go
package main

import "fmt"

func main() {
	command, allowed := "delete", false
	switch command {
	case "delete":
		if !allowed {
			fmt.Println("Нет разрешения")
			break
		}
		fmt.Println("Удалено")
	default:
		fmt.Println("Неизвестная команда")
	}
}
```

Go выходит из каждого `case` автоматически. Если блок нужно завершить раньше во внутреннем условии, полезен `break`.

### 8. Классификация символа

```go
package main

import "fmt"

func main() {
	char := 'e'
	switch char {
	case 'a', 'e', 'i', 'o', 'u':
		fmt.Println("Гласная")
	default:
		fmt.Println("Согласная или другой символ")
	}
}
```

`switch` работает и со значениями `rune`.

### 9. Группировка кодов состояния HTTP

```go
package main

import "fmt"

func main() {
	code := 404
	switch code / 100 {
	case 2:
		fmt.Println("Успешно")
	case 4:
		fmt.Println("Ошибка клиента")
	case 5:
		fmt.Println("Ошибка сервера")
	default:
		fmt.Println("Другой ответ")
	}
}
```

Целочисленное деление выделяет разряд сотен кода и проверяет состояния одной группы вместе.

### 10. Продолжение общего действия через `fallthrough`

```go
package main

import "fmt"

func main() {
	role := "admin"
	switch role {
	case "admin":
		fmt.Println("Управлять настройками")
		fallthrough
	case "editor":
		fmt.Println("Редактировать статьи")
		fallthrough
	case "reader":
		fmt.Println("Читать статьи")
	}
}
```

Блоки после `admin` выполняются без условий. Для модели прав обычно понятнее явные условия; пример показывает поведение `fallthrough`.
