# Наша первая программа

В этом уроке мы напишем первую программу на Go, которая выводит информацию в терминал в виде текста.

На этом простом примере разберём несколько важных вещей:

* как устроена программа на Go;
* с какого места программа начинает работу;
* как использовать функцию из другого пакета;
* как `go run` запускает код;
* как компилятор проверяет код;
* как создаётся исполняемый файл.

Создайте на компьютере папку `first-program`. Если вы создали её в прошлом уроке, откройте её в редакторе кода.

Внутри папки создайте файл `main.go`.

Имя `main.go` не является обязательным требованием компилятора Go. Файл можно назвать, например, `hello.go`. Главное, чтобы у файла было расширение `.go`, а код внутри был написан правильно.

В этом уроке мы используем имя `main.go`, потому что оно очень часто встречается в небольших программах на Go.

**Внимание**

Некоторые операционные системы скрывают расширения файлов.

```
Поэтому проверьте, что файл случайно не стал `main.go.txt`. `main.go.txt` не является исходным файлом Go, потому что его настоящее расширение — `.txt`.
```

## Первая программа

Напишите в файле `main.go` следующий код:

```go
package main

import "fmt"

func main() {
	fmt.Println("Привет, мир!")
}
```

Сохраните файл.

Затем откройте терминал и перейдите в папку, где находится `main.go`. Запустите программу командой:

```bash
go run main.go
```

`go run` проверяет код Go, компилирует его и запускает получившуюся временную программу.

Если код правильный, в терминале появится результат:

```text
Привет, мир!
```

Этот результат выводится из-за следующей строки кода:

```go
fmt.Println("Привет, мир!")
```

`"Привет, мир!"` — значение, переданное функции `Println()`.

`Println()` записывает это значение в терминал. Затем автоматически добавляет ещё и символ новой строки.

Поэтому следующий вывод в терминале начинается с новой строки.

## Как работает код?

Теперь разберём программу строка за строкой.

### `package main`

Первая строка:

```go
package main
```

сообщает, к какому пакету относится файл Go.

**Пакет** (package) — способ объединить в одну группу файлы Go, относящиеся к одной задаче.

Например, если в одной папке несколько файлов `.go`, они обычно используют одно и то же имя пакета.

Здесь имя пакета:

```go
main
```

`main` — имя пакета с особым смыслом: оно используется для создания исполняемой программы.

В целом пакеты Go используются для двух видов задач:

* пакеты, которые предоставляют функции и типы для другого кода;
* пакет `main`, из которого получается программа, запускаемая напрямую.

Например, `fmt` предоставляет готовые функции для других программ. А пакет `main` используется для создания исполняемой программы.

Но одной строки:

```go
package main
```

недостаточно.

В запускаемой программе должна быть ещё и функция `main()`:

```go
func main() {
}
```

Эта функция не принимает параметров и не возвращает значений.

Значит, базовый вид исполняемой программы на Go такой:

```go
package main

func main() {
}
```

Если в пакете `main` нет нужной функции `main()`, у исполняемой программы не будет точки входа.

### `import "fmt"`

Следующая строка:

```go
import "fmt"
```

позволяет использовать готовый код из другого пакета.

`import` — способ подключить другой пакет, чтобы использовать его в текущем файле Go.

Здесь:

```go
"fmt"
```

— путь импорта пакета `fmt` из стандартной библиотеки Go.

Вместе с Go поставляется множество готовых пакетов. Все вместе они называются **стандартной библиотекой** (standard library).

Пакет `fmt` используется для таких задач:

* вывод значений в терминал;
* форматирование текста;
* вывод нескольких значений вместе;
* в некоторых случаях — чтение данных из терминала.

В этом уроке мы используем только функцию:

```go
fmt.Println()
```

В Go импортированный пакет обязательно должен использоваться.

Например, в коде:

```go
package main

import "fmt"

func main() {
}
```

`fmt` импортирован, но не используется.

В таком случае компилятор выдаёт ошибку.

Это одно из важных правил Go. Оно не даёт ненужным импортам накапливаться в коде.

### `func main()`

Следующая строка:

```go
func main() {
```

объявляет функцию с именем `main`.

`func` — ключевое слово, которое используется в Go для объявления функции.

Функции мы подробно изучим в следующих уроках. Пока можно представлять функцию как блок кода, выполняющий определённую задачу.

Здесь имя функции:

```text
main
```

Функция `main()` в пакете `main` — **точка входа** (entry point) исполняемой программы.

Проще говоря, когда программа запускается, основной код начинает выполняться именно с этой функции.

Среда выполнения Go (runtime) подготавливает запуск программы, а затем выполняет функцию `main.main`.

Следующие фигурные скобки:

```go
{
}
```

обозначают границы тела функции.

Например, в коде:

```go
func main() {
	fmt.Println("Привет, мир!")
}
```

строка:

```go
fmt.Println("Привет, мир!")
```

находится в теле функции `main()`.

В этом примере в функции только одно действие.

Действия в коде Go обычно выполняются сверху вниз.

Значит, ход этой программы можно упрощённо представить так:

```text
main() начинается
       ↓
выполняется fmt.Println(...)
       ↓
main() заканчивается
       ↓
программа завершается
```

Здесь есть ещё одно тонкое правило.

Когда функция `main()` заканчивается, завершается и вся программа. Если работают другие горутины, `main()` не ждёт их автоматически.

Горутины мы отдельно изучим в следующих уроках. Пока достаточно запомнить, что `main()` определяет основной жизненный цикл исполняемой программы на Go.

### `fmt.Println("Привет, мир!")`

Теперь рассмотрим основное действие:

```go
fmt.Println("Привет, мир!")
```

В этой строке мы вызываем функцию `Println()` из пакета `fmt`.

Точка:

```text
fmt.Println
   ^
```

означает, что мы обращаемся к имени внутри пакета слева.

Здесь:

* `fmt` — пакет;
* `Println` — функция внутри этого пакета.

Функции передано значение:

```go
"Привет, мир!"
```

Это значение типа **string**, то есть строка.

Строка — данные в виде текста.

Двойные кавычки:

```text
"Привет, мир!"
```

показывают, где строка начинается и где заканчивается.

Сами кавычки не выводятся.

Поэтому код:

```go
fmt.Println("Привет, мир!")
```

выводит:

```text
Привет, мир!
```

а не:

```text
"Привет, мир!"
```

Значение `"Привет, мир!"` передано функции `Println()` как **аргумент**.

Аргумент — значение, которое передаётся функции при её вызове.

Этот процесс можно упрощённо представить так:

```text
"Привет, мир!"
       ↓
fmt.Println(...)
       ↓
выводится в терминал
       ↓
добавляется новая строка
```

Часть `ln` в имени `Println()` можно запомнить как «line» (строка). Выведя значения, функция добавляет в конце новую строку.

Если новая строка не должна добавляться автоматически, можно использовать функцию `fmt.Print()`.

Например:

```go
fmt.Print("Привет, ")
fmt.Print("мир!")
```

Эти два вызова могут вывести текст в одну строку:

```text
Привет, мир!
```

Но пока на уроках удобнее будет `fmt.Println()`.

### Точка с запятой

Во многих языках программирования в конце команды ставится точка с запятой:

```text
;
```

В синтаксисе Go тоже есть понятие точки с запятой.

Но программисты на Go обычно не ставят `;` в конце каждой строки.

Например, мы пишем:

```go
fmt.Println("Привет")
fmt.Println("Мир")
```

а не:

```go
fmt.Println("Привет");
fmt.Println("Мир");
```

Причина в том, что лексер Go по правилам синтаксиса автоматически вставляет точку с запятой во многих местах.

Поэтому в повседневном коде на Go `;` почти не пишут.

Но это не значит, что «код можно переносить на новую строку где угодно».

Например, в некоторых случаях важно расположение фигурных скобок.

Обычная запись в Go:

```go
func main() {
	fmt.Println("Привет")
}
```

Перенос открывающей скобки `{` на другую строку может привести к ошибке компиляции.

Одна из причин — как раз правила автоматической вставки точки с запятой.

Поэтому важно писать код на Go в стандартном стиле и форматировать его с помощью `gofmt`.

## `go run`

Мы запустили программу командой:

```bash
go run main.go
```

Эта команда выполняет несколько этапов.

Рассмотрим процесс по шагам.

### 1. Файл читается

Сначала инструменты Go читают файл:

```text
main.go
```

### 2. Код проверяется

Компилятор проверяет правильность кода.

Например:

* правильный ли синтаксис;
* существуют ли использованные имена;
* правильны ли импорты;
* совместимы ли типы;
* правильно ли написаны объявления.

Если на этом этапе найдена ошибка, компиляция не продолжается.

### 3. Код компилируется

Код, прошедший проверку, компилируется в вид, который компьютер может выполнить.

### 4. Запускается временная программа

`go run` автоматически запускает получившуюся временную исполняемую программу.

Весь процесс:

```text
main.go
   ↓
проверка
   ↓
компиляция
   ↓
временная исполняемая программа
   ↓
запуск
   ↓
Привет, мир!
```

Если компиляция не удалась, функция `main()` вообще не запускается.

Здесь есть важное различие.

Например, если в терминале появилась запись:

```text
Привет, мир!
```

её выводит наша программа через:

```go
fmt.Println("Привет, мир!")
```

А если появилось сообщение о синтаксической ошибке, его выводит не наша программа, а компилятор Go или инструменты Go.

Значит:

```text
сообщение компиляции → приходит от инструментов Go

вывод программы      → приходит из написанного нами кода
```

Это различие позже станет очень важным при разборе ошибок.

## Создание исполняемого файла

`go run` удобен, чтобы быстро проверить код.

Но иногда программу нужно собрать как отдельный исполняемый файл.

Для этого используем `go build`:

```bash
go build -o hello main.go
```

Разберём команду по частям.

`go build`:

```bash
go build
```

компилирует код Go.

Параметр `-o`:

```bash
-o hello
```

задаёт имя получаемого исполняемого файла.

`main.go`:

```bash
main.go
```

— исходный файл для компиляции.

Значит, команда:

```bash
go build -o hello main.go
```

создаёт в текущей папке исполняемую программу `hello`.

В Windows файл обычно выглядит так:

```text
hello.exe
```

А в macOS и Linux может выглядеть так:

```text
hello
```

В macOS и Linux запустите программу так:

```bash
./hello
```

Здесь:

```text
./
```

означает, что нужно запустить файл из текущей папки.

В PowerShell используется команда:

```powershell
.\hello.exe
```

В обоих случаях программа даёт одинаковый результат:

```text
Привет, мир!
```

Главное различие между `go run` и `go build` можно запомнить так.

`go run`:

```text
код
 ↓
компиляция
 ↓
сразу запуск
```

Это удобно для уроков и быстрых экспериментов.

`go build`:

```text
код
 ↓
компиляция
 ↓
сохранение исполняемого файла
```

А это удобно, чтобы запускать программу позже.

Чтобы запустить готовую исполняемую программу на Go, на компьютере обычно не нужен установленный компилятор Go.

Причина в том, что компиляция уже выполнена.

Здесь есть небольшое уточнение: исполняемый файл, собранный для другой операционной системы или архитектуры процессора, может не работать в текущей системе. Например, исполняемый файл для Linux обычно не запускается напрямую в Windows.

## Комментарии

**Комментарий** (comment) — текст, который пишут, чтобы дать дополнительное пояснение человеку, читающему код.

Например, комментарием можно объяснить:

* что делает код;
* почему он написан именно так;
* причину сложного решения;
* что нужно будет изменить позже.

Компилятор не выполняет комментарий как действие программы.

### Однострочный комментарий

Однострочный комментарий начинается с:

```text
//
```

Например:

```go
// Выводит на экран "Привет, мир!".
fmt.Println("Привет, мир!")
```

Первая строка — комментарий:

```go
// Выводит на экран "Привет, мир!".
```

Она не выполняется.

Следующая строка — обычный код Go:

```go
fmt.Println("Привет, мир!")
```

и она выполняется.

Всё, что находится от знака `//` до конца строки, считается комментарием.

Комментарий можно написать и после кода:

```go
fmt.Println("Привет") // выводит текст в терминал
```

Но комментариев не должно быть слишком много. Если код понятен сам по себе, комментировать каждую простую строку не нужно.

### Многострочный комментарий

Многострочный комментарий начинается с:

```text
/*
```

и заканчивается:

```text
*/
```

Например:

```go
/*
Этот комментарий
может занимать несколько строк.
*/
```

Текст между `/*` и `*/` компилятор не выполняет как действие программы.

В коде на Go для повседневных комментариев обычно чаще используют `//`.

Особенно широко `//` применяется в документирующих комментариях к пакетам, функциям, типам и другим объявлениям.

## Частые ошибки

Хотя первая программа очень маленькая, в ней есть несколько ошибок, которые часто допускают новички.

### Путаница с регистром букв

Следующий вызов неправильный:

```go
// fmt.println("Привет, мир!") // ошибка: в пакете fmt нет println
```

Go различает заглавные и строчные буквы.

Значит:

```text
Println
```

и:

```text
println
```

— не одно и то же имя.

Правильная функция, которая нам нужна:

```go
fmt.Println
```

И в реальных проектах разница в одну букву в имени пакета, функции, переменной или типа означает обращение к совсем другому имени.

Если такого имени нет, компилятор выдаёт ошибку.

### Незакрытая кавычка или скобка

Следующий код неправильный:

```go
fmt.Println("Привет, мир!) // ошибка: нет закрывающей кавычки
```

Если строка началась с:

```text
"
```

в нужном месте она должна закрыться ещё одной:

```text
"
```

Правильный вариант:

```go
fmt.Println("Привет, мир!")
```

То же правило относится к круглым и фигурным скобкам.

Например, в коде:

```go
fmt.Println("Привет"
```

не хватает закрывающей:

```text
)
```

А в следующем коде:

```go
func main() {
	fmt.Println("Привет")
```

не хватает закрывающей:

```text
}
```

Компилятор находит такие синтаксические проблемы и выводит сообщение об ошибке.

Иногда сообщение об ошибке появляется не на той строке, где ошибка началась, а на следующей. Причина в том, что компилятор может заметить неправильный синтаксис позже.

### Команда выполнена не в той папке

Если терминал находится не в той папке, где лежит `main.go`, команда:

```bash
go run main.go
```

может не найти файл.

В macOS и Linux текущую папку можно проверить командой:

```bash
pwd
```

Файлы в папке показывает:

```bash
ls
```

В PowerShell текущую папку можно проверить командой:

```powershell
Get-Location
```

А файлы показывает:

```powershell
Get-ChildItem
```

Например, в папке должен быть виден файл:

```text
main.go
```

Если файл в другой папке, сначала перейдите в неё в терминале.

### Забытые `package main` или `main()`

В исполняемой программе на Go должен быть пакет:

```go
package main
```

Кроме того, в этом пакете должна быть функция:

```go
func main() {
}
```

Например, в следующем коде нет `main()`:

```go
package main

import "fmt"

func hello() {
	fmt.Println("Привет")
}
```

`hello()` — обычная функция. Она не становится автоматически точкой начала программы.

Для исполняемой программы нужна `main.main`.

И наоборот: даже если `main()` есть, но пакет называется иначе, исполняемая программа `main` не получится.

Значит, нужны оба условия вместе:

```text
package main
+
func main()
```

## Форматирование кода программы

Чтобы привести код Go к стандартному стилю, используется `gofmt`.

Выполните в терминале команду:

```bash
gofmt -w main.go
```

`gofmt` приводит внешний вид кода к стандартам Go.

Например, он приводит к единому стилю:

* отступы;
* пробелы;
* расположение строк;
* некоторые синтаксические форматы.

Параметр `-w`:

```text
-w
```

означает, что отформатированный результат записывается в сам файл `main.go`.

Если код уже отформатирован правильно, видимых изменений может не быть.

Важный момент: `gofmt` не проверяет логику программы.

Например, следующий код правильный с точки зрения синтаксиса и форматирования:

```go
fmt.Println("Пока, мир!")
```

Но если задача — вывести `"Привет, мир!"`, это может быть логически неверным результатом.

`gofmt` это не исправит.

Запустите отформатированный файл ещё раз:

```bash
go run main.go
```

Результат снова тот же:

```text
Привет, мир!
```

Это естественно. Форматирование меняет внешний вид кода, а не его назначение или логику работы.

## Важные понятия

Хотя первая программа маленькая, в ней есть несколько основных понятий, которые снова и снова будут встречаться в следующих уроках.

* `package main` используется для создания исполняемой программы.
* `main()` — основная точка входа исполняемой программы на Go.
* `import` позволяет использовать код из другого пакета.
* `fmt.Println()` выводит значение в терминал и добавляет в конце новую строку.
* Go различает заглавные и строчные буквы.
* Импортированный пакет должен использоваться.
* `go run` компилирует код и сразу запускает временную программу.
* `go build` создаёт исполняемый файл и сохраняет его.
* `gofmt` приводит код к стандартному формату Go, но не исправляет логические ошибки.
* Нужно отличать сообщение компиляции от результата, который выводит программа.

В следующем уроке мы изучим переменные — они позволяют хранить значения под именем и использовать их повторно.
