# Переменные и константы

Переменная — область памяти, которая используется для хранения значения под именем. Во время работы программы значение переменной можно читать и при необходимости изменять.

Например, программе погоды может понадобиться хранить название города и температуру в нём. Вместо того чтобы просто писать эти значения по отдельности в разных местах кода, мы даём им понятные имена:

```text
city
temperature
```

Эти имена показывают, что означает значение внутри кода.

Например, человек, увидевший следующий код, может не сразу понять, что означает число `28`:

```go
fmt.Println(28)
```

Но если у значения есть имя, смысл становится яснее:

```go
temperature := 28
fmt.Println(temperature)
```

В этом и состоит главная задача переменных: хранить значение и обращаться к нему по понятному имени.

## Объявление переменной

Прежде чем использовать переменную, её нужно объявить.

Объявить — значит сообщить Go следующее:

* какое у переменной имя;
* значение какого типа она хранит;
* при необходимости — какое у неё начальное значение.

Например:

```go
var age int = 25
```

Разберём эту строку по частям:

* `var` — ключевое слово для объявления переменной;
* `age` — имя переменной;
* `int` — тип переменной;
* `25` — начальное значение.

`int` — один из типов для хранения целых чисел.

Значит, строка:

```go
var age int = 25
```

означает «создай переменную типа `int` с именем `age` и присвой ей значение `25`».

Полная программа выглядит так:

```go
package main

import "fmt"

func main() {
	var age int = 25
	var temperature float64 = 36.6

	fmt.Println("Возраст:", age)
	fmt.Println("Температура:", temperature)
}
```

Здесь две переменные:

```go
var age int = 25
```

и:

```go
var temperature float64 = 36.6
```

`age` имеет тип `int`.

А `temperature` — тип `float64`. `float64` часто используется для хранения чисел с дробной частью.

Результат:

```text
Возраст: 25
Температура: 36.6
```

Функции `fmt.Println()` можно передать несколько аргументов через запятую.

Например:

```go
fmt.Println("Возраст:", age)
```

Здесь передано два аргумента:

1. `"Возраст:"`
2. `age`

Выводя их в терминал, `Println()` ставит между ними подходящий пробел.

В одной строке можно передать и больше значений:

```go
package main

import "fmt"

func main() {
	var age int = 25
	var temperature float64 = 36.6

	fmt.Println("Возраст:", age, "Температура:", temperature)
}
```

Результат будет примерно таким:

```text
Возраст: 25 Температура: 36.6
```

## Изменение значения

Как следует из названия, значение переменной можно менять во время работы программы.

Например:

```go
var count int = 10
count = 15
fmt.Println(count)
```

Сначала:

```text
count = 10
```

Затем выполняется строка:

```go
count = 15
```

В результате вместо старого значения `10` сохраняется новое значение `15`.

В терминале появится:

```text
15
```

Здесь оператор `=` не создаёт новую переменную.

Он присваивает новое значение существующей переменной.

Например:

```go
var count int = 10
```

объявляет переменную.

А следующая строка:

```go
count = 15
```

обновляет значение уже существующей переменной `count`.

Новое значение должно соответствовать типу переменной.

Например:

```go
var age int = 25

// age = "двадцать пять"
```

Здесь `age` имеет тип `int`.

А `"двадцать пять"` — это `string`, то есть текстовое значение.

Значение `string` нельзя напрямую присвоить переменной типа `int`. Поэтому, если убрать комментарий, возникнет ошибка компиляции.

Go — статически типизированный язык. Это значит, что тип переменной известен на этапе компиляции и потом она не «превращается» в другой тип.

## Вывод типа

Не всегда нужно писать тип переменной вручную.

Если есть начальное значение, Go часто может определить тип по этому значению.

Например:

```go
var name = "Азиза"
var age = 24
var price = 19.5
```

Здесь Go делает такой вывод:

```text
name  → string
age   → int
price → float64
```

Этот процесс называется **выводом типа** (type inference) — автоматическим определением типа по значению.

Например, в строке:

```go
var name = "Азиза"
```

`string` отдельно не написан.

Но поскольку `"Азиза"` — строковое значение, Go определяет тип `name` как `string`.

Точно так же для:

```go
var age = 24
```

типом по умолчанию будет `int`.

Важно, что после того как тип определён, он не меняется.

Например:

```go
var age = 24

// age = "двадцать четыре"
```

в этом коде `age` сначала определена как `int`.

После этого ей нельзя присвоить значение типа `string`.

Вывод типа сокращает запись, но не отменяет проверку типов в Go.

## Короткое объявление: `:=`

Внутри функции есть короткий способ объявить переменную:

```go
name := "Азиза"
```

Этот синтаксис использует оператор `:=`.

Например:

```go
package main

import "fmt"

func main() {
	name := "Азиза"
	age := 24

	fmt.Println(name, age)
}
```

Здесь:

```go
name := "Азиза"
```

делает сразу две вещи:

1. объявляет новую переменную `name`;
2. присваивает ей начальное значение `"Азиза"`.

Сам тип Go определяет по значению.

Точно так же в строке:

```go
age := 24
```

`age` определяется как `int`.

`:=` используется только внутри функций.

Например, такая запись правильная:

```go
func main() {
	num := 10
	fmt.Println(num)
}
```

Но на уровне пакета синтаксис короткого объявления использовать нельзя.

На уровне пакета используется `var`:

```go
var num = 10
```

`=` и `:=` — не одно и то же.

Обратите внимание на следующий код:

```go
num := 10
num = 20
```

Первая строка:

```go
num := 10
```

создаёт новую переменную.

Вторая строка:

```go
num = 20
```

изменяет значение существующей переменной.

Это можно запомнить так:

```text
:=  → объявление + присваивание
=   → присваивание существующей переменной
```

Новичкам удобно внутри функций объявлять через `:=` переменные, начальное значение которых известно сразу.

Например:

```go
name := "Али"
age := 30
```

Если тип нужно явно указать заранее или значение присваивается позже, удобнее `var`:

```go
var age int
age = 30
```

## Переменная без начального значения

С помощью `var` переменную можно объявить и без начального значения:

```go
var num int
var text string
var active bool
```

Такие переменные не остаются «без значения» или в неизвестном состоянии.

Go даёт каждому типу стандартное начальное значение.

Оно называется **нулевым значением** (zero value).

Для основных типов:

| Тип           | Нулевое значение       |
| ------------- | ---------------------- |
| числовые типы | `0`                    |
| `string`      | `""` — пустая строка   |
| `bool`        | `false`                |

Например:

```go
package main

import "fmt"

func main() {
	var attempts int
	var message string
	var ready bool

	fmt.Printf("attempts=%d, message=%q, ready=%t\n", attempts, message, ready)
}
```

Результат:

```text
attempts=0, message="", ready=false
```

Здесь мы не присвоили начальное значение ни одной переменной.

Но Go автоматически присвоил значения:

```text
attempts → 0
message  → ""
ready    → false
```

Это важная особенность Go.

Если локальная переменная объявлена через `var`, она не получает случайное значение из памяти. Ей присваивается нулевое значение её типа.

В этом примере используется `fmt.Printf()`:

```go
fmt.Printf("attempts=%d, message=%q, ready=%t\n", attempts, message, ready)
```

`Printf()` выводит значения по заданному формату.

Здесь:

* `%d` — целое число;
* `%q` — вывод строки в кавычках;
* `%t` — значение типа `bool`;
* `\n` — символ новой строки.

Благодаря `%q` хорошо видна даже пустая строка:

```text
message=""
```

Иначе пустая строка в терминале была бы незаметна.

## Объявление нескольких переменных

В Go можно объявить несколько переменных в одной строке.

Например:

```go
var width, height int = 800, 600
```

Здесь:

```text
width  → 800
height → 600
```

обе переменные имеют тип `int`.

Значения присваиваются именам слева по порядку.

То есть:

```go
var width, height int = 800, 600
```

на практике равносильно:

```go
var width int = 800
var height int = 600
```

Внутри функции несколько переменных можно создать и коротким объявлением:

```go
name, city := "Али", "Самарканд"
```

Здесь:

```text
name → "Али"
city → "Самарканд"
```

Значения слева и справа сопоставляются по порядку.

Запись нескольких значений в одной строке может сделать код компактнее.

Но если объявление становится слишком длинным или трудным для понимания, лучше разбить его на отдельные строки:

```go
name := "Али"
city := "Самарканд"
```

Цель не только в том, чтобы писать меньше строк. Важно, чтобы код легко читался.

## Обращение к переменным

Переменную нельзя использовать в любом месте кода.

У каждой переменной есть **область видимости** (scope).

Область видимости определяет, из каких частей кода можно обращаться к переменной.

В Go блоки ограничиваются `{` и `}`.

Например:

```go
package main

import "fmt"

func main() {
	city := "Ташкент"

	if true {
		temperature := 28
		fmt.Println(city, temperature)
	}

	// fmt.Println(temperature)
}
```

Здесь:

```go
city := "Ташкент"
```

объявлена в блоке функции `main()`.

Поэтому `city` видна и во внутреннем блоке `if`:

```go
fmt.Println(city, temperature)
```

Но:

```go
temperature := 28
```

объявлена внутри блока `if`.

Поэтому она видна только в этом внутреннем блоке и во вложенных в него блоках.

После выхода из блока `if`:

```go
// fmt.Println(temperature)
```

не работает.

Если убрать комментарий, компилятор не найдёт в этом месте имя `temperature`.

Упрощённо это можно представить так:

```text
блок main
├── city видна
│
└── блок if
    ├── city видна
    └── temperature видна

после окончания if:
city видна
temperature не видна
```

В больших программах область видимости помогает не путать имена друг с другом.

## Именование переменных

Имя переменной должно как можно яснее показывать её назначение.

Например, по коду:

```go
x := 25
```

нельзя сразу понять, что означает `x`.

Если значение обозначает возраст:

```go
age := 25
```

гораздо понятнее.

Точно так же:

```go
price := 15000
numberOfUsers := 120
```

эти имена показывают смысл значений.

В реальных проектах идентификаторы обычно называют по-английски, и это часто рекомендуется. Особенно в международных командах так проще работать над кодом вместе с другими.

Например:

```go
userCount := 120
totalPrice := 50000
```

Основные синтаксические правила для имён переменных:

* имя может начинаться с буквы или `_`;
* в следующих символах можно использовать буквы и цифры;
* пробелы не используются;
* знак `-` не может быть обычной частью имени;
* ключевые слова Go, такие как `var`, `func`, `package`, нельзя использовать как имена;
* заглавные и строчные буквы различаются.

Например:

```text
age
Age
```

для Go это два разных имени.

Имена из нескольких слов обычно пишут в стиле camelCase:

```go
numberOfUsers
totalAmount
maximumSpeed
```

В реальном коде на Go чаще встречаются более короткие имена:

```go
userCount
totalPrice
maxSpeed
```

Не стоит без необходимости использовать слишком короткие или бессмысленные имена.

Но короткие имена вроде `i`, `j`, `x` могут быть нормальными в небольших локальных контекстах. Например, для индекса в коротком цикле `for` широко используется `i`.

Главное — чтобы имя не затрудняло понимание кода.

## Неиспользуемая переменная

Go считает ошибкой переменную, которая объявлена внутри функции, но не используется.

Например:

```go
func main() {
	age := 25
}
```

Здесь:

```go
age := 25
```

создаёт переменную.

Но `age` потом нигде не используется.

Такой код приводит к ошибке компиляции.

Например, переменную можно использовать:

```go
func main() {
	age := 25
	fmt.Println(age)
}
```

Или, если она вообще не нужна, её надо удалить.

Это правило помогает находить ненужные переменные, случайно оставшиеся в коде.

В этом смысле оно похоже на правило о неиспользуемых импортах.

Компилятор Go заставляет держать код относительно чистым.

## Константы: `const`

Некоторые значения не должны меняться во время работы программы.

Например:

* число часов в сутках;
* математический коэффициент;
* постоянный текст;
* неизменное значение конфигурации, известное при компиляции.

Для таких значений используется `const`.

**Константа** (constant) — именованное значение, которому потом нельзя присвоить новое значение.

Например:

```go
package main

import "fmt"

func main() {
	const hoursPerDay = 24
	const greeting string = "Привет"

	fmt.Println(greeting, hoursPerDay)
}
```

Здесь две константы:

```go
const hoursPerDay = 24
```

и:

```go
const greeting string = "Привет"
```

В первой тип отдельно не указан.

Во второй тип `string` указан явно.

Константе потом нельзя присвоить новое значение.

Например:

```go
const pi = 3.14

// pi = 3.1415
```

Если раскомментировать вторую строку, возникнет ошибка компиляции.

Причина в том, что `pi` — не переменная, а константа.

Главное различие между `var` и `const` можно запомнить так:

```text
var   → значение может измениться позже
const → значение нельзя переприсвоить
```

Константы Go могут содержать значения, известные при компиляции: числа, строки и `bool`.

Значение константы должно быть известно на этапе компиляции.

Например:

```go
const minute = 60
const hour = 60 * minute
```

Это правильно.

Компилятор может вычислить значение `hour`.

Но результат обычного вызова функции нельзя сделать константой.

Например:

```go
// const now = time.Now()
```

`time.Now()` вычисляет текущее время во время выполнения.

Это значение не известно заранее на этапе компиляции.

Поэтому оно не может быть значением `const`.

Представлять `const` как «просто переменную, которую нельзя изменить» не совсем верно.

Константы в Go — понятие времени компиляции, и у них свои правила для типов и выражений.

Если нужно создать последовательность константных значений, можно использовать `iota`.

Эта возможность отдельно объясняется в уроке про enum и iota.

В следующем уроке мы рассмотрим основные типы данных Go и операции над ними.

## Примеры

### 1. Обмен значениями за один раз

Этот пример показывает, что в Go можно поменять местами значения двух переменных, не создавая временную третью переменную.

```go
package main

import "fmt"

func main() {
	a, b := 10, 20

	a, b = b, a

	fmt.Println(a, b)
}
```

Сначала:

```text
a = 10
b = 20
```

Затем выполняется строка:

```go
a, b = b, a
```

Важно, что сначала берутся значения с правой стороны.

То есть Go сначала подготавливает значения:

```text
b → 20
a → 10
```

Затем они присваиваются левой стороне в соответствующем порядке:

```text
a ← 20
b ← 10
```

Результат:

```text
20 10
```

В других языках для такого обмена может понадобиться временная переменная:

```text
temp = a
a = b
b = temp
```

А в Go благодаря множественному присваиванию это можно сделать в одну строку.

### 2. Объявление нескольких переменных сразу

Этот пример показывает создание нескольких переменных одним оператором `:=`.

```go
package main

import "fmt"

func main() {
	name, age, active := "Али", 24, true

	fmt.Println(name, age, active)
}
```

Здесь создаются три новые переменные:

```text
name   → "Али"
age    → 24
active → true
```

Значения присваиваются именам слева по порядку.

Go определяет тип каждой переменной отдельно:

```text
name   → string
age    → int
active → bool
```

Значит, переменные в одном коротком объявлении не обязаны быть одного типа.

Результат:

```text
Али 24 true
```

Главное правило этого примера: `:=` может одновременно объявить несколько новых переменных.

### 3. Нулевое значение переменной

Этот пример показывает, какие значения получают переменные без начального значения.

```go
package main

import "fmt"

func main() {
	var num int
	var text string
	var active bool

	fmt.Printf("num=%d, text=%q, active=%t\n", num, text, active)
}
```

Мы не присвоили значения следующим переменным:

```go
var num int
var text string
var active bool
```

Go автоматически присваивает им нулевые значения.

По шагам:

```text
int    → 0
string → ""
bool   → false
```

Поэтому результат:

```text
num=0, text="", active=false
```

Главное правило этого примера: переменная, объявленная через `var`, не остаётся без начального значения. Она получает нулевое значение своего типа.

### 4. Обновление существующей переменной в коротком объявлении

`:=` не требует, чтобы все имена были новыми.

Если слева есть хотя бы одна новая переменная, вместе с ней можно использовать и существующую переменную из той же области видимости.

Например:

```go
package main

import "fmt"

func main() {
	num := 8

	num, square := num+1, num*num

	fmt.Println(num, square)
}
```

Первая строка:

```go
num := 8
```

создаёт `num`.

Затем переходим к строке:

```go
num, square := num+1, num*num
```

Слева:

* `num` — существующая переменная;
* `square` — новая переменная.

Поскольку есть новая `square`, можно использовать `:=`.

Важный момент: выражения справа вычисляются до выполнения присваивания.

Старое значение `num`:

```text
8
```

Поэтому:

```text
num + 1 = 8 + 1 = 9
num * num = 8 * 8 = 64
```

Затем значения записываются:

```text
num    ← 9
square ← 64
```

Результат:

```text
9 64
```

При вычислении `square` используется старое `num = 8`, а не новое `num = 9`.

Главное правило этого примера: при множественном присваивании выражения справа сначала вычисляются, а затем записываются в переменные слева.

### 5. Область видимости переменной

Этот пример показывает, что во внутреннем блоке можно создать новую переменную с тем же именем, что и внешняя.

```go
package main

import "fmt"

func main() {
	message := "внешняя"

	{
		message := "внутренняя"
		fmt.Println(message)
	}

	fmt.Println(message)
}
```

Сначала во внешнем блоке создаётся:

```go
message := "внешняя"
```

Затем открывается внутренний блок:

```go
{
	message := "внутренняя"
	fmt.Println(message)
}
```

Внутренняя строка:

```go
message := "внутренняя"
```

не изменяет внешнюю `message`.

Она создаёт для этого внутреннего блока другую, новую переменную.

Во внутреннем блоке используется `message` из ближайшей области видимости:

```text
внутренняя
```

Когда блок заканчивается, внутренняя `message` выходит из области видимости.

После этого снова видна внешняя:

```go
message := "внешняя"
```

Результат:

```text
внутренняя
внешняя
```

Такая ситуация называется **затенением** (shadowing).

Затенение иногда бывает полезным, но если оно происходит случайно, это может привести к ошибке. Программист может думать, что обновляет внешнюю переменную, а на самом деле создать новую внутреннюю.

### 6. Переменная уровня пакета

Переменную можно объявить не только внутри функции, но и на уровне пакета.

Например:

```go
package main

import "fmt"

var visits int

func main() {
	visits++
	visits++

	fmt.Println(visits)
}
```

Здесь:

```go
var visits int
```

находится вне какой-либо функции.

Она объявлена на уровне пакета.

Поскольку начальное значение не задано:

```text
visits = 0
```

Затем:

```go
visits++
```

увеличивает значение на единицу:

```text
0 → 1
```

После ещё одного выполнения:

```go
visits++
```

получается:

```text
1 → 2
```

Результат:

```text
2
```

Имя уровня пакета видно из функций этого пакета.

В этом примере функция `main()` может обращаться к `visits`.

Но чрезмерное использование изменяемых переменных уровня пакета может затруднить понимание и тестирование кода, потому что значение могут изменять сразу несколько функций.

### 7. Объявление с явным типом

Иногда значение переменной присваивается позже.

В этом случае тип можно указать заранее:

```go
package main

import "fmt"

func main() {
	var distance float64

	distance = 12

	fmt.Printf("%.1f км\n", distance)
}
```

Сначала объявляется:

```go
var distance float64
```

Поскольку начальное значение не задано, нулевое значение `float64`:

```text
0
```

Затем выполняется:

```go
distance = 12
```

Здесь `12` — нетипизированная целочисленная константа (untyped integer constant). Поскольку её значение можно представить в `float64`, при присваивании она приводится к переменной типа `float64`.

В результате значение в `distance` хранится как `float64`.

Запись в `Printf()`:

```text
%.1f
```

выводит число с одной цифрой после запятой.

Результат:

```text
12.0 км
```

Главное правило этого примера: если тип переменной задан при объявлении, последующие присваивания должны соответствовать этому типу.

### 8. Групповое объявление

Связанные переменные можно сгруппировать внутри блока `var`.

Например:

```go
package main

import "fmt"

func main() {
	var (
		product  = "книга"
		quantity = 3
		price    = 25000
	)

	fmt.Println(product, quantity*price)
}
```

Этот синтаксис:

```go
var (
	...
)
```

позволяет записать несколько объявлений `var` в одном блоке.

Значения:

```text
product  → "книга"
quantity → 3
price    → 25000
```

Затем вычисляется:

```go
quantity * price
```

```text
3 * 25000 = 75000
```

Результат:

```text
книга 75000
```

Групповое объявление может облегчить чтение, особенно когда нужно показать в одном месте настройки одной задачи или близкие друг к другу значения.

Но не обязательно собирать несвязанные переменные в один блок только ради краткости синтаксиса.

### 9. Вычисление константного выражения

Значение константы можно задать и выражением из других констант.

Например:

```go
package main

import "fmt"

const (
	second = 1
	minute = 60 * second
	hour   = 60 * minute
)

func main() {
	fmt.Println(hour)
}
```

Теперь по шагам посмотрим, как получаются значения.

Сначала:

```text
second = 1
```

Затем вычисляется:

```go
minute = 60 * second
```

```text
60 * 1 = 60
```

Значит:

```text
minute = 60
```

Затем вычисляется:

```go
hour = 60 * minute
```

```text
60 * 60 = 3600
```

Таким образом:

```text
hour = 3600
```

Результат:

```text
3600
```

Эти вычисления не нужно заново выполнять во время работы программы каждый раз. Поскольку выражения состоят из констант, их значения могут быть определены на этапе компиляции.

Такие именованные константы уменьшают необходимость писать прямо в коде числа с непонятным смыслом.

Например, вместо:

```go
timeout := 3600
```

в зависимости от контекста запись:

```go
timeout := hour
```

может яснее показать смысл кода.
