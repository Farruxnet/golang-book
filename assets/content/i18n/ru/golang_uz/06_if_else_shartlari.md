# Условные операторы if, else if и else в Go

Программа не всегда выполняет одни и те же команды. Иногда в зависимости от изменения значения ей нужно выбрать
один из вариантов логики. Например, разрешить вход в систему, если пользователь совершеннолетний, и отказать в противном случае.

Выполнение кода в разных направлениях в зависимости от условия называется ветвлением (branching). Ветвление
выполняется с помощью `if`, `else if` и `else`.

## Условие `if`

`if` проверяет заданное логическое выражение. Если выражение `true`, выполняется код между `{` и `}`. Если `false`,
эта часть пропускается.

```go
if booleanExpression {
	// Этот код выполняется, если условие true.
}
```

Например:

```go
package main

import "fmt"

func main() {
	temperature := 32
	isHot := temperature > 30 // считаем жарким, если выше 30
	if isHot {
		fmt.Println("Сегодня жарко.")
	}
}
```

**Результат:**

```text
Сегодня жарко.
```

Результат сравнения `temperature > 30` — `true`, поэтому сообщение выводится на экран. Если бы значение `temperature`
было `25`, блок `if` не выполнился бы.

> **Информация**
>
> В Go фигурные скобки в блоке `if` обязательны; их пишут, даже если в блоке всего одна команда.

## Условие должно быть типа `bool`

Выражение в `if` должно возвращать `bool`, то есть значение `true` или `false`:

```go
age := 20
if age >= 18 {
	fmt.Println("Совершеннолетний")
}
```

**Результат:**

```text
Совершеннолетний
```

В отличие от некоторых языков, Go не считает `0` значением `false`, а остальные числа — `true`:

```go
num := 1
// if num { } // ошибка компиляции: num не bool
```

## Проверка возраста пользователя

Получим возраст с консоли и выведем сообщение, если пользователю больше 18 лет:

```go
package main

import "fmt"

func main() {
	var age int

	fmt.Print("Введите ваш возраст: ")
	_, err := fmt.Scan(&age)
	if err != nil {
		fmt.Println("Ошибка: введите возраст целым числом.")
		return
	}

	if age > 18 {
		fmt.Println("Добро пожаловать!")
	}
}
```

Если ввести `19`:

```text
Введите ваш возраст: 19
Добро пожаловать!
```

Если ввести `18`, сообщение не появится. Причина в том, что выражение `18 > 18` равно `false`. Если возраст 18 тоже
допустим, нужно использовать оператор «больше или равно»:

```go
if age >= 18 {
	fmt.Println("Добро пожаловать!")
}
```

Важно точно выбирать границы значений:

- `age > 18` - только 19 и больше;
- `age >= 18` - 18 и больше;
- `age < 18` - значения меньше 18;
- `age <= 18` - 18 и меньше.

**Информация**

Как работает `_, err := fmt.Scan(&age)`?
***
`fmt.Scan(&age)` читает значение, введённое пользователем, и возвращает **два результата**:
1. сколько значений прочитано успешно;
2. ошибку, возникшую при чтении.
```go
_, err := fmt.Scan(&age)
```
Здесь:
- `_` — означает, что первый результат нам не нужен. В Go `_` называется **пустым идентификатором**. Он принимает значение, но не сохраняет его;
- `err` — хранит значение ошибки. Если пользователь введёт текст вместо возраста, в `err` будет ошибка;
- `:=` — создаёт переменную `err` и присваивает ей значение;
- `&age` — передаёт функции `fmt.Scan` адрес переменной `age` в памяти, чтобы введённое значение записалось в `age`.
Например, если пользователь введёт `25`, `fmt.Scan` вернёт примерно такие результаты:
```go
1, nil
```
Это значит, что `1` значение прочитано успешно и ошибки не было. Поскольку первый результат нам не нужен, мы игнорируем его с помощью `_`.
Если пользователь введёт `двадцать`, значение не подойдёт к типу `int`, и в `err` появится ошибка:
```go
if err != nil {
    fmt.Println("Ошибка: введите возраст целым числом.")
    return
}
```
В Go `nil` означает отсутствие ошибки. Если `err != nil`, значит, при чтении значения произошла ошибка.

## else — иначе

Если используется только `if`, при ложном условии никакой код не выполняется. Просто написать сообщение после блока `if`
тоже не решает проблему:

```go
if age >= 18 {
	fmt.Println("Добро пожаловать!")
}

fmt.Println("Нельзя!")
```

В этом коде `Нельзя!` выводится всегда. Если возраст `20`, появятся оба сообщения, потому что второй `Println()` не
находится ни в каком условии.

Чтобы выполнить ровно одно из двух направлений, используется `else`:

```go
if booleanExpression {
	// Выполняется, если условие true.
} else {
	// Выполняется, если условие false.
}
```

Дополним пример с возрастом через `else`:

```go
package main

import "fmt"

func main() {
	var age int

	fmt.Print("Введите ваш возраст: ")
	_, err := fmt.Scan(&age)
	if err != nil {
		fmt.Println("Ошибка: введите возраст целым числом.")
		return
	}

	if age >= 18 {
		fmt.Println("Добро пожаловать!")
	} else {
		fmt.Println("Нельзя!")
	}
}
```

Если ввести `15`:

```text
Введите ваш возраст: 15
Нельзя!
```

Если ввести `18`:

```text
Введите ваш возраст: 18
Добро пожаловать!
```

Выполняется только один из блоков `if` и `else`. Если условие `true`, работает `if`, иначе — `else`.

## else if — несколько условий

Иногда нужно выбрать не из двух, а из нескольких вариантов. `else if` последовательно проверяет дополнительные условия:

```go
if firstCondition {
	// Выполняется, если первое условие true.
} else if secondCondition {
	// Выполняется, если первое false, а второе true.
} else if thirdCondition {
	// Выполняется, если предыдущие false, а третье true.
} else {
	// Выполняется, если ни одно условие не true.
}
```

Go проверяет условия сверху вниз. После выполнения блока первого истинного условия остальные части `else if` и `else`
не проверяются.

```go
package main

import "fmt"

func main() {
	var age int

	fmt.Print("Введите ваш возраст: ")
	_, err := fmt.Scan(&age)
	if err != nil {
		fmt.Println("Ошибка: введите возраст целым числом.")
		return
	}

	if age >= 30 {
		fmt.Println("Вам 30 лет или больше.")
	} else if age >= 18 {
		fmt.Println("Добро пожаловать!")
	} else {
		fmt.Println("Нельзя!")
	}
}
```

Здесь диапазоны распределяются так:

|             Возраст | Выполняемый блок     |
|--------------------:|----------------------|
|        `30` и больше | `if age >= 30`      |
|        от `18` до `29` | `else if age >= 18` |
|       меньше `18` | `else`                 |

Во втором условии не нужно писать `age < 30`. Если программа дошла до этой строки, первое условие `age >= 30`
уже оказалось `false`.

## Порядок условий важен

Если более широкое условие записано раньше, следующее, более точное условие может не выполниться:

```go
if age >= 18 {
	fmt.Println("18 или больше")
} else if age >= 30 {
	fmt.Println("30 или больше")
}
```

В этом коде блок `age >= 30` никогда не выполнится. Например, `35` подходит под первое условие `age >= 18`, и
проверка на этом заканчивается.

Правильный порядок — сначала писать более точное условие или условие с верхней границей!

```go
if age >= 30 {
	fmt.Println("30 или больше")
} else if age >= 18 {
	fmt.Println("от 18 до 29")
}
```

## Объединение нескольких условий

С помощью операторов `&&`, `||` и `!` несколько проверок можно объединить в одно условие.

### `&&`: должны выполняться все условия

```go
package main

import "fmt"

func main() {
	age := 24
	hasTicket := true

	if age >= 18 && hasTicket {
		fmt.Println("Вы можете войти на мероприятие.")
	} else {
		fmt.Println("Для входа нужны подходящий возраст и билет.")
	}
}
```

При использовании `&&` оба условия должны быть `true`.

### `||`: достаточно одного условия

```go
isWeekend := true
onVacation := false

if isWeekend || onVacation {
	fmt.Println("Сегодня можно отдохнуть.")
}
```

При использовании `||` блок выполняется, если хотя бы одно условие `true`.

### `!`: отрицание значения

```go
blocked := false

if !blocked {
	fmt.Println("Пользователь активен.")
}
```

`!blocked` означает то же, что и `blocked == false`, но форма с отрицанием используется чаще, потому что она короче.

## Проверка диапазона значений

Проверка того, что число находится в определённом диапазоне, встречается очень часто. Например, балл за экзамен
должен быть от `0` до `100`:

```go
package main

import "fmt"

func main() {
	var score int

	fmt.Print("Введите результат: ")
	_, err := fmt.Scan(&score)
	if err != nil {
		fmt.Println("Ошибка: введите целое число.")
		return
	}

	if score < 0 || score > 100 {
		fmt.Println("Ошибка: результат должен быть от 0 до 100.")
	} else if score >= 86 {
		fmt.Println("Отлично")
	} else if score >= 71 {
		fmt.Println("Хорошо")
	} else if score >= 56 {
		fmt.Println("Удовлетворительно")
	} else {
		fmt.Println("Неудовлетворительно")
	}
}
```

Сначала проверен недопустимый диапазон. Затем оценки расположены сверху вниз. Например, `90` подходит под первое
условие оценки; `75` не проходит первое, но подходит под второе.

## Вложенный `if`

Внутри одного блока `if` можно написать другой `if`. Это называется вложенным условием (nested `if`):

```go
package main

import "fmt"

func main() {
	loggedIn := true
	admin := false

	if loggedIn {
		fmt.Println("Личная страница открыта.")

		if admin {
			fmt.Println("Панель управления открыта.")
		}
	} else {
		fmt.Println("Сначала войдите в систему.")
	}
}
```

Внутренний `if admin` проверяется, только когда внешнее условие `loggedIn` равно `true`.

Если вложенных блоков становится много, код труднее читать. Его можно упростить логическим оператором или
`return`.

## Короткое объявление в `if`

Go позволяет написать короткую инструкцию перед условием `if`. Инструкция и условие разделяются точкой с запятой:

```go
package main

import "fmt"

func main() {
	money := 3

	if balance := money; balance > 5 {
		fmt.Println("Средства:", balance)
	} else {
		fmt.Println("Недостаточно", balance)
	}
}
```

Сначала выполняется `balance := money;`, затем проверяется `balance > 5`.

Переменная, созданная в коротком объявлении, работает только в `if` и связанных с ним блоках `else if` и `else`:

```go
if num := 10; num > 0 {
	fmt.Println(num)
}

// fmt.Println(num) // здесь к num обратиться нельзя
```

Этот способ удобен, когда временный результат нужен только внутри условия. Например, его часто используют для
проверки `err`, возвращённого функцией.

## Граница области видимости

К переменной, объявленной внутри `if`, нельзя обратиться за пределами этого блока:

```go
age := 20

if age >= 18 {
	message := "Добро пожаловать"
	fmt.Println(message)
}

// fmt.Println(message) // ошибка компиляции
```

`message` существует только внутри блока `{}` оператора `if`. Если значение нужно и после блока, переменную нужно
объявить до `if`:

```go
message := "Нельзя"

if age >= 18 {
	message = "Добро пожаловать"
}

fmt.Println(message)
```

## Упрощение кода с помощью `return`

Если в начале проверить ошибочные случаи и сразу завершить функцию, вложенных условий становится меньше:

```go
package main

import "fmt"

func main() {
	var age int

	fmt.Print("Введите ваш возраст: ")
	_, err := fmt.Scan(&age)
	if err != nil {
		fmt.Println("Ошибка: введите целое число.")
		return
	}

	if age < 0 || age > 150 {
		fmt.Println("Ошибка: возраст должен быть от 0 до 150.")
		return
	}

	if age < 18 {
		fmt.Println("Нельзя!")
		return
	}

	fmt.Println("Добро пожаловать!")
}
```

После проверки каждого неправильного случая `return` завершает работу функции `main()`. Лишние `else` и
вложенные условия не нужны.

## Разница между `if` и `else if`

Если используется несколько `if`, может выполниться несколько блоков:

```go
num := 12

if num > 0 {
	fmt.Println("Положительное")
}

if num%2 == 0 {
	fmt.Println("Чётное")
}
```

В результате выводятся и `Положительное`, и `Чётное`. Потому что оба условия проверяются отдельно.

А в цепочке `if`–`else if`–`else` выполняется только первый подходящий блок:

```go
if num < 0 {
	fmt.Println("Отрицательное")
} else if num == 0 {
	fmt.Println("Ноль")
} else {
	fmt.Println("Положительное")
}
```

Отдельные `if` подходят, когда нужно одновременно проверить несколько разных условий, а `else if` — когда из
взаимоисключающих вариантов нужно выбрать один.

> **Внимание**
>
> Если не проверять результат `fmt.Scan(&)`, при вводе текста или неправильного формата программа может продолжить
> работу с ошибочным значением. Всегда проверяйте, что значение, пришедшее извне, имеет нужный тип и соответствует допустимым условиям.

В следующей части мы научимся использовать оператор `switch`, чтобы сравнивать одно значение с несколькими
конкретными вариантами.

## Примеры

### 1. Определение знака числа

```go
package main

import "fmt"

func main() {
	num := -7
	if num > 0 {
		fmt.Println("Положительное")
	} else if num < 0 {
		fmt.Println("Отрицательное")
	} else {
		fmt.Println("Ноль")
	}
}
```

Три случая взаимоисключающие, поэтому выполняется только один из них.

### 2. Проверка високосного года

```go
package main

import "fmt"

func main() {
	year := 2024
	leap := year%400 == 0 || year%4 == 0 && year%100 != 0
	if leap {
		fmt.Println("Високосный год")
	} else {
		fmt.Println("Обычный год")
	}
}
```

Год високосный, если он делится на `400` или делится на `4`, но не делится на `100`.

### 3. Нахождение наибольшего из трёх чисел

```go
package main

import "fmt"

func main() {
	a, b, c := 12, 27, 19
	largest := a
	if b > largest {
		largest = b
	}
	if c > largest {
		largest = c
	}
	fmt.Println(largest)
}
```

Каждый независимый `if` может обновить текущее наибольшее значение.

### 4. Проверка существования треугольника

```go
package main

import "fmt"

func main() {
	a, b, c := 3, 4, 5
	if a > 0 && b > 0 && c > 0 && a+b > c && a+c > b && b+c > a {
		fmt.Println("Треугольник существует")
	} else {
		fmt.Println("Треугольник не существует")
	}
}
```

Стороны должны быть положительными, а сумма любых двух сторон должна быть больше третьей.

### 5. Вложенная проверка

```go
package main

import "fmt"

func main() {
	login, password := "admin", "go123"
	if login == "admin" {
		if password == "go123" {
			fmt.Println("Вход выполнен успешно")
		} else {
			fmt.Println("Неверный пароль")
		}
	} else {
		fmt.Println("Пользователь не найден")
	}
}
```

Внутренний `if` проверяет пароль, только если логин правильный.

### 6. Объявление переменной в `if`

```go
package main

import "fmt"

func main() {
	if num := 42; num%2 == 0 {
		fmt.Println(num, "— чётное число")
	} else {
		fmt.Println(num, "— нечётное число")
	}
}
```

`num` объявляется в начальной части. Она видна только в этом `if` и его блоке `else`.

### 7. Значение по умолчанию для пустой строки

```go
package main

import "fmt"

func main() {
	name := ""
	if name == "" {
		name = "Гость"
	}
	fmt.Println("Привет,", name)
}
```

Для одного условного изменения писать `else` не обязательно.

### 8. Выбор уровня скидки

```go
package main

import "fmt"

func main() {
	purchase := 750_000
	discount := 0
	if purchase >= 1_000_000 {
		discount = 15
	} else if purchase >= 500_000 {
		discount = 10
	} else if purchase >= 100_000 {
		discount = 5
	}
	fmt.Println(discount, "%")
}
```

Проверка начинается с большей границы. Иначе меньшая граница сработала бы раньше.

### 9. Проверка перед делением на ноль

```go
package main

import "fmt"

func main() {
	num, divisor := 20, 0
	if divisor != 0 {
		fmt.Println("Результат:", num/divisor)
	} else {
		fmt.Println("Делить на ноль нельзя")
	}
}
```

Деление выполняется, только когда делитель не равен нулю. Эта проверка не даёт программе остановиться с ошибкой во время выполнения.

### 10. Приведение значения к диапазону

```go
package main

import "fmt"

func main() {
	volume := 120
	if volume < 0 {
		volume = 0
	} else if volume > 100 {
		volume = 100
	}
	fmt.Println(volume)
}
```

Результат — `100`. Этот способ не даёт внешнему значению выйти за допустимые границы.
