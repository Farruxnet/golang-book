# Основные типы данных в Go

Тип данных определяет, что представляет значение и какие операции с ним можно выполнять.

Например:

* `int` представляет целые числа;
* `string` — текст;
* `bool` — логическое состояние в виде `true` или `false`.

Представьте, что программе нужно хранить имя пользователя, его возраст и то, вошёл ли он в систему. У этих значений разное назначение. Поэтому и типы у них разные:

```go
package main

import "fmt"

func main() {
    name := "Али"      // string
    age := 25          // int
    loggedIn := true   // bool

    fmt.Println(name, age, loggedIn)
}
```

Результат:

```text
Али 25 true
```

Здесь:

* `name` — текст, поэтому его тип `string`;
* `age` — целое число, поэтому его тип `int`;
* `loggedIn` — состояние «да или нет», поэтому его тип `bool`.

Типы определяют не только то, как хранится значение, но и какие операции с ним можно выполнять.

Например, с `age` можно выполнять арифметические операции:

```go
age := 25
nextAge := age + 1
```

А `name` используется как текст:

```go
name := "Али"
message := "Привет, " + name
```

А значение типа `bool`, такое как `loggedIn`, удобно для проверки условия:

```go
if loggedIn {
    // пользователь вошёл в систему
}
```

## Зачем нужен тип данных?

Go — язык со статической типизацией. Это значит, что тип каждой переменной известен в момент компиляции кода.

Эта особенность помогает компилятору находить многие неправильные операции ещё до запуска программы.

Например, переменной, созданной для хранения целого числа, потом нельзя присвоить текстовое значение:

```go
var age int = 25

// age = "двадцать пять"
// значение string нельзя присвоить переменной int
```

Переменная `age` объявлена как `int`. Поэтому попытка присвоить ей значение типа `string`, например `"двадцать пять"`, приводит к ошибке компиляции.

Во многих случаях Go может и сам определить тип по начальному значению:

```go
name := "Али" // string
age := 25     // int
price := 19.5 // float64
```

Здесь мы не писали имена типов вручную. Но у переменных всё равно есть точные типы:

* `name` — `string`, потому что `"Али"` — текстовый литерал;
* `age` — `int`, потому что `25` — целочисленный литерал;
* `price` — `float64`, потому что `19.5` — литерал дробного числа.

Значит, использование `:=` не означает, что у переменной нет типа. Компилятор определяет тип по начальному значению.

Тип переменной можно увидеть с помощью спецификатора формата `%T`:

```go
package main

import "fmt"

func main() {
    value := 97
    fmt.Printf("Значение: %v, тип: %T\n", value, value)
}
```

Результат:

```text
Значение: 97, тип: int
```

Здесь:

* `%v` выводит значение в обычном виде;
* `%T` выводит тип значения в Go.

Этот способ особенно удобен, чтобы проверить, какой тип Go выбрал автоматически.

## Целые числа

У целых чисел нет дробной части.

Например:

```text
-12
0
25
```

В повседневных вычислениях чаще всего используется тип `int`:

```go
var age int = 25
var temperature int = -5
var studentCount = 30
```

В последней строке тип отдельно не указан:

```go
var studentCount = 30
```

Go определяет эту переменную как `int` по начальному значению.

Тип `int` имеет размер 32 или 64 бита в зависимости от архитектуры платформы. На практике для обычных вычислений, возраста, количества товаров, индексов и счётчиков обычно выбирают `int`.

### Знаковые числа точного размера

Иногда важно, сколько именно бит занимает тип. В таком случае можно использовать типы `int8`, `int16`, `int32` и `int64`.

Это **знаковые** (signed) типы. Поэтому вместе с положительными числами они могут хранить отрицательные числа и ноль.

| Тип     | Размер |                                         Диапазон значений |
| ------- | -----: | --------------------------------------------------------: |
| `int8`  | 8 бит  |                                            от -128 до 127 |
| `int16` | 16 бит |                                      от -32 768 до 32 767 |
| `int32` | 32 бит |                        от -2 147 483 648 до 2 147 483 647 |
| `int64` | 64 бит | от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 |

Например, `int8` может представить только 256 разных значений:

```text
-128 ... -1, 0, 1 ... 127
```

Поэтому значение `128` не помещается в диапазон `int8`.

### Беззнаковые целые числа

В Go есть и беззнаковые (unsigned) целочисленные типы.

Они не хранят отрицательные значения:

| Тип      | Размер |                  Диапазон значений |
| -------- | -----: | ---------------------------------: |
| `uint8`  | 8 бит  |                         от 0 до 255 |
| `uint16` | 16 бит |                      от 0 до 65 535 |
| `uint32` | 32 бит |               от 0 до 4 294 967 295 |
| `uint64` | 64 бит |  от 0 до 18 446 744 073 709 551 615 |

Например, для `uint8` диапазон такой:

```text
0 ... 255
```

Тип `uint`, как и `int`, имеет размер 32 или 64 бита в зависимости от архитектуры платформы.

В обычных вычислениях чаще удобнее `int`. Причина в том, что Go не смешивает разные числовые типы автоматически.

Например, значения `int` и `uint` нельзя сложить напрямую:

```go
var a int = 10
var b uint = 20

// total := a + b // ошибка компиляции
```

В таком случае один из типов нужно явно преобразовать.

**Внимание**

Выход за пределы диапазона значений, который может вместить тип, называется переполнением (`overflow`).

```
Если для числа выбран слишком маленький тип, значение может в нём не поместиться. Поэтому при выборе типа важно учитывать наибольшее и наименьшее возможное значение данных.
```

Например:

```go
package main

import "fmt"

func main() {
    var num int8 = 128
    fmt.Println(num)
}
```

Этот код не компилируется. Причина в том, что наибольшее значение для `int8` — `127`, а мы даём `128`.

Результат будет примерно таким:

```text
.\main.go:6:17: cannot use 128 (untyped int constant)
as int8 value in variable declaration (overflows)
```

Компилятор находит эту ошибку ещё до запуска программы.

Здесь `128` — константа, ещё не привязанная к конкретному целочисленному типу. Но когда её требуется поместить в переменную `int8`, компилятор проверяет диапазон значений и видит, что она не помещается.

## Дробные числа

Для чисел с дробной частью в Go используются типы `float32` и `float64`:

```go
var temperature float64 = 36.6
var distance float32 = 12.5
```

Одно из главных различий между ними — точность и объём памяти:

| Тип       | Размер | Примерная точность        |
| --------- | -----: | ------------------------: |
| `float32` | 32 бит |   6–7 десятичных цифр     |
| `float64` | 64 бит | 15–16 десятичных цифр     |

Определяя тип литерала дробного числа автоматически, Go обычно выбирает `float64`:

```go
price := 12.5
```

Здесь тип `price` — `float64`.

Поэтому в общих вычислениях `float64` встречается чаще.

Например:

```go
package main

import "fmt"

func main() {
    price := 12.5
    quantity := 3.0
    total := price * quantity

    fmt.Printf("Итого: %.2f\n", total)
}
```

Вычисление выполняется так:

```text
price    = 12.5
quantity = 3.0

12.5 × 3.0 = 37.5
```

Результат:

```text
Итого: 37.50
```

Спецификатор `%.2f` выводит дробное число с двумя знаками после запятой.

Хотя само значение равно `37.5`, на экран оно выводится как:

```text
37.50
```

**Информация**

`float32` и `float64` не могут абсолютно точно хранить некоторые десятичные дроби в двоичном формате.

```
Например, значение вроде `0.1` может храниться во внутренней памяти как очень близкое к нему число. В большинстве обычных вычислений эта проблема незаметна, но при работе с деньгами небольшие ошибки округления могут быть важны.

При хранении денежных значений часто удобно использовать наименьшую денежную единицу. Например, значение `12.50` можно хранить как целое число `1250`. В этом случае вычисления выполняются с целыми значениями.
```

## Логический тип: `bool`

`bool` хранит только одно из двух значений:

```text
true
false
```

Этот тип используется для представления состояний «да или нет».

Например:

```go
var active bool = true
var blocked bool = false
```

Здесь:

* `active` — `true`, то есть пользователь активен;
* `blocked` — `false`, то есть пользователь не заблокирован.

Результат операторов сравнения тоже имеет тип `bool`.

Например:

```go
package main

import "fmt"

func main() {
    age := 20
    isAdult := age >= 18

    fmt.Println("Совершеннолетний?", isAdult)
}
```

Здесь выполняется сравнение:

```go
age >= 18
```

Если подставить значения:

```text
20 >= 18
```

Это условие истинно. Поэтому:

```go
isAdult := true
```

Результат:

```text
Совершеннолетний? true
```

В следующих уроках мы будем много использовать значения `bool` с условными операторами, такими как `if`.

## Текстовый тип: `string`

`string` используется для хранения текста.

Технически `string` — последовательность байтов. Обычно эти байты представляют текст в формате UTF-8.

Строковый литерал пишется в двойных кавычках:

```go
name := "Дильшод"
message := "Изучаем Go"
empty := ""
```

Здесь:

* `"Дильшод"` — обычный текст;
* `"Изучаем Go"` — другой текст;
* `""` — пустая строка нулевой длины.

Две строки можно объединить оператором `+`:

```go
package main

import "fmt"

func main() {
    name := "Дильшод"
    message := "Привет, " + name + "!"

    fmt.Println(message)
}
```

Процесс объединения выглядит так:

```text
"Привет, " + "Дильшод" + "!"
```

В результате получается новая строка:

```text
Привет, Дильшод!
```

Исходный код Go обычно пишется в формате UTF-8. А строки хранят последовательности байтов. При работе с текстом в UTF-8 можно хранить буквы любого алфавита, эмодзи и другие символы Unicode.

Но здесь есть важная тонкость: один видимый символ Unicode — это не всегда один байт.

Поэтому при работе со `string` **количество байтов** и **количество кодовых точек Unicode** могут различаться.

### `byte` и `rune`

При работе с текстом в Go часто встречаются типы `byte` и `rune`.

`byte` — другое имя типа `uint8`:

```go
type byte = uint8
```

Он часто используется для представления одного байта.

Например:

```go
var value byte = 65
```

А `rune` — другое имя типа `int32`:

```go
type rune = int32
```

Обычно он используется для представления одной кодовой точки Unicode.

Литерал rune пишется в одинарных кавычках:

```go
var letter rune = 'O'
var specialLetter rune = '‘'
```

Здесь `"O"` было бы строкой. `'O'` — один литерал rune.

Если получить длину `string` через `len()`, вернётся количество байтов, а не количество символов Unicode.

Например:

```go
package main

import "fmt"

func main() {
    text := "Go😊"

    fmt.Println("Байты:", len(text))
    fmt.Println("Символы:", len([]rune(text)))
}
```

Результат:

```text
Байты: 6
Символы: 3
```

Почему `len(text)` вывел `6`?

Текст:

```text
Go😊
```

состоит из трёх видимых символов:

```text
G
o
😊
```

Но в формате UTF-8 их размер в байтах разный:

```text
G   -> 1 байт
o   -> 1 байт
😊  -> 4 байта
```

Всего:

```text
1 + 1 + 4 = 6 байт
```

Поэтому результат:

```go
len(text)
```

равен:

```text
6
```

А следующее выражение:

```go
[]rune(text)
```

превращает строку в последовательность кодовых точек Unicode.

В результате получаются три rune:

```text
'G'
'o'
'😊'
```

Поэтому результат:

```go
len([]rune(text))
```

равен `3`.

Эта разница важна при индексировании текста в Unicode и подсчёте его длины. Работу с `byte`, `rune` и UTF-8 мы подробно рассмотрим в следующих уроках.

## Комплексные числа

В Go есть отдельные типы и для комплексных чисел:

```text
complex64
complex128
```

Комплексное число состоит из двух частей:

* действительной части;
* мнимой части.

Например:

```go
var z complex128 = complex(2, 3)
```

В математической записи это значение означает:

```text
2 + 3i
```

Функция `complex()` принимает два значения и создаёт комплексное число:

```go
complex(2, 3)
```

Здесь:

```text
2 -> действительная часть
3 -> мнимая часть
```

Комплексные числа используются в научных, математических и инженерных вычислениях.

В обычных веб-приложениях, CLI-программах или повседневной бизнес-логике они встречаются редко. Поэтому пока достаточно знать, что они существуют и для чего нужны.

## Преобразование типов

Go не преобразует числовые типы друг в друга автоматически.

Например, `int` и `float64` — разные типы. Чтобы использовать их в одном арифметическом выражении, нужно явно преобразовать нужное значение.

Пример:

```go
package main

import "fmt"

func main() {
    var pieces int = 5
    var price float64 = 12.5

    total := float64(pieces) * price
    fmt.Println(total)
}
```

Здесь:

```go
pieces
```

имеет тип `int`.

А `price` имеет тип:

```go
float64
```

Так писать нельзя:

```go
// total := pieces * price
```

Причина в том, что значения типов `int` и `float64` нельзя перемножать напрямую.

Поэтому мы пишем:

```go
float64(pieces)
```

и на время вычисления преобразуем значение `pieces` в `float64`.

Вычисление:

```text
pieces = 5
float64(pieces) = 5.0

5.0 × 12.5 = 62.5
```

Важно, что преобразование не меняет тип исходной переменной.

То есть:

```go
pieces
```

по-прежнему `int`.

Только выражение:

```go
float64(pieces)
```

создаёт новое значение `float64`.

Дробное число тоже можно превратить в целое:

```go
fraction := 9.8
num := int(fraction)
```

В результате:

```text
num = 9
```

Это **не округление**.

При преобразовании значения `float64` в `int` дробная часть отбрасывается, и значение усекается в сторону нуля.

Например:

```text
9.8  -> 9
9.2  -> 9
-9.8 -> -9
-9.2 -> -9
```

Значит, результат `int(9.8)` не будет `10`.

Если нужно настоящее округление, для этого используют другие способы.

**Внимание**

Преобразование большого числа в тип с меньшим диапазоном во время выполнения может исказить результат.

Например:

```go
value := 300
small := uint8(value)
```

`uint8` хранит только диапазон:

```text
0 ... 255
```

`300` не помещается в этот диапазон. После преобразования старшие биты отбрасываются, и результат:

```text
44
```

Это можно представить так:

```text
300 = 256 + 44
```

Поскольку `uint8` может хранить только младшие 8 бит, остаётся `44`.

Но для констант правило другое.

Например:

```go
// var x = uint8(300)
```

не компилируется. Причина в том, что компилятор заранее видит: константное значение не помещается в диапазон `uint8`.

Поэтому перед преобразованием значения времени выполнения в меньший тип важно проверить, помещается ли оно в диапазон нового типа.

Преобразование числа в текст или текста в число отличается от преобразования между обычными числовыми типами.

Например, для:

```text
"123" -> 123
```

обычно используют пакет `strconv`.

Эту тему мы подробно рассмотрим в следующих уроках, когда будем работать с пакетами и вводом данных.

## Нулевые значения

В Go переменная без начального значения не получает случайное значение.

Она автоматически получает **нулевое значение** (zero value) своего типа.

Нулевые значения для основных типов:

| Тип                         | Нулевое значение |
| --------------------------- | ---------------- |
| целые и дробные числа       | `0`              |
| комплексные числа           | `0+0i`           |
| `bool`                      | `false`          |
| `string`                    | `""`             |

Например:

```go
package main

import "fmt"

func main() {
    var num int
    var price float64
    var active bool
    var message string

    fmt.Printf("num=%d, price=%.1f, active=%t, message=%q\n", num, price, active, message)
}
```

Мы не присвоили начальное значение ни одной из этих переменных:

```go
var num int
var price float64
var active bool
var message string
```

Тем не менее у них есть определённые значения:

```text
num     -> 0
price   -> 0.0
active  -> false
message -> ""
```

Результат:

```text
num=0, price=0.0, active=false, message=""
```

Это одна из важных особенностей Go.

Например, если написать:

```go
var active bool
```

`active` автоматически будет `false`.

Или если написать:

```go
var message string
```

`message` будет не `nil`, а пустой строкой:

```go
""
```

Понятие нулевого значения будет важно и в следующих темах — при работе со struct, указателями, срезами, map и интерфейсами.

## Какой тип выбрать?

В начале достаточно таких простых правил:

* для целого числа — `int`;
* для дробного числа — `float64`;
* для текста — `string`;
* для состояния «да или нет» — `bool`;
* для одной кодовой точки Unicode — `rune`.

Например:

```go
age := 25             // int
price := 19.99        // float64
name := "Али"         // string
active := true        // bool
symbol := 'A'         // rune
```

Типы точного размера, такие как `int32`, `uint16` или `float32`, лучше выбирать, когда в них есть реальная необходимость.

Например:

* при работе с двоичным форматом;
* когда сетевой протокол требует точного размера в битах;
* когда размер поля в формате файла строго определён;
* когда нужно точное соответствие типа внешнему API или столбцу базы данных.

Массивы, срезы, map, struct, указатели, функции, интерфейсы и каналы — тоже типы в Go.

Они выполняют более сложные задачи, чем простой `int` или `string`. Например:

* срез хранит последовательность значений;
* map хранит связи между ключами и значениями;
* struct объединяет несколько полей в одно значение;
* указатель ссылается на адрес другого значения в памяти;
* функция сама может быть значением;
* интерфейс описывает, каким поведением обладает тип;
* канал используется для передачи значений между горутинами.

Их мы рассмотрим отдельно в следующих частях.

**Информация**

`nil` — не отдельный тип данных.

```
Это специальное значение, которое используется у некоторых типов, таких как указатели, срезы, map, каналы, функции и интерфейсы, чтобы обозначить отсутствие значения или объекта.
```

## Примеры

### 1. Границы целочисленного типа

Этот пример показывает, какой диапазон чисел может хранить тип `int8`.

В пакете `math` есть константы, обозначающие минимальные и максимальные значения некоторых числовых типов:

```go
package main

import (
    "fmt"
    "math"
)

func main() {
    fmt.Println(math.MinInt8, math.MaxInt8)
}
```

Результат:

```text
-128 127
```

Значит, тип `int8` хранит значения в диапазоне:

```text
-128 ... 127
```

Например:

```go
var a int8 = -128
var b int8 = 127
```

правильно.

Но:

```go
// var c int8 = 128
```

ошибка.

Если нужны значения больше или меньше, выбирают `int16`, `int32`, `int64` или другой подходящий для задачи тип.

Этот пример показывает, что при выборе числового типа нужно учитывать его ёмкость.

### 2. Беззнаковое целое число

Этот пример показывает хранение небольшого значения, которое не может быть отрицательным, в типе `uint8`:

```go
package main

import "fmt"

func main() {
    var red uint8 = 255
    fmt.Println(red)
}
```

Результат:

```text
255
```

Поскольку диапазон `uint8`:

```text
0 ... 255
```

значение `255` помещается в этот тип.

Например:

```go
var red uint8 = 255
```

может выглядеть естественно для представления цветового канала в модели RGB, потому что компоненты цвета обычно лежат в диапазоне от `0` до `255`.

Но отрицательное значение нельзя напрямую задать как константу:

```go
// var red uint8 = -1
```

Это приводит к ошибке компиляции.

Этот пример показывает главное различие между знаковыми и беззнаковыми целочисленными типами.

### 3. Преобразование типа

Этот пример показывает, что Go не смешивает числовые типы неявно:

```go
package main

import "fmt"

func main() {
    count := 3
    price := 12.5

    total := float64(count) * price
    fmt.Println(total)
}
```

Здесь:

```go
count := 3
```

имеет тип `int`.

```go
price := 12.5
```

имеет тип `float64`.

Поэтому через:

```go
float64(count)
```

мы преобразуем значение `count` в `float64` для вычисления.

Затем:

```text
3.0 × 12.5 = 37.5
```

Результат:

```text
37.5
```

Если не написать преобразование:

```go
// total := count * price
```

компилятор сообщит, что `int` и `float64` несовместимы.

Этот пример показывает, что в Go преобразование между числовыми типами нужно писать явно.

### 4. Дробная часть при преобразовании в целое

Этот пример показывает, что происходит при преобразовании значения `float64` в `int`:

```go
package main

import "fmt"

func main() {
    positive, negative := 8.9, -8.9
    fmt.Println(int(positive), int(negative))
}
```

Результат:

```text
8 -8
```

Здесь:

```text
8.9  -> 8
-8.9 -> -8
```

Дробная часть отброшена.

Важный момент: это не математическое округление.

Например:

```text
8.9
```

при округлении до ближайшего целого стало бы `9`.

Но результат:

```go
int(8.9)
```

равен `8`.

Для отрицательного значения число тоже усекается в сторону нуля:

```go
int(-8.9)
```

даёт:

```text
-8
```

Этот пример показывает поведение преобразования числа с плавающей точкой в целочисленный тип.

### 5. Хранение символа в типе `byte`

Этот пример показывает, что `byte` на самом деле — другое имя для `uint8`:

```go
package main

import "fmt"

func main() {
    var char byte = 'G'
    fmt.Printf("%d %c %T\n", char, char, char)
}
```

Результат:

```text
71 G uint8
```

Здесь `'G'` — литерал rune.

В таблицах Unicode и ASCII у `G` десятичное значение:

```text
71
```

Поскольку оно помещается в `byte`, можно написать:

```go
var char byte = 'G'
```

Посмотрим на спецификаторы формата:

```text
%d -> в виде числа
%c -> в виде символа
%T -> тип
```

Поэтому одно значение выводится в трёх разных видах:

```text
71
G
uint8
```

`byte` — псевдоним типа `uint8`. Поэтому `%T` показывает в результате `uint8`.

Этот тип часто встречается при работе с двоичными данными, файлами, сетевыми данными или отдельными байтами строки UTF-8.

### 6. Символ Unicode в `rune`

Этот пример показывает хранение одной кодовой точки Unicode как `rune`:

```go
package main

import "fmt"

func main() {
    char := '‘'
    fmt.Printf("%c %U %T\n", char, char, char)
}
```

Значение `char` записано в одинарных кавычках:

```go
'‘'
```

Поэтому это не строка, а литерал rune.

А `rune` — псевдоним типа `int32`.

Назначение спецификаторов формата:

```text
%c -> сам символ
%U -> кодовая точка Unicode
%T -> тип Go
```

Поэтому результат будет примерно таким:

```text
‘ U+2018 int32
```

Здесь:

```text
U+2018
```

— кодовая точка Unicode левой одинарной кавычки.

Этот пример показывает, что `rune` подходит не только для символов ASCII, но и для работы с любыми символами Unicode.

### 7. Дробное число в научной записи

Очень большие или очень маленькие значения с плавающей точкой можно записывать в научной (экспоненциальной) записи:

```go
package main

import "fmt"

func main() {
    speedOfLight := 3e8
    smallValue := 1.5e-3

    fmt.Println(speedOfLight, smallValue)
}
```

Запись `e` означает степень числа 10.

Например:

```text
3e8
```

означает:

```text
3 × 10⁸
```

то есть:

```text
300000000
```

А `1.5e-3` означает:

```text
1.5 × 10⁻³
```

то есть:

```text
0.0015
```

Поскольку тип явно не указан, оба значения обычно определяются как `float64`:

```go
speedOfLight := 3e8
smallValue := 1.5e-3
```

В научных вычислениях такая запись помогает гораздо компактнее показывать очень большие или очень маленькие числа.

### 8. Сырой строковый литерал

В Go строку можно записать не только в двойных кавычках, но и в обратных.

Такая строка называется **сырым строковым литералом** (raw string literal):

```go
package main

import "fmt"

func main() {
    path := `C:\Users\Ali\main.go`
    fmt.Println(path)
}
```

Результат:

```text
C:\Users\Ali\main.go
```

В обычной строке символ `\` может обозначать начало escape-последовательности.

Например:

```go
"сообщение\nследующая строка"
```

Здесь `\n` означает новую строку.

А внутри сырой строки `\` сохраняется как есть:

```go
`C:\Users\Ali\main.go`
```

Поэтому сырые строки удобны для путей к файлам в Windows или текста, где много обратных слешей.

Сырые строки используются и для многострочного текста:

```go
text := `первая строка
вторая строка
третья строка`
```

Этот пример показывает, что строковый литерал можно записать двумя способами.

### 9. Комплексное число

Этот пример показывает создание комплексного числа в Go и получение его частей по отдельности:

```go
package main

import "fmt"

func main() {
    z := complex(3.0, 4.0)

    fmt.Println(z, real(z), imag(z))
}
```

Следующий вызов:

```go
complex(3.0, 4.0)
```

создаёт комплексное число:

```text
3 + 4i
```

Здесь:

```text
3 -> действительная часть
4 -> мнимая часть
```

`real()` получает действительную часть:

```go
real(z)
```

результат:

```text
3
```

А `imag()` получает мнимую часть:

```go
imag(z)
```

результат:

```text
4
```

Результат обычно выглядит так:

```text
(3+4i) 3 4
```

Этот пример показывает основное назначение функций `complex()`, `real()` и `imag()`.

### 10. Просмотр типа через формат

Этот пример показывает, что похожие на вид значения могут иметь разные типы:

```go
package main

import "fmt"

func main() {
    whole := 26
    fraction := 26.5
    text := "26.5"

    fmt.Printf("%T %T %T\n", whole, fraction, text)
}
```

Здесь:

```go
whole := 26
```

— `int`.

```go
fraction := 26.5
```

— `float64`.

```go
text := "26.5"
```

— `string`.

`26.5` и `"26.5"` выглядят похоже, но для Go это совершенно разные значения.

Первое — число:

```go
26.5
```

Второе — последовательность символов:

```go
"26.5"
```

Если посмотреть их типы через `%T`:

```text
int float64 string
```

получится такой результат.

Этот пример показывает, что внешний вид значения на экране и его тип в Go — не одно и то же.
