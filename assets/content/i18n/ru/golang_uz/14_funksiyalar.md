# Функции в Go

Функция — именованный блок кода, который выполняет определённую задачу. Она позволяет собрать повторяющийся код в
одном месте, разделить программу на небольшие части и тестировать каждую часть отдельно.

## Объявление и вызов

```go
func name(parameter ParamType) ReturnType {
	return value
}
```

**Параметр** — переменная, указанная в объявлении функции. А **аргумент** — конкретное значение, которое передаётся
параметру при вызове функции.

```go
package main

import "fmt"

func greet(name string) string {
	return "Привет, " + name + "!"
}

func main() {
	message := greet("Али")
	fmt.Println(message)
}
```

Результат:

```text
Привет, Али!
```

`greet` принимает один параметр `string` и возвращает `string`. `return` завершает работу функции и возвращает
значение. Для функции, которая не возвращает никакого значения, тип результата в объявлении не пишется.

Идущие подряд параметры одного типа можно записать коротко: `func add(a, b int) int`.

## Возврат нескольких значений

Функция Go может возвращать несколько значений. Эта возможность часто используется, чтобы вернуть вместе с
результатом и ошибку:

```go
package main

import "fmt"

func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, fmt.Errorf("делить на ноль нельзя")
	}
	return a / b, nil
}

func main() {
	result, err := divide(10, 4)
	if err != nil {
		fmt.Println("Ошибка:", err)
		return
	}
	fmt.Println("Результат:", result)
}
```

Результат:

```text
Результат: 2.5
```

Если `b` равно нулю, деление не выполняется и возвращается ошибка. Возврат ошибки отдельным значением широко
применяется в коде, работающем с API, файлами или базами данных. Если одно из возвращаемых значений не нужно, его
можно проигнорировать с помощью `_`.

## Аргументы передаются по значению

В Go все аргументы передаются по значению. Функция получает копию значения аргумента:

```go
package main

import "fmt"

func increment(n int) {
	n++
}

func main() {
	num := 10
	increment(num)
	fmt.Println(num)
}
```

Результат:

```text
10
```

`slice`, `map`, `channel` и `pointer` тоже передаются по значению. Но их копии могут ссылаться на те же базовые данные.
Поэтому копирование аргумента не означает, что изменения внутри функции никогда не повлияют на вызывающий код.

## Вариативная функция

Иногда мы заранее не знаем, сколько аргументов будет передано функции.

Например, мы хотим написать функцию, которая вычисляет сумму нескольких чисел. С обычными параметрами пришлось бы
заранее задать количество аргументов:

```go
func sum(a, b int) int {
	return a + b
}
```

Эта функция принимает только два числа:

```go
sum(10, 20)
```

Если мы хотим передать три, четыре или больше чисел, такой функции недостаточно. В таких случаях используется
**вариативная функция** (variadic). Вариативный параметр записывается так:

```go
numbers ...int
```

Эта запись означает:

> параметру `numbers` можно передать ноль или больше значений `int`

Например:

```go
package main

import "fmt"

func sum(numbers ...int) int {
	result := 0

	for _, num := range numbers {
		result += num
	}

	return result
}

func main() {
	fmt.Println(sum(1, 2, 3, 4))
}
```

Результат:

```text
10
```

Здесь:

```go
sum(1, 2, 3, 4)
```

передаёт функции четыре отдельных аргумента `int`.

А внутри функции параметр:

```go
numbers ...int
```

работает как `[]int`.

То есть при вызове выше `numbers` внутри функции можно представить примерно так:

```go
[]int{1, 2, 3, 4}
```

Поэтому его элементы можно обойти с помощью `range`:

```go
for _, num := range numbers {
	result += num
}
```

Вариативной функции можно передавать разное количество аргументов:

```go
fmt.Println(sum())
fmt.Println(sum(10))
fmt.Println(sum(10, 20))
fmt.Println(sum(10, 20, 30, 40))
```

Например:

```go
sum()
```

тоже правильный вызов, потому что вариативный параметр принимает **ноль или больше** аргументов.

### Передача среза в вариативную функцию

Теперь представим, что у нас есть готовый срез:

```go
numbers := []int{5, 6, 7}
```

Так написать нельзя:

```go
sum(numbers)
```

Потому что `sum` ожидает отдельные аргументы `int`, а `numbers` — одно значение `[]int`.

В таком случае после имени среза пишется `...`:

```go
sum(numbers...)
```

Полный пример:

```go
package main

import "fmt"

func sum(numbers ...int) int {
	result := 0

	for _, num := range numbers {
		result += num
	}

	return result
}

func main() {
	numbers := []int{5, 6, 7}

	fmt.Println(sum(numbers...))
}
```

Результат:

```text
18
```

Следующая запись:

```go
sum(numbers...)
```

передаёт элементы среза в функцию как отдельные аргументы.

По смыслу это похоже на:

```go
sum(5, 6, 7)
```

Значит, `...` может встречаться в двух местах, и его роль немного различается.

В параметре функции:

```go
func sum(numbers ...int)
```

`...int` означает:

> этот параметр принимает любое количество аргументов `int`

При вызове функции:

```go
sum(numbers...)
```

`numbers...` означает:

> разверни элементы среза в отдельные аргументы

### Вариативный параметр должен быть последним

У функции могут быть и обычные параметры, и вариативный:

```go
func message(prefix string, numbers ...int) {
	// ...
}
```

Тогда функцию можно вызвать так:

```go
message("Результат:", 10, 20, 30)
```

Но вариативный параметр всегда должен стоять в **конце** списка параметров.

Например, так написать нельзя:

```go
func message(numbers ...int, prefix string) {
	// ...
}
```

Причина в том, что заранее нельзя знать, сколько аргументов примет `numbers`. Если после него есть ещё параметр,
становится неясно, какие аргументы относятся к вариативному параметру, а какие — к следующему.

Поэтому правильная запись:

```go
func message(prefix string, numbers ...int) {
	// ...
}
```

Кратко:

```go
func sum(numbers ...int)
```

— функция принимает любое количество аргументов `int`.

```go
sum(1, 2, 3)
```

— передаются три отдельных аргумента.

```go
numbers := []int{1, 2, 3}
sum(numbers...)
```

— элементы среза передаются как отдельные аргументы.

А внутри функции `numbers` используется как `[]int`.

## Значение-функция и анонимная функция

В Go функция тоже используется как значение. Её можно сохранить в переменную или передать другой функции в качестве
аргумента.

```go
package main

import "fmt"

func calculate(a, b int, op func(int, int) int) int {
	return op(a, b)
}

func main() {
	multiply := func(a, b int) int {
		return a * b
	}

	fmt.Println(calculate(4, 5, multiply))
}
```

Результат:

```text
20
```

Если анонимная функция использует переменную из внешней области видимости (scope), образуется замыкание (closure).
Замыкание сохраняет ссылку на эту переменную, поэтому её состояние может сохраняться и при следующих вызовах. Этот
приём встречается в callback, middleware и функциях конфигурации.

## Рекурсия

Вызов функцией самой себя называется рекурсией. У рекурсивной функции обязательно должно быть условие остановки:

```go
package main

import "fmt"

func factorial(n uint64) uint64 {
	if n <= 1 {
		return 1
	}
	return n * factorial(n-1)
}

func main() {
	fmt.Println(factorial(5))
}
```

Результат:

```text
120
```

Каждый вызов занимает дополнительное место в стеке. Очень глубокая рекурсия увеличивает расход ресурсов. Для простых
последовательных вычислений цикл может быть понятнее. Если результат факториала превысит ёмкость `uint64`, произойдёт
переполнение. Поэтому этот пример не предназначен для вычисления больших чисел.

## Примеры

### 1. Проверка чётности числа

```go
package main

import "fmt"

func isEven(num int) bool {
	return num%2 == 0
}

func main() {
	fmt.Println(isEven(18))
}
```

Функция возвращает вычисленное значение `bool` прямо через `return`. Результат этого примера — `true`.

### 2. Именованные возвращаемые значения

```go
package main

import "fmt"

func rectangle(width, height int) (area int, perimeter int) {
	area = width * height
	perimeter = 2 * (width + height)
	return
}

func main() {
	area, perimeter := rectangle(8, 5)
	fmt.Println(area, perimeter)
}
```

Именованные возвращаемые значения работают внутри функции как обычные переменные. `return` без значений возвращает
их текущие значения.

### 3. Проверка с ранним `return`

```go
package main

import "fmt"

func div(a, b float64) (float64, bool) {
	if b == 0 {
		return 0, false
	}
	return a / b, true
}

func main() {
	result, ok := div(20, 4)
	fmt.Println(result, ok)
}
```

Сначала проверяется случай деления на ноль. Второе возвращаемое значение показывает, успешно ли выполнено деление.

### 4. Вариативная сумма

```go
package main

import "fmt"

func sum(numbers ...int) int {
	result := 0
	for _, num := range numbers {
		result += num
	}
	return result
}

func main() {
	fmt.Println(sum(2, 4, 6, 8))
}
```

`...int` означает, что функция принимает ноль или больше аргументов `int`. Внутри функции `numbers` работает как срез.

### 5. Передача среза как вариативных аргументов

```go
package main

import "fmt"

func largest(numbers ...int) int {
	max := numbers[0]
	for _, num := range numbers[1:] {
		if num > max {
			max = num
		}
	}
	return max
}

func main() {
	numbers := []int{7, 12, 4, 19}
	fmt.Println(largest(numbers...))
}
```

`numbers...` передаёт элементы среза как отдельные аргументы. В примере заранее известно, что срез не пуст.

### 6. Передача функции в качестве аргумента

```go
package main

import "fmt"

func calculate(a, b int, op func(int, int) int) int {
	return op(a, b)
}

func main() {
	multiply := func(a, b int) int { return a * b }
	fmt.Println(calculate(6, 7, multiply))
}
```

Тип параметра `op` обозначает функцию, которая принимает два `int` и возвращает один `int`.

### 7. Хранение состояния в замыкании

```go
package main

import "fmt"

func counter() func() int {
	count := 0
	return func() int {
		count++
		return count
	}
}

func main() {
	next := counter()
	fmt.Println(next(), next(), next())
}
```

Возвращённая анонимная функция сохраняет ссылку на внешнюю переменную `count`. Поэтому последовательные вызовы дают
`1 2 3`.

### 8. map из функций

```go
package main

import "fmt"

func main() {
	ops := map[string]func(int, int) int{
		"+": func(a, b int) int { return a + b },
		"-": func(a, b int) int { return a - b },
	}
	fmt.Println(ops["+"](10, 3))
}
```

Функция тоже может быть значением `map`. Сначала функция берётся по ключу, затем вызывается с аргументами.

### 9. Сумма цифр с помощью рекурсии

```go
package main

import "fmt"

func digitSum(num int) int {
	if num == 0 {
		return 0
	}
	return num%10 + digitSum(num/10)
}

func main() {
	fmt.Println(digitSum(5832))
}
```

Каждый вызов отделяет последнюю цифру числа. Условие `num == 0` останавливает рекурсию.

### 10. Возврат функции в зависимости от условия

```go
package main

import "fmt"

func chooseOp(name string) func(int, int) int {
	if name == "multiply" {
		return func(a, b int) int { return a * b }
	}
	return func(a, b int) int { return a + b }
}

func main() {
	op := chooseOp("multiply")
	fmt.Println(op(5, 4))
}
```

Функция может возвращать в качестве результата другую функцию. Возвращённое значение затем вызывается как обычная
функция.
