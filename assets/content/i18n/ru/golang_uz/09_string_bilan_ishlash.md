# Работа со `string` в Go

`string` — тип, который хранит текст и произвольные последовательности байтов. Такие значения, как имя пользователя,
URL, путь к файлу или JSON, в программах часто используются в виде `string`.

Чтобы правильно работать со строками, важно различать три понятия:

* **байты** — то, как текст хранится в памяти;
* **кодовые точки Unicode** — значение, присвоенное каждому символу;
* **видимые пользователю символы** — буква, цифра или знак, которые на экране выглядят как один символ.

Количество этих трёх величин не всегда совпадает. Например, обычная английская буква чаще всего занимает один байт.
А буквы кириллицы, буквы с диакритикой или эмодзи могут состоять из нескольких байтов.

## Строковые литералы и неизменяемость

В Go текст можно записать двумя способами.

Строка в двойных кавычках называется **интерпретируемым строковым литералом** (interpreted string literal). В ней
специальные последовательности, такие как `\n`, `\t` и `\"`, имеют особый смысл:

```go
text := "Привет\nМир"
```

Здесь `\n` означает переход на новую строку.

Строка в обратных кавычках называется **сырым строковым литералом** (raw string literal). Текст в ней хранится почти
так, как написан. Специальные последовательности не интерпретируются, а текст можно писать на нескольких строках:

```go
text := `Привет\nМир`
```

В этом случае `\n` — не новая строка, а два обычных символа.

```go
package main

import "fmt"

func main() {
	line := "Первая строка\nВторая строка"
	path := `C:\temp\main.go`

	fmt.Println(line)
	fmt.Println(path)
}
```

**Результат:**

```text
Первая строка
Вторая строка
C:\temp\main.go
```

`'A'` в одинарных кавычках — не строка, а литерал `rune`. `rune` представляет одну кодовую точку Unicode и является
другим именем типа `int32`.

В Go строки неизменяемы (immutable). Байт внутри созданной строки заменить нельзя:

```go
text := "Go"
// text[0] = 'N' // ошибка компиляции: элементу строки нельзя присвоить значение
```

А `text = "No"` можно. Это не изменяет старую строку, а присваивает переменной `text` другое строковое значение.

## String, `byte` и `rune`

Строка может хранить произвольные байты. Для текста Go обычно использует UTF-8, но само значение `string` не
гарантирует, что байты в нём — корректный UTF-8.

- `byte` представляет один байт и является другим именем типа `uint8`;
- `rune` представляет кодовую точку Unicode и является другим именем типа `int32`;
- символы ASCII занимают в UTF-8 один байт, а остальные символы — несколько байтов.

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	text := "Go is fun 😊"

	fmt.Println("Байты:", len(text))
	fmt.Println("Количество rune:", utf8.RuneCountInString(text))
	for index, char := range text {
		fmt.Printf("%2d: %c\n", index, char)
	}
}
```

Результат (начало):

```text
Байты: 14
Количество rune: 11
 0: G
 1: o
 2: (пробел)
 3: i
```

`len(text)` считает байты, а не символы. `utf8.RuneCountInString()` считает кодовые точки Unicode. `range` каждый раз
отдаёт одну закодированную в UTF-8 руну, а индекс — это байтовая позиция, с которой она начинается.

> **Информация**
>
> Количество rune не всегда равно количеству символов, которые видит пользователь. Некоторые символы состоят из
> нескольких кодовых точек Unicode. В стандартной библиотеке Go нет общей функции для подсчёта таких составных символов.

## Получение байтов по индексу

`text[i]` возвращает байт с индексом `i` как `byte`:

```go
package main

import "fmt"

func main() {
	text := "Go"
	first := text[0]

	fmt.Println(first)
	fmt.Printf("%c\n", first)
}
```

**Результат:**

```text
71
G
```

`71` — байтовое значение `G` в UTF-8 и ASCII. `%c` выводит это значение как символ. Если индекс отрицательный или
равен `len(text)` либо больше, программа завершается с ошибкой во время выполнения (panic).

Если взять только один байт многобайтового символа, целый символ не получится. Чтобы обрабатывать текст Unicode по
символам, используют `range` или `[]rune`:

```go
package main

import "fmt"

func main() {
	text := "Привет"
	runes := []rune(text)

	fmt.Printf("Первая руна: %c\n", runes[0])
	fmt.Printf("Третья руна: %c\n", runes[2])
}
```

Результат:

```text
Первая руна: П
Третья руна: и
```

`[]rune(text)` создаёт новый срез рун и память для него. Если текст нужно прочитать последовательно только один раз,
`range` обычно расходует меньше памяти.

## Объединение и сравнение строк

Небольшое количество строк можно объединить через `+`. `==` и `!=` проверяют равенство последовательностей байтов.
А `<`, `>`, `<=` и `>=` сравнивают лексикографически, то есть в порядке значений байтов.

```go
package main

import "fmt"

func main() {
	firstName := "Али"
	lastName := "Валиев"
	fullName := firstName + " " + lastName

	fmt.Println(fullName)
	fmt.Println(fullName == "Али Валиев")
	fmt.Println("Go" < "Rust")
}
```

Результат:

```text
Али Валиев
true
true
```

## Создание строки с помощью `strings.Builder`

Сложение нескольких небольших строк оператором `+` удобно в простых случаях:

```go
text := "Привет, " + "мир!"
```

Но многократное сложение строк через `+` внутри большого цикла может быть неэффективным. Поскольку строки в Go
неизменяемы, при каждом сложении может создаваться новая строка и выделяться дополнительная память.

Чтобы собрать много кусков текста, используют `strings.Builder`:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	var builder strings.Builder

	for i := 1; i <= 3; i++ {
		if i > 1 {
			builder.WriteString(", ")
		}

		fmt.Fprint(&builder, i)
	}

	fmt.Println(builder.String())
}
```

Результат:

```text
1, 2, 3
```

В этом коде:

* `var builder strings.Builder` — создаёт builder для сбора кусков текста;
* `builder.WriteString(", ")` — записывает в builder запятую и пробел;
* `fmt.Fprint(&builder, i)` — записывает число в builder в виде текста;
* `builder.String()` — превращает собранный результат в обычное значение `string`.

Условие `if i > 1` нужно, чтобы запятая ставилась только между числами, а не перед первым числом.

`strings.Builder` собирает куски во внутреннем буфере. Готовый результат получают через `String()`.

## Получение части строки

`text[start:end]` возвращает диапазон байтов от индекса `start` до индекса `end`, не включая сам `end`:

```go
package main

import "fmt"

func main() {
	text := "Hello, world!"

	fmt.Println(text[:5])
	fmt.Println(text[7:12])
	fmt.Println(text[7:])
}
```

**Результат:**

```text
Hello
world
world!
```

Границы — это байтовые индексы (здесь строка из символов ASCII, поэтому каждый символ — один байт). Если не
выполняется `0 <= start <= end <= len(text)`, программа завершается с ошибкой. Разрез посередине символа UTF-8 может
дать неправильный результат.

Если нужно резать по кодовым точкам Unicode, сначала преобразуют в `[]rune`:

```go
runes := []rune("Gopher")
part := string(runes[:3]) // "Gop"
```

## Копирование части строки

Когда из большой строки выделяют маленькую часть, получившаяся строка в некоторых случаях может продолжать
использовать память, где хранится исходная строка.

Например:

```go
bigText := "текст очень большого объёма..."
part := bigText[:4]
```

Здесь, хотя `part` представляет лишь небольшой текст, из-за неё большой текст может дольше оставаться в памяти.

Если нужна полностью независимая от исходной строки копия маленькой части, используют `strings.Clone`:

```go
part := strings.Clone(bigText[:4])
```

`strings.Clone` создаёт новую копию заданной строки. После этого `part` больше не зависит от памяти исходной большой
строки.

Однако `strings.Clone` не нужно использовать всегда, ведь она выделяет новую память и копирует данные строки. Её
разумно применять в основном в таких случаях:

* маленькая часть взята из очень большой строки;
* эта часть хранится долго;
* требуется именно копия строки.

В простых и кратковременных операциях часть строки можно использовать напрямую.

## Пакет `strings`

Пакет `strings` стандартной библиотеки предоставляет функции для поиска, разделения, объединения, замены и изменения
регистра.

### Поиск и проверка

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "Go programming language"

	fmt.Println(strings.Contains(text, "Go"))
	fmt.Println(strings.Count(text, "a"))
	fmt.Println(strings.HasPrefix(text, "Go"))
	fmt.Println(strings.HasSuffix(text, "language"))
	fmt.Println(strings.Index(text, "program"))
	fmt.Println(strings.Index(text, "Python"))
}
```

Результат:

```text
true
3
true
true
3
-1
```

`Contains()` проверяет наличие подстроки, а `Count()` — сколько раз она встречается. `Index()` возвращает байтовый
индекс первого совпадения или `-1`, если ничего не найдено. Прежде чем использовать результат как индекс, нужно
проверить, что он не равен `-1`.

`strings.ContainsAny(text, "abc")` проверяет, есть ли хотя бы одна из рун второго аргумента. Для поиска целой подстроки
нужно использовать `Contains()`.

### Разделение строки и обратное объединение

В Go для разделения строки на части используют `strings.Split()` и `strings.Fields()`, а для обратного объединения
частей — `strings.Join()`.

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	line := " go, backend ,api "
	parts := strings.Split(line, ",")

	for i := range parts {
		parts[i] = strings.TrimSpace(parts[i])
	}

	fmt.Println(parts)
	fmt.Println(strings.Join(parts, " | "))
	fmt.Println(strings.Fields("  Go\tbackend\nAPI  "))
}
```

Результат:

```text
[go backend api]
go | backend | api
[Go backend API]
```

`strings.Split(line, ",")` разделяет строку в местах, где встречается запятая:

```go
parts := strings.Split(line, ",")
```

В результате получается такой срез:

```go
[" go" " backend " "api "]
```

В начале или конце элементов могут остаться пробелы. Поэтому внутри цикла лишние пробелы убираются с помощью
`strings.TrimSpace()`:

```go
for i := range parts {
	parts[i] = strings.TrimSpace(parts[i])
}
```

`strings.Join()` объединяет строки среза в одну строку через заданный разделитель:

```go
strings.Join(parts, " | ")
```

Результат:

```text
go | backend | api
```

А `strings.Fields()` разделяет строку по пробельным символам:

```go
strings.Fields("  Go\tbackend\nAPI  ")
```

Вместе с обычным пробелом эта функция принимает как разделители табуляцию (`\t`), перевод строки (`\n`) и другие
пробельные символы Unicode. Идущие подряд пробельные символы считаются одним разделителем, и пустые элементы в
результат не добавляются.

Главное различие:

* `Split()` разделяет только по заданному разделителю;
* `Split()` в некоторых случаях сохраняет пустые элементы;
* `Fields()` считает разделителем любую последовательность пробельных символов;
* `Fields()` не добавляет пустые элементы в результат;
* `Join()` объединяет элементы среза в одну строку.

Полезно отдельным примером показать, как `Split()` создаёт пустые элементы:

```go
fmt.Println(strings.Split("go,,api", ","))
// [go  api]
```

### Замена и повторение текста в строке

В Go для замены определённого текста в строке другим используются функции `strings.Replace()` и
`strings.ReplaceAll()`. А для многократного повторения одного и того же текста — `strings.Repeat()`.

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "Go быстрый, Go простой"

	fmt.Println(strings.Replace(text, "Go", "Golang", 1))
	fmt.Println(strings.ReplaceAll(text, "Go", "Golang"))
	fmt.Printf("%q\n", strings.Repeat("Go! ", 3))
}
```

Результат:

```text
Golang быстрый, Go простой
Golang быстрый, Golang простой
"Go! Go! Go! "
```

`strings.Replace()` заменяет в строке старый текст новым:

```go
strings.Replace(text, "Go", "Golang", 1)
```

Здесь:

* `text` — изменяемая строка;
* `"Go"` — искомый старый текст;
* `"Golang"` — новый текст, который пишется вместо него;
* `1` — сколько вхождений нужно заменить.

Поэтому заменяется только первое `"Go"`:

```text
Golang быстрый, Go простой
```

Чтобы заменить все вхождения, можно передать `-1`:

```go
strings.Replace(text, "Go", "Golang", -1)
```

Но для этой цели `strings.ReplaceAll()` понятнее и удобнее для чтения:

```go
strings.ReplaceAll(text, "Go", "Golang")
```

В результате заменяются все значения `"Go"` в строке:

```text
Golang быстрый, Golang простой
```

`strings.Repeat()` повторяет заданную строку указанное количество раз:

```go
strings.Repeat("Go! ", 3)
```

Результат:

```text
Go! Go! Go! 
```

Поскольку в примере используется спецификатор `%q`, результат выводится в кавычках. Так виден и пробел в конце
строки.

Если передать `Repeat()` отрицательное количество повторений или если создаваемая строка окажется слишком большой,
программа может перейти в состояние `panic`. Поэтому, если количество повторений приходит от пользователя или из
внешнего источника, его нужно проверить заранее:

```go
if count >= 0 && count <= 100 {
	result := strings.Repeat("Go! ", count)
	fmt.Println(result)
}
```

### Удаление символов в начале и в конце строки

В Go для удаления ненужных пробелов, префиксов, суффиксов и других символов в начале или в конце строки используются
функции `Trim` из пакета `strings`.

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	value := "\t язык программирования Go \n"
	url := "https://go-lang.uz/"

	fmt.Printf("%q\n", strings.TrimSpace(value))
	fmt.Println(strings.TrimPrefix(url, "https://"))
	fmt.Println(strings.TrimSuffix(url, "/"))
	fmt.Println(strings.Trim("...Go...", "."))
}
```

Результат:

```text
"язык программирования Go"
go-lang.uz/
https://go-lang.uz
Go
```

`strings.TrimSpace()` удаляет пробельные символы в начале и в конце строки:

```go
strings.TrimSpace(value)
```

Вместе с обычным пробелом эта функция убирает табуляцию (`\t`), перевод строки (`\n`) и другие пробельные символы
Unicode. Пробелы внутри строки она не трогает.

`strings.TrimPrefix()` удаляет точный префикс в начале строки:

```go
strings.TrimPrefix(url, "https://")
```

Результат:

```text
go-lang.uz/
```

`strings.TrimSuffix()` удаляет точный суффикс в конце строки:

```go
strings.TrimSuffix(url, "/")
```

Результат:

```text
https://go-lang.uz
```

Если заданного префикса или суффикса в строке нет, `TrimPrefix()` и `TrimSuffix()` возвращают исходную строку без
изменений.

А `strings.Trim()` принимает второй аргумент не как цельный текст, а как набор символов, которые нужно удалить:

```go
strings.Trim("...Go...", ".")
```

Здесь удаляются все точки в начале и в конце строки:

```text
Go
```

Например:

```go
fmt.Println(strings.Trim("!?Go?!", "!?"))
```

Результат:

```text
Go
```

Потому что `Trim()` удаляет символы `!` и `?` с обоих краёв строки, пока они встречаются. Символы в середине строки
сохраняются.

### Перевод в верхний и нижний регистр и сравнение без учёта регистра

В Go для перевода букв строки в нижний или верхний регистр используются функции `strings.ToLower()` и
`strings.ToUpper()`. Для сравнения двух строк без учёта регистра применяется `strings.EqualFold()`.

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	value := "Go Программирование"

	fmt.Println(strings.ToLower(value))
	fmt.Println(strings.ToUpper(value))
	fmt.Println(strings.EqualFold("GO", "go"))
}
```

Результат:

```text
go программирование
GO ПРОГРАММИРОВАНИЕ
true
```

`strings.ToLower()` переводит буквы строки в нижний регистр:

```go
strings.ToLower("Go Программирование")
```

Результат:

```text
go программирование
```

А `strings.ToUpper()` переводит буквы в верхний регистр:

```go
strings.ToUpper("Go Программирование")
```

Результат:

```text
GO ПРОГРАММИРОВАНИЕ
```

Эти функции возвращают новую строку. Исходная строка не меняется, потому что строки в Go — неизменяемые значения.

`strings.EqualFold()` сравнивает две строки без учёта регистра букв:

```go
strings.EqualFold("GO", "go")
```

Результат:

```text
true
```

Если нужно только проверить равенство без учёта регистра, лучше использовать `EqualFold()`, чем переводить обе строки
через `ToLower()` и сравнивать их:

```go
// Работает, но замысел не очень очевиден
strings.ToLower(a) == strings.ToLower(b)

// Выражает замысел яснее
strings.EqualFold(a, b)
```

`EqualFold()` использует правила сравнения букв Unicode. Поэтому она лучше подходит и для работы с другими системами
письма, помимо обычных английских букв.

По названию можно подумать, что `strings.ToTitle()` делает заглавной только первую букву каждого слова, но она работает
не так. Эта функция переводит каждую букву строки в `title case` по правилам Unicode:

```go
fmt.Println(strings.ToTitle("go программирование"))
```

Результат обычно такой:

```text
GO ПРОГРАММИРОВАНИЕ
```

Поэтому `ToTitle()` не предназначена для оформления заголовков на естественном языке. Например, правила, по которым
заглавной делается только первая буква каждого слова в имени или заголовке, зависят от языка и должны выполняться
отдельной логикой.

### Изменение символов с помощью `strings.Map()`

`strings.Map()` обрабатывает каждый символ Unicode строки, то есть каждую `rune`, заданной функцией и создаёт новую
строку.

Если функция:

* возвращает ту же руну, этот символ добавляется в результат;
* возвращает другую руну, символ заменяется;
* возвращает `-1`, символ удаляется из результата.

В следующем примере сохраняются только буквы, а цифры, точка и пробел удаляются:

```go
package main

import (
	"fmt"
	"strings"
	"unicode"
)

func main() {
	value := "Go 1.22"

	onlyLetters := strings.Map(func(char rune) rune {
		if unicode.IsLetter(char) {
			return char
		}

		return -1
	}, value)

	fmt.Println(onlyLetters)
}
```

Результат:

```text
Go
```

`strings.Map()` по одной передаёт руны строки в переменную `char`:

```go
func(char rune) rune
```

`unicode.IsLetter(char)` проверяет, является ли руна буквой. Если это буква, она возвращается без изменений:

```go
return char
```

Если руна не буква, возвращается `-1`, и она не добавляется в новую строку:

```go
return -1
```

`strings.Map()` можно использовать не только для удаления символов, но и для их замены. Например, заменить все
пробельные символы дефисом:

```go
result := strings.Map(func(char rune) rune {
	if unicode.IsSpace(char) {
		return '-'
	}

	return char
}, "язык программирования Go")

fmt.Println(result)
```

Результат:

```text
язык-программирования-Go
```

Этот способ полезен для очистки текста, нормализации или сохранения только разрешённых символов.

Однако валидация и очистка текста — не одна и та же задача. Если молча удалять неправильные символы, можно скрыть
ошибку пользователя. Если введённое значение должно строго соответствовать правилам, лучше вернуть пользователю
понятное сообщение об ошибке, чем удалять неправильные символы.

## Проверка того, что строка в формате UTF-8

В Go `string` на самом деле — последовательность байтов. Поэтому в строке не обязательно всегда находится корректный
текст UTF-8. Неправильные байты особенно часто встречаются, когда данные получены из файла, сети, базы данных или
другого внешнего источника.

В следующем примере байт `0xff` не соответствует правилам UTF-8:

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	value := string([]byte{0xff, 'G', 'o'})

	fmt.Println(utf8.ValidString(value))
	fmt.Printf("%q\n", value)
}
```

Результат:

```text
false
"\xffGo"
```

`utf8.ValidString()` проверяет, образуют ли байты строки корректную последовательность UTF-8:

```go
utf8.ValidString(value)
```

Если строка — корректный UTF-8, функция возвращает `true`, иначе `false`.

В примере `value` создана из таких байтов:

```go
[]byte{0xff, 'G', 'o'}
```

Байты `'G'` и `'o'` — корректные символы UTF-8, но `0xff` не является допустимым байтом в тексте UTF-8. Поэтому
результат — `false`.

Формат `%q` выводит строку в кавычках и с escape-последовательностями:

```go
fmt.Printf("%q\n", value)
```

Поэтому неправильный байт показан в результате как `\xff`:

```text
"\xffGo"
```

Если использовать цикл `range` по некорректной строке UTF-8, Go вместо недопустимой последовательности возвращает
значение `utf8.RuneError`. На экране оно обычно выглядит как символ `�`:

```go
for _, char := range value {
	fmt.Printf("%c\n", char)
}
```

Примерный результат:

```text
�
G
o
```

Если используемый протокол или формат файла принимает только текст UTF-8, значение нужно проверить перед обработкой:

```go
if !utf8.ValidString(value) {
	fmt.Println("Ошибка: текст не в формате UTF-8")
	return
}
```

Эта проверка помогает не передавать неправильно закодированные данные на следующие этапы.

## Распространённые ошибки

### Считать результат `len()` количеством символов

В Go `len()` возвращает количество байтов в строке, а не количество символов.

У символов ASCII один символ обычно занимает один байт. Поэтому для обычного английского текста результат `len()`
кажется равным количеству символов:

```go
text := "Go"

fmt.Println(len(text)) // 2
```

А у символов Unicode один символ может состоять из нескольких байтов:

```go
text := "Go😊"

fmt.Println(len(text))                    // 6 байт
fmt.Println(utf8.RuneCountInString(text)) // 3 руны
```

Чтобы узнать количество кодовых точек, то есть рун, используют `utf8.RuneCountInString()`.

Однако количество символов, которые пользователь видит на экране, тоже не всегда равно количеству рун. Например,
некоторые эмодзи или диакритические знаки могут состоять из нескольких рун. В таком случае нужно специальное решение,
которое считает графемные кластеры.

### Разрез строки не по границе символа

При таком разрезе строки индексы обозначают байты, а не символы:

```go
part := text[a:b]
```

Если символ Unicode состоит из нескольких байтов, разрез посередине может дать некорректную строку UTF-8.

Например:

```go
text := "Go😊"
part := text[:3]

fmt.Printf("%q\n", part)
```

Этот разрез может взять только первый байт эмодзи, и результат будет некорректным UTF-8.

Если нужно резать по рунам, строку можно преобразовать в `[]rune`:

```go
text := "Go😊"
runes := []rune(text)

part := string(runes[:3])

fmt.Println(part) // Go😊
```

Этот способ понятен, но требует дополнительной памяти, потому что создаёт новый срез и строку.

### Думать, что `strings.Trim()` удаляет подстроку

`strings.Trim()` принимает второй аргумент не как цельную подстроку, а как набор рун для удаления.

Например:

```go
result := strings.Trim("abba", "ab")

fmt.Printf("%q\n", result)
```

Результат:

```text
""
```

Причина в том, что функция удаляет все руны `a` и `b` в начале и в конце строки.

Если нужно удалить точную часть `"ab"` в начале строки, используют `TrimPrefix()`:

```go
fmt.Println(strings.TrimPrefix("abba", "ab"))
// ba
```

А для точной части в конце строки — `TrimSuffix()`:

```go
fmt.Println(strings.TrimSuffix("abba", "ba"))
// ab
```

### Думать, что смена регистра решает все проблемы с текстом

Преобразование текста через `ToLower()` или `ToUpper()` не всегда полностью соответствует правилам естественного языка.
Правила регистра Unicode и требования к оформлению текста в разных языках могут быть сложными.

Если нужно лишь проверить техническое равенство без учёта регистра, лучше использовать `strings.EqualFold()`:

```go
fmt.Println(strings.EqualFold("GO", "go"))
// true
```

Но для оформления имён пользователей, сортировки по правилам локального языка или создания заголовков обычных
`ToLower()` и `ToUpper()` может быть недостаточно. Для таких задач нужны чёткие требования продукта и специальная
библиотека, подходящая для языка.

## Примеры

### 1. Сбор текста с помощью `strings.Builder`

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	var builder strings.Builder
	for i := 1; i <= 3; i++ {
		builder.WriteString(fmt.Sprintf("Строка %d\n", i))
	}
	fmt.Print(builder.String())
}
```

При последовательном объединении многих кусков `Builder` уменьшает количество создаваемых новых строк. Готовый
результат получают через `String()`.

### 2. Удаление лишних пробелов между словами

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "  Изучаем\t язык   Go\n"
	clean := strings.Join(strings.Fields(text), " ")
	fmt.Println(clean)
}
```

`Fields()` считает разделителями идущие подряд пробелы, табуляции и переводы строк. `Join()` снова объединяет слова
через один пробел.

### 3. Разделение по нескольким разделителям

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	parts := strings.FieldsFunc("яблоко,гранат;виноград груша", func(r rune) bool {
		return r == ',' || r == ';' || r == ' '
	})
	fmt.Println(parts)
}
```

`FieldsFunc()` позволяет с помощью функции определить, какие руны являются разделителями.

### 4. Удаление префикса, только если он есть

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	address := "https://go.dev"
	address = strings.TrimPrefix(address, "https://")
	fmt.Println(address)
}
```

`TrimPrefix()` удаляет префикс, только если он совпадает полностью. А `Trim()` удаляет заданный набор символов с обоих
краёв.

### 5. Разделение строки по разделителю

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	before, after, found := strings.Cut("lang=uz", "=")
	fmt.Println(before, after, found)
}
```

`Cut()` делит строку на часть до первого разделителя и часть после него. Третье значение показывает, найден ли
разделитель.

### 6. Подсчёт вхождений подстроки

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "go test, go build, go run"
	fmt.Println(strings.Count(text, "go"))
}
```

Результат — `3`. `Count()` считает непересекающиеся вхождения.

### 7. Замена только первого вхождения

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "ошибка: ошибка: файл не найден"
	fmt.Println(strings.Replace(text, "ошибка", "предупреждение", 1))
}
```

Последний аргумент задаёт, сколько вхождений нужно заменить. Поскольку передано `1`, заменяется только первое
вхождение. Если передать `-1`, заменяются все вхождения.

### 8. Переворот текста по кодовым точкам Unicode

```go
package main

import "fmt"

func main() {
	runes := []rune("Привет")
	for left, right := 0, len(runes)-1; left < right; left, right = left+1, right-1 {
		runes[left], runes[right] = runes[right], runes[left]
	}
	fmt.Println(string(runes))
}
```

Переворот строки по байтам может испортить многобайтовые символы UTF-8. `[]rune` сохраняет границы символов.

### 9. Проверка первой буквы каждого слова

```go
package main

import (
	"fmt"
	"strings"
	"unicode"
)

func main() {
	for _, word := range strings.Fields("Язык Программирования Go") {
		for _, first := range word {
			fmt.Println(word, unicode.IsUpper(first))
			break
		}
	}
}
```

Внутренний `range` безопасно берёт первую руну Unicode слова. `break` не проверяет остальные руны, а
`unicode.IsUpper()` определяет, является ли взятая руна заглавной буквой.

### 10. Получение независимой копии строки

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	big := strings.Repeat("a", 1000) + "final"
	small := strings.Clone(big[len(big)-5:])
	fmt.Println(small)
}
```

Подстрока иногда может удерживать память, занятую большим источником. `strings.Clone()` создаёт независимую копию
подстроки.
