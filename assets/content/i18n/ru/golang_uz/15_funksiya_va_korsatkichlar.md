# Функции и указатели

Go копирует значение каждого аргумента, переданного функции. Иногда функции нужно изменить исходную переменную или
избежать копирования большого значения. В такой ситуации правильно использовать параметр-`pointer`.

## Параметр-значение и параметр-указатель

```go
package main

import "fmt"

func changeByValue(n int) {
	n = 100
}

func changeByPointer(n *int) {
	*n = 100
}

func main() {
	num := 10
	changeByValue(num)
	fmt.Println("После значения:", num)

	changeByPointer(&num)
	fmt.Println("После указателя:", num)
}
```

Результат:

```text
После значения: 10
После указателя: 100
```

Первая функция изменяет копию значения `num`. Второй функции передаётся `&num`, то есть адрес `num`. Указатель `n`
тоже передаётся по значению, но его копия ссылается на ту же переменную `num`. `*n = 100` обновляет значение этой
переменной.

В Go нет ссылочных параметров, как в C++. Указатель тоже передаётся в функцию по значению.

## Безопасная обработка `nil`

Параметр-указатель может быть `nil`. В зависимости от требований функции в таком случае можно вернуть ошибку или
считать `nil` особым значением:

```go
package main

import (
	"fmt"
	"strings"
)

func trim(text *string) error {
	if text == nil {
		return fmt.Errorf("указатель на текст равен nil")
	}
	*text = strings.TrimSpace(*text)
	return nil
}

func main() {
	name := "  Go-разработчик  "
	if err := trim(&name); err != nil {
		fmt.Println("Ошибка:", err)
		return
	}
	fmt.Printf("%q\n", name)
}
```

Результат:

```text
"Go-разработчик"
```

Если использовать `*text` без проверки на `nil`, во время работы программы произойдёт `panic`. В открытом API нужно
документировать, как функция обращается со значением `nil`.

## Когда нужен указатель?

Указатель может быть уместен в таких случаях:

- функция должна изменить значение;
- важно уменьшить затраты на копирование больших данных, и это подтверждают измерения;
- общее состояние одного объекта управляется из нескольких мест.

Не передавайте небольшое число, `bool` или маленький struct через указатель только из предположения, что «указатель
быстрее». Указатель вносит состояние `nil` и общие изменяемые данные. Это может усложнить понимание кода и его
параллельное использование.

Для изменения элементов среза или `map` обычно не нужны `*[]T` или `*map[K]V`. Их значения ссылаются на базовые
данные. Но если в результате `append` внутри функции меняется длина или ёмкость среза, возврат обновлённого среза —
обычный и понятный способ.

## Возврат указателя

В Go возвращать указатель на локальную переменную безопасно. Компилятор обеспечивает хранение значения столько,
сколько нужно:

```go
func newNumber() *int {
	n := 16
	return &n
}
```

Будет ли значение размещено в стеке или в heap, компилятор решает с помощью escape analysis. Не привязывайте логику
работы кода к предположениям о том, в какой части памяти находится значение.

## Примеры

### 1. Увеличение значения через указатель

```go
package main

import "fmt"

func increment(num *int) {
	*num++
}

func main() {
	num := 9
	increment(&num)
	fmt.Println(num)
}
```

Функция принимает адрес переменной. Запись `*num++` равносильна `(*num)++` и увеличивает на единицу значение, на
которое ссылается указатель.

### 2. Обмен двух значений

```go
package main

import "fmt"

func swap(a, b *string) {
	*a, *b = *b, *a
}

func main() {
	first, second := "лево", "право"
	swap(&first, &second)
	fmt.Println(first, second)
}
```

Оба указателя ссылаются на переменные вызывающего кода. Значения меняются местами без отдельной временной переменной.

### 3. Безопасный выход при указателе `nil`

```go
package main

import "fmt"

func show(num *int) {
	if num == nil {
		fmt.Println("Значение не задано")
		return
	}
	fmt.Println(*num)
}

func main() {
	show(nil)
}
```

Перед обращением к значению через указатель проверяется `nil`. Благодаря раннему `return` при `num`, равном `nil`,
`*num` не выполняется.

### 4. Значение по умолчанию через указатель

```go
package main

import "fmt"

func valueOr(p *int, fallback int) int {
	if p == nil {
		return fallback
	}
	return *p
}

func main() {
	num := 0
	fmt.Println(valueOr(nil, 10))
	fmt.Println(valueOr(&num, 10))
}
```

`nil` и `0` рассматриваются как разные случаи. Первый вызов возвращает значение по умолчанию — `10`, а второй —
существующее значение — `0`.

### 5. Функция, возвращающая указатель

```go
package main

import "fmt"

func newCounter(start int) *int {
	num := start
	return &num
}

func main() {
	p := newCounter(5)
	*p += 3
	fmt.Println(*p)
}
```

Возвращать указатель на локальную переменную в Go безопасно. Компилятор определяет, как долго нужно хранить значение.

### 6. Замена самого среза через указатель

```go
package main

import "fmt"

func add(numbers *[]int, num int) {
	*numbers = append(*numbers, num)
}

func main() {
	numbers := []int{1, 2}
	add(&numbers, 3)
	fmt.Println(numbers)
}
```

Для изменения элементов указатель на срез не нужен. В этом примере указатель используется, чтобы функция могла
обновить и длину в описании среза. Обычно вернуть обновлённый срез проще и понятнее.

### 7. Указатель на map не нужен

```go
package main

import "fmt"

func update(scores map[string]int) {
	scores["Go"] = 100
}

func main() {
	scores := map[string]int{"Go": 80}
	update(scores)
	fmt.Println(scores)
}
```

Хотя `map` передаётся в функцию по значению, функция может обновлять её элементы. Для этой задачи `*map` не нужен.

### 8. Изменение массива через указатель

```go
package main

import "fmt"

func clear(numbers *[3]int) {
	for i := range numbers {
		numbers[i] = 0
	}
}

func main() {
	numbers := [3]int{4, 5, 6}
	clear(&numbers)
	fmt.Println(numbers)
}
```

При передаче в функцию по значению массив копируется целиком. А указатель на массив позволяет изменять элементы
исходного массива без создания копии.

### 9. Копируется сам параметр-указатель

```go
package main

import "fmt"

func otherAddress(p *int) {
	other := 99
	p = &other
}

func main() {
	num := 10
	p := &num
	otherAddress(p)
	fmt.Println(*p)
}
```

Результат — `10`. `p` внутри функции — копия указателя. Если направить её на другую переменную, `p` в вызывающем коде
не изменится.

### 10. Обновление адреса через указатель на указатель

```go
package main

import "fmt"

func repoint(p **int, target *int) {
	*p = target
}

func main() {
	first, second := 10, 20
	p := &first
	repoint(&p, &second)
	fmt.Println(*p)
}
```

Тип `**int` обозначает указатель на указатель типа `*int`. Поэтому функция может направить `p` вызывающего кода на
другую переменную.
